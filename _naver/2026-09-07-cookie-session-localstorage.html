쿠키 vs 세션 vs 로컬스토리지 — 브라우저 저장소 구분하기

2026. 9. 7. · 프론트엔드

한 줄 요약 — 쿠키는 매 요청에 자동 전송돼 인증에, 로컬/세션스토리지는 클라이언트 전용 데이터에 적합합니다.

 

브라우저에 데이터를 저장하는 여러 방법

로그인 상태나 설정을 유지하려면 브라우저에 데이터를 저장해야 합니다. 쿠키·로컬스토리지·세션스토리지의 차이를 알면 상황에 맞게 고를 수 있습니다.

 

세 저장소 비교
항목 쿠키 로컬스토리지 세션스토리지
수명 만료일까지 영구 탭 닫으면 사라짐
서버 전송 자동 안 됨 안 됨

 

무엇을 언제 쓰나
인증 토큰 -> 쿠키(특히 HttpOnly)
다크모드·최근 검색어 -> localStorage
여러 단계 폼 임시값 -> sessionStorage

 

실무 포인트

인증 토큰을 localStorage에 저장하면 XSS에 취약합니다. 자바스크립트로 접근 가능해 악성 스크립트에 탈취당할 수 있어, HttpOnly 쿠키가 더 안전합니다.

주의 — HttpOnly 쿠키는 자동 전송되므로 CSRF에 노출될 수 있어 SameSite·CSRF 토큰 방어가 필요합니다. 어느 저장소에도 민감정보를 평문으로 두지 마세요.
