복합키가 뭔가요 — 여러 컬럼을 묶어 기본키로 쓰기

데이터베이스

한 줄 요약 — 복합키는 두 개 이상의 컬럼을 묶어 하나의 기본키로 삼는 것으로, 다대다 연결 테이블에 자주 씁니다.

 

컬럼 하나로 못 구분할 때

수강신청 테이블에서 "학생 A가 과목 1 신청" 행을 고유 구분하려면? student_id만으론 한 학생이 여러 과목을 신청하니 안 됩니다. 복합키는 (student_id, course_id)처럼 조합이 유일하면 기본키로 삼습니다.

 

단일키 vs 복합키
구분 단일키 복합키
구성 컬럼 1개 컬럼 2개 이상
유일성 그 컬럼만으로 조합으로

 

예시
CREATE TABLE enrollments (
    student_id BIGINT,
    course_id  BIGINT,
    PRIMARY KEY (student_id, course_id)
);
-- (학생, 과목) 조합이 유일 -> 중복 신청 불가

 

실무 포인트

학생-과목·사용자-역할 같은 다대다 연결 테이블에 자연스럽습니다. 무의미한 단일 id를 키로 두고 조합엔 UNIQUE를 거는 대리키 방식도 많이 쓰니 비교해 고르세요.

주의 — 복합키 컬럼 순서가 인덱스 활용에 영향을 줍니다. (A,B) 인덱스는 B만으로 조회하면 못 타니 자주 조회하는 컬럼을 앞에 두세요.
