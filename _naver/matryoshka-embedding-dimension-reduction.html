Matryoshka 임베딩 — 벡터 차원을 유연하게 잘라 쓰는 법

AI

한 줄 요약 — 벡터의 앞쪽 부분만 잘라도 의미가 보존되도록 학습된 Matryoshka 임베딩으로 저차원 1차 필터링과 고차원 정밀 검색을 조합하는 법을 정리했습니다.

 

왜 지금 Matryoshka 임베딩을 다시 봐야 하는가

임베딩 차원이 클수록 정확도는 높지만 저장 공간과 유사도 계산 비용이 함께 늘어납니다. PCA 같은 사후 차원 축소는 품질이 눈에 띄게 떨어지는 경우가 많았습니다. MRL은 학습 단계에서부터 차원을 잘라도 의미가 보존되도록 만듭니다.

 

러시아 인형처럼 중첩된 표현을 학습한다

MRL은 벡터의 앞쪽 부분집합만 잘라내도 유의미한 임베딩이 되도록 학습합니다. 앞쪽 차원에 거친 의미 정보가, 뒤쪽으로 갈수록 세부 보정 정보가 위계적으로 배치됩니다.

 

정확도와 비용 사이에서 차원을 동적으로 선택할 수 있다

1차 후보군 필터링은 64~128차원으로 빠르게, 최종 재순위 단계는 전체 차원으로 정밀하게 비교하는 2단계 검색이 가능합니다. 별도의 재순위 모델을 학습할 필요 없이 같은 임베딩을 다른 정밀도로 재사용합니다.

차원 검색 속도 적합한 용도
전체(1536) 느림 최종 재순위
중간(256) 중간 일반 벡터 검색
작음(64) 매우 빠름 대규모 1차 필터링

 

예제 — 차원을 잘라 2단계 검색 구현하기
def truncate_and_normalize(embedding, dim):
    truncated = embedding[:dim]
    return truncated / np.linalg.norm(truncated)

query_embedding_full = embed_model.encode(query)
query_small = truncate_and_normalize(query_embedding_full, 128)
candidates = vector_db.search(query_small, dim=128, top_k=200)

query_full = truncate_and_normalize(query_embedding_full, 1536)
reranked = []
for doc in candidates:
    doc_full_vec = fetch_full_embedding(doc.id)
    score = cosine_similarity(query_full, doc_full_vec)
    reranked.append((doc, score))

final_results = sorted(reranked, key=lambda x: -x[1])[:20]

전체 차원 벡터는 상위 200개 후보에 대해서만 조회하면 되므로 비용을 줄이면서도 정확도를 유지할 수 있습니다.

 

실무 포인트

사용 중인 모델이 실제로 MRL로 학습됐는지 먼저 확인하세요. 일반 모델을 임의로 자르면 의미가 크게 훼손됩니다.

잘라낸 차원으로도 재정규화를 잊지 마세요. 정규화하지 않으면 유사도 계산이 왜곡됩니다.

주의 — 차원별 정확도 손실을 실제 도메인 데이터로 벤치마크하세요. 논문 벤치마크가 모든 도메인에 그대로 적용되지는 않습니다.
