AUTO_INCREMENT와 시퀀스가 뭔가요 — ID를 자동으로 매기기

2026. 9. 9. · 데이터베이스

한 줄 요약 — AUTO_INCREMENT·시퀀스는 새 행마다 DB가 다음 고유 번호를 자동 부여하는 기능이며, 삭제해도 번호는 되돌아가지 않습니다.

 

ID를 직접 1, 2, 3... 매겨야 하나

데이터를 넣을 때마다 고유한 기본키가 필요합니다. 매번 "제일 큰 ID가 몇이지?"를 조회해 +1 하는 건 번거롭고, 동시 요청이면 값이 겹칠 수 있죠. AUTO_INCREMENT(시퀀스)는 새 행이 들어올 때 DB가 알아서 다음 번호를 부여해 이를 해결합니다.

 

DB별 이름
DB 방식
MySQL AUTO_INCREMENT
PostgreSQL SERIAL / IDENTITY
Oracle SEQUENCE

 

사용 예시
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50)
);
INSERT INTO users(name) VALUES ('철수'); -- id: 1
INSERT INTO users(name) VALUES ('영희'); -- id: 2

 

실무 포인트

id 2를 지워도 다음은 3부터입니다("빈 칸" 생김은 정상). 순차 ID는 예측 가능해 /users/1처럼 남의 데이터를 넘겨짚을 수 있으니, 외부 노출엔 UUID를 쓰세요. 샤딩 환경에선 스노플레이크 같은 분산 ID를 고려합니다.

주의 — 자동 증가 ID로 "총 몇 개인지"를 유추하면 안 됩니다. 삭제로 빈 번호가 생기기 때문입니다.
