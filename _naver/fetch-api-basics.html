fetch로 API 호출하기 — 프론트에서 서버 데이터 받아오기

2026. 9. 14. · 프론트엔드

한 줄 요약 — fetch는 브라우저 내장 함수로 서버에 HTTP 요청을 보내고, 응답은 res.json()으로 파싱합니다.

 

프론트에서 서버 데이터를 어떻게 받나

화면에 서버 데이터를 표시하려면 브라우저가 서버에 요청을 보내 응답을 받아야 합니다. fetch는 브라우저에 내장된, 서버에 HTTP 요청을 보내는 함수로 별도 라이브러리 없이 씁니다.

 

기본 사용
// GET
const res = await fetch('/api/users');
const data = await res.json();

// POST
await fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: '철수' })
});

 

실무 포인트

fetch는 404·500 응답도 "성공"으로 봐 catch로 안 잡힙니다. res.ok/res.status를 직접 확인하세요. 실제 데이터는 res.json()으로 한 번 더 꺼내야 하며, 이 단계도 await이 필요합니다.

주의 — 다른 도메인 API는 CORS 정책이 적용됩니다. 인증이 필요하면 headers에 토큰을 넣거나 credentials 옵션으로 쿠키를 포함하세요.
