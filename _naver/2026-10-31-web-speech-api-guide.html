Web Speech API로 음성 인식·음성 합성 기능 붙이기

프론트엔드

한 줄 요약 — 브라우저 내장 Web Speech API(SpeechRecognition + SpeechSynthesis)로 서버 비용 없이 음성 검색·읽어주기 프로토타입을 빠르게 만들 수 있습니다.

 

왜 항상 외부 API부터 떠올리게 되는가

음성 검색이나 텍스트 읽어주기 기능을 붙이려 하면 대부분 외부 STT/TTS API 연동부터 검토합니다. 프로덕션급 정확도가 필요하면 맞는 선택이지만, 프로토타입이거나 보조 기능 수준이라면 브라우저에 이미 내장된 Web Speech API만으로도 상당 부분 구현할 수 있습니다.

 

잘못된 접근 vs 올바른 접근

지원 여부를 확인하지 않고 바로 new SpeechRecognition()을 호출하면 특정 브라우저에서 기능이 조용히 깨집니다. 기능 감지와 폴백을 반드시 준비해야 합니다.

const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;

if (!SpeechRecognition) {
  showFallbackUI();
} else {
  const recognition = new SpeechRecognition();
  recognition.lang = 'ko-KR';
  recognition.interimResults = true;
  recognition.onresult = (event) => {
    searchInput.value = event.results[event.results.length - 1][0].transcript;
  };
}

lang 속성을 명시하지 않으면 브라우저 UI 언어로 추측해 인식률이 떨어질 수 있습니다. interimResults를 켜면 말하는 도중에도 중간 결과를 실시간으로 반영할 수 있습니다.

주의 — speechSynthesis.getVoices()는 페이지 로드 직후 빈 배열을 반환하는 경우가 많습니다. voiceschanged 이벤트를 구독해 목록이 채워진 뒤 원하는 목소리를 찾아야 합니다.

실무 포인트

마이크 권한 요청은 반드시 사용자 클릭 같은 제스처와 함께 이뤄져야 합니다. onend 이벤트로 인식 세션 종료를 감지해 UI 상태를 되돌리고, HTTPS 환경에서만 대부분 동작한다는 점도 잊지 마세요. 긴 텍스트를 TTS로 읽힐 때는 문장 단위로 끊어 큐에 넣는 것이 안전합니다.
