웹서버와 WAS 차이가 뭔가요 — Nginx와 톰캣의 역할

2026. 9. 18. · 인프라

한 줄 요약 — 웹서버(Nginx)는 정적 파일을 전달하고, WAS(톰캣)는 코드를 실행해 동적 결과를 만듭니다.

 

Nginx랑 톰캣은 뭐가 다른가

웹서버는 HTML·이미지 같은 정적 파일을 그대로 전달하고, WAS는 코드를 실행해 동적 결과(DB 조회·로그인)를 만듭니다.

 

웹서버 vs WAS
구분 웹서버 WAS
예 Nginx 톰캣
처리 정적 파일 코드 실행(동적)

 

왜 함께 쓰나
클라이언트 -> Nginx -> 톰캣
  Nginx: 정적 파일은 직접 응답(빠름)
         동적 요청은 WAS로 전달(리버스 프록시)

 

실무 포인트

정적 파일까지 WAS가 처리하면 무거우니 웹서버가 정적을 맡습니다. 웹서버가 앞에서 SSL 종료·로드밸런싱·필터링을 처리하면 WAS를 직접 노출 안 해 보안에 유리합니다.

주의 — 스프링 부트는 톰캣을 내장해 WAS를 따로 안 띄워도 되지만, 운영에선 앞에 Nginx를 두는 구성이 여전히 흔합니다.
