MapLibre GL JS CustomLayerInterface로 Three.js WebGL 레이어 통합하기

GIS

한 줄 요약 — MapLibre의 CustomLayerInterface를 쓰면 같은 WebGL 컨텍스트와 프레임 안에서 Three.js 3D 모델을 지도 좌표에 정확히 겹쳐 그릴 수 있습니다.

 

왜 지금 커스텀 레이어를 알아야 하는가

MapLibre GL JS의 내장 레이어만으로는 항공기 경로 애니메이션, 정밀 3D 모델(GLTF), 파티클 효과 같은 표현이 부족할 때가 있습니다. 별도 오버레이 캔버스를 얹으면 확대·회전 시 프레임 지연이나 어긋남이 생기기 쉽지만, CustomLayerInterface를 쓰면 같은 WebGL 컨텍스트와 같은 프레임 안에서 그리기 때문에 이 문제가 사라집니다.

 

 

CustomLayerInterface가 실제로 하는 일

레이어 타입을 "custom"으로 지정하면 MapLibre는 매 프레임 render(gl, matrix) 함수를 직접 호출해줍니다. gl은 MapLibre가 이미 초기화한 WebGL 컨텍스트 그 자체이고, matrix는 현재 카메라 위치·줌·틸트를 반영한 Mercator 투영 행렬입니다. 별도 캔버스 없이 같은 좌표계로 이어서 그릴 수 있는 것이 핵심입니다.

 

Three.js 카메라를 Mercator 행렬에 맞추는 법

MapLibre가 넘겨주는 matrix는 Three.js의 일반적인 카메라 설정과 맞지 않습니다. 표준적인 해법은 Three.js 카메라의 projectionMatrix를 이 행렬로 직접 덮어쓰는 것입니다. 모델 좌표는 위경도가 아니라 MercatorCoordinate로 변환한 정규화 좌표로 배치해야 합니다.

항목 일반 Three.js MapLibre CustomLayer 안
카메라 투영 PerspectiveCamera 자체 계산 MapLibre의 matrix 주입
좌표계 임의의 3D 월드 좌표 Mercator 정규화 좌표 변환 필요
WebGL 컨텍스트 Three.js가 새로 생성 MapLibre 것을 재사용

 

예제 — 최소 CustomLayer 구현
const customLayer = {
  id: '3d-model-layer',
  type: 'custom',
  renderingMode: '3d',

  onAdd(map, gl) {
    this.camera = new THREE.Camera();
    this.scene = new THREE.Scene();
    this.renderer = new THREE.WebGLRenderer({
      canvas: map.getCanvas(),
      context: gl,
      antialias: true,
    });
    this.renderer.autoClear = false;
  },

  render(gl, matrix) {
    const m = new THREE.Matrix4().fromArray(matrix);
    const l = new THREE.Matrix4()
      .makeTranslation(mx, my, mz)
      .scale(new THREE.Vector3(scale, -scale, scale));

    this.camera.projectionMatrix = m.multiply(l);
    this.renderer.resetState();
    this.renderer.render(this.scene, this.camera);
    map.triggerRepaint();
  },
};

map.on('load', () => map.addLayer(customLayer));

 

실무 포인트

renderer.autoClear = false를 반드시 설정하세요. 기본값대로 두면 Three.js가 화면을 지우면서 MapLibre 지도 레이어까지 지워집니다.

애니메이션이 있다면 map.triggerRepaint()를 매 프레임 호출하세요. 그렇지 않으면 지도가 정적일 때 커스텀 레이어 애니메이션도 함께 멈춥니다.

주의 — z-fighting과 깊이 버퍼 공유 문제를 초기에 테스트하세요. fill-extrusion 3D 건물과 Three.js 모델이 같은 깊이 버퍼를 공유하므로, 스케일이 어긋나면 건물 뒤에 있어야 할 모델이 앞으로 튀어나오는 오류가 생깁니다.
