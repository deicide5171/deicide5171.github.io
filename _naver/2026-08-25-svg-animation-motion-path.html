곡선을 따라 움직이는 UI — SVG 애니메이션과 CSS Motion Path 실무

2026. 8. 25. · 프론트엔드

한 줄 요약 — SMIL이 사실상 유지보수 단계에 머문 지금, 경로를 따라 움직이는 애니메이션의 최신 표준인 CSS offset-path와 Web Animations API 활용법을 정리했습니다.

 

경로를 따라 움직이는 애니메이션, 이제는 CSS로

버튼 클릭 시 아이콘이 곡선을 그리며 장바구니로 날아가는 연출, 지도 위 경로를 따라 움직이는 마커 같은 "경로를 따라 움직이는" 애니메이션은 흔히 SVG의 animateMotion(SMIL)으로 구현됐습니다. 그런데 SMIL은 브라우저 벤더들 사이에서 오랫동안 신규 개발이 중단된 상태이고, 최신 명세는 이 역할을 CSS의 motion path(offset-path) 기능으로 넘기는 방향으로 정리되고 있습니다.

 

핵심 개념 1 — offset-path, 임의의 경로를 움직임의 궤적으로

CSS Motion Path 스펙의 핵심은 offset-path 속성입니다. SVG path() 함수로 곡선을 지정하면 요소가 그 경로를 따라 이동할 수 있는 궤적을 갖습니다. 실제 이동은 offset-distance를 애니메이션시켜 구현하고, offset-rotate로 접선 방향을 따라 자연스럽게 회전시킬 수 있습니다. SMIL과 달리 일반 HTML 요소에도 그대로 쓸 수 있다는 점이 실무에서 특히 유용합니다.

 

핵심 개념 2 — SVG path와 CSS 좌표계의 차이

SVG path의 d 속성 좌표는 SVG 문서의 viewBox 기준 좌표계를 따르지만, CSS offset-path에 넣는 경로 좌표는 해당 요소가 속한 CSS 박스 좌표계를 기준으로 해석됩니다. 두 좌표계가 다르다는 것을 모르고 그대로 복붙하면 요소가 엉뚱한 위치로 튀는 경우가 흔합니다.

구분 SMIL animateMotion CSS offset-path
적용 대상 SVG 요소만 HTML/SVG 모두
표준 상태 신규 개발 중단 활발히 개발 중

 

핵심 개념 3 — Web Animations API로 프로그래밍적 제어

CSS 애니메이션만으로는 스크롤 진행률에 맞춰 경로 진행률을 맞추는 등의 동적 제어가 번거롭습니다. 이런 경우 Web Animations API(WAAPI)로 offset-distance를 직접 키프레임 애니메이션으로 제어하면, JavaScript에서 animation.currentTime을 조작해 임의의 진행률로 동기화할 수 있습니다.

 

예제 — CSS Motion Path + WAAPI로 곡선 이동
.icon {
  offset-path: path("M 20 200 C 120 20, 280 20, 380 200");
  offset-rotate: auto;
  offset-distance: 0%;
}

const icon = document.getElementById('cart-icon');
const animation = icon.animate(
  [{ offsetDistance: '0%' }, { offsetDistance: '100%' }],
  { duration: 800, easing: 'ease-in-out', fill: 'forwards' }
);

// 스크롤 진행률에 맞춰 경로 진행률을 수동으로 매핑
window.addEventListener('scroll', () => {
  const progress = getScrollProgress();
  animation.currentTime = progress * animation.effect.getTiming().duration;
});

 

실무 도입 시 이것만은 챙기세요
1. 브라우저 지원 범위를 확인하세요 — @supports로 기능 감지 후 폴백을 분기하는 패턴이 안전합니다.
2. 경로가 복잡할수록 GPU 가속 여부를 확인하세요 — offset-path 자체를 매 프레임 바꾸면 성능이 급격히 나빠집니다.
3. 접근성 고려를 빠뜨리지 마세요 — prefers-reduced-motion으로 모션 민감 사용자를 위한 대체 스타일을 제공하세요.

 

마무리 — 3줄 요약

① SMIL animateMotion은 유지보수 단계에 머물러 있고, 경로 애니메이션의 최신 표준은 CSS offset-path입니다.
② SVG 좌표계와 CSS 박스 좌표계가 달라 경로 좌표를 그대로 복사하면 위치가 어긋나기 쉽습니다.
③ 동적 제어가 필요하면 Web Animations API로 진행률을 직접 조작하고, 성능을 위해 경로 자체보다 진행률만 애니메이션하세요.
