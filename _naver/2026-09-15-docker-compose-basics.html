도커 컴포즈가 뭔가요 — 여러 컨테이너를 한 번에 실행하기

인프라

한 줄 요약 — 도커 컴포즈는 여러 컨테이너 구성을 하나의 YAML에 적어 명령 한 줄로 실행하는 도구입니다.

 

컨테이너를 하나씩 띄우기 번거롭다

웹·DB·Redis를 함께 띄우려면 docker run을 각각 실행하고 옵션을 일일이 지정해야 합니다. 도커 컴포즈는 여러 컨테이너 구성을 하나의 YAML에 적어두고 명령 한 줄로 전부 실행합니다.

 

docker-compose.yml 예시
services:
  web:
    build: .
    ports: ["8080:80"]
  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: secret

 

명령
명령 하는 일
up -d 백그라운드 실행
down 전부 중지·삭제

 

실무 포인트

팀원이 docker compose up 한 줄로 동일한 개발 환경을 띄웁니다. 컴포즈 네트워크 안에서 서비스는 이름으로 통신합니다(웹→DB 호스트를 db로).

주의 — 컴포즈는 단일 호스트용입니다. 여러 서버에 걸친 대규모 운영은 쿠버네티스 같은 오케스트레이터를 쓰세요.
