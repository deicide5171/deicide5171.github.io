JPA 영속성 컨텍스트가 뭔가요 — 엔티티를 관리하는 1차 캐시

2026. 9. 14. · 백엔드

한 줄 요약 — 영속성 컨텍스트는 JPA가 엔티티를 담아 관리하는 공간으로, 1차 캐시·변경 감지·쓰기 지연을 제공합니다.

 

같은 데이터 두 번 조회에 쿼리 한 번

JPA에서 같은 엔티티를 두 번 조회해도 쿼리가 한 번만 나가는 건 영속성 컨텍스트 덕분입니다. 엔티티를 담아 관리하는 논리적 공간으로, 조회한 엔티티를 1차 캐시에 보관합니다.

 

핵심 기능
기능 설명
1차 캐시 재조회 시 DB 안 감
변경 감지 값 바뀌면 자동 UPDATE
쓰기 지연 커밋 시점에 INSERT

 

변경 감지 예시
@Transactional
public void updateName(Long id, String newName) {
    User user = userRepository.findById(id).get();
    user.setName(newName);
    // save() 없이도 커밋 시 UPDATE 자동 실행
}

 

실무 포인트

영속 상태 엔티티는 save() 없이 값만 바꾸면 커밋 시 변경 감지로 UPDATE가 나갑니다. 컨텍스트는 트랜잭션 범위라 1차 캐시도 요청마다 새로 생겨 사라집니다.

주의 — 트랜잭션 밖에서 지연 로딩(lazy) 필드에 접근하면 LazyInitializationException이 납니다. 필요한 데이터는 트랜잭션 안에서 조회하세요.
