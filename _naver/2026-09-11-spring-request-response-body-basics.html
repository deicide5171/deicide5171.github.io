@RequestBody와 @ResponseBody — 스프링에서 JSON 주고받기

2026. 9. 11. · 백엔드

한 줄 요약 — @RequestBody는 요청 JSON을 자바 객체로, @ResponseBody는 자바 객체를 응답 JSON으로 자동 변환합니다.

 

JSON과 자바 객체를 어떻게 오가나

프론트가 보낸 JSON을 코드에서 다루려면 객체로 바꿔야 하고, 반대로 객체를 응답하려면 JSON으로 바꿔야 합니다. @RequestBody가 요청 JSON→객체, @ResponseBody가 객체→응답 JSON을 자동 변환합니다(Jackson 사용).

 

두 애너테이션의 역할
애너테이션 방향
@RequestBody 요청 JSON → 객체
@ResponseBody 객체 → 응답 JSON

 

예시
@RestController
public class UserController {
    @PostMapping("/users")
    public UserResponse create(@RequestBody UserRequest req) {
        return new UserResponse(1L, req.getName());
    }
}
// @RestController면 반환 객체가 자동 JSON

 

실무 포인트

JSON 키와 자바 필드명이 매핑 기준입니다(다르면 @JsonProperty). 본문은 @RequestBody, 쿼리는 @RequestParam으로 구분하세요. DTO에 @Valid를 붙여 검증을 함께 하면 좋습니다.

주의 — JSON 키와 필드 이름이 다르면 값이 채워지지 않습니다. @JsonProperty나 케이스 변환 설정을 맞추세요.
