CSS 우선순위가 뭔가요 — 스타일이 왜 안 먹는지 이해하기

2026. 9. 15. · 프론트엔드

한 줄 요약 — 명시도(우선순위)는 규칙 충돌 시 어느 것을 적용할지 정하며, 인라인 > id > class > 태그 순입니다.

 

스타일을 줬는데 안 바뀐다

CSS로 색을 바꿨는데 화면이 그대로일 때가 있죠. 다른 규칙이 더 "강해서" 이겼기 때문입니다. 규칙이 충돌하면 CSS는 명시도(우선순위)로 어느 규칙을 적용할지 정합니다.

 

우선순위 (높을수록 이김)
선택자 강도
인라인 style 가장 강함
id (#header) 강함
class (.btn) 중간
태그 (div) 약함

같은 강도면 나중에 선언된 규칙이 이깁니다.

 

예시
p { color: black; }     /* 약함 */
.text { color: blue; }  /* 중간 */
#intro { color: red; }  /* 강함 */

 -> 빨강(id 승)

 

실무 포인트

!important는 남발하면 나중에 못 덮어 유지보수가 지옥이 되니 최후의 수단입니다. 스타일링은 주로 class로 하고 id 남용을 피하세요. 안 먹으면 개발자 도구로 확인합니다.

주의 — id는 우선순위가 너무 높아 나중에 덮기 어렵습니다. id는 JS 선택·앵커 용도로, 스타일은 class로 하세요.
