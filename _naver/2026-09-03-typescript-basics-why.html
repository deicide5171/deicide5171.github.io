TypeScript를 왜 쓰나요 — 자바스크립트와 무엇이 다른지 기초부터

2026. 9. 3. · 프론트엔드

한 줄 요약 — TypeScript는 자바스크립트에 타입을 더해 실행 전에 명백한 실수를 잡아주는 언어이며, 자동완성·리팩터링·문서화 이점도 함께 줍니다.

 

왜 잘 돌아가는 JS에 타입을 붙이나

자바스크립트의 유연함은 실행 중에야 드러나는 버그로 돌아옵니다. user가 undefined였거나 숫자를 기대한 함수에 문자열이 들어가는 실수가 대표적입니다. TypeScript는 이를 작성하는 순간에 잡아줍니다.

 

타입이 막아주는 대표적 실수
// JS: 실행해봐야 에러를 안다
function getDiscount(price) { return price * 0.9; }
getDiscount("1000"); // 이상한 결과

// TS: 작성하는 순간 빨간 줄
function getDiscount(price: number): number { return price * 0.9; }
getDiscount("1000"); // 에러: string은 number에 할당 불가

 

JS vs TS
항목 JavaScript TypeScript
타입 검사 없음(실행 중 오류) 작성/컴파일 시점
리팩터링 놓치기 쉬움 타입 어긋나면 알려줌

let name: string = "김철수";
let age: number = 30;

interface User {
  id: number;
  name: string;
  email?: string; // ?는 선택적 속성
}
