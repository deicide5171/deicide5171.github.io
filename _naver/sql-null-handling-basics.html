SQL에서 NULL이 뭔가요 — '값 없음'이 만드는 함정

2026. 9. 10. · 데이터베이스

한 줄 요약 — NULL은 "값 없음(모름)"으로 0·빈 문자열과 다르며, = NULL로 비교되지 않아 IS NULL을 써야 합니다.

 

NULL은 0도 빈 문자열도 아니다

SQL에서 NULL은 "값이 없음(모름)"을 뜻합니다. 숫자 0이나 빈 문자열과는 다릅니다. 문제는 이 NULL이 비교·계산에서 예상 밖으로 동작한다는 점입니다.

 

NULL의 함정
시도 결과
WHERE col = NULL 아무것도 안 나옴
WHERE col IS NULL 올바른 방법
1 + NULL 결과가 NULL

 

올바른 처리
-- NULL 여부
SELECT * FROM users WHERE phone IS NULL;
-- NULL 대체
SELECT name, COALESCE(phone, '미등록') FROM users;
-- COUNT(col)은 NULL을 안 센다
SELECT COUNT(*), COUNT(phone) FROM users;

 

실무 포인트

비교는 반드시 IS NULL/IS NOT NULL로 하세요(= NULL은 항상 매칭 안 됨). 화면 표시엔 COALESCE(값, 기본값)으로 대체값을 주고, 집계·조인에서 NULL이 빠지거나 무시되는지 확인하세요.

주의 — NULL이 있는 컬럼으로 조인하면 매칭이 빠지고, COUNT(컬럼)은 NULL을 세지 않습니다. 의도와 맞는지 확인하세요.
