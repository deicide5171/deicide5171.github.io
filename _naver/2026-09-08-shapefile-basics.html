셰이프파일(Shapefile)이 뭔가요 — 왜 파일이 여러 개인가

GIS

한 줄 요약 — 셰이프파일은 .shp·.shx·.dbf 등 여러 파일이 세트로 하나의 공간 데이터를 이루는 형식이라, 파일을 옮길 땐 함께 옮겨야 합니다.

 

.shp 하나만 받으면 왜 안 열릴까

GIS 데이터를 받으면 .shp, .shx, .dbf 같은 파일이 세트로 옵니다. .shp 하나만 복사하면 제대로 안 열리죠. 셰이프파일은 사실 여러 파일이 모여 하나의 공간 데이터를 이루는 형식입니다. 1990년대 Esri가 만든 오래된 포맷이지만 지금도 가장 널리 쓰입니다.

 

구성 파일
확장자 역할
.shp 도형(점·선·면)의 좌표 (필수)
.shx 도형 위치 색인 (필수)
.dbf 속성(이름·인구 등) (필수)
.prj 좌표계 정보 (권장)

 

이렇게 나뉘어 있다
seoul_district.shp  <- 자치구 경계 도형
seoul_district.shx  <- 도형 색인
seoul_district.dbf  <- 자치구 이름·인구 등 속성
seoul_district.prj  <- 좌표계(WGS84 등)
-> 4개가 같은 이름으로 한 폴더에 있어야 열린다

 

실무 포인트

파일을 옮길 땐 세트로(압축해서) 옮기세요. .prj가 없으면 좌표계를 몰라 엉뚱한 위치에 찍힙니다. 속성명 10자 제한·한글 인코딩·2GB 제한 같은 한계가 있어, 요즘은 GeoPackage나 GeoJSON도 많이 씁니다.

주의 — .shp만 복사하고 .dbf·.shx를 빠뜨리면 열리지 않습니다. 데이터를 받으면 .prj(좌표계) 유무도 꼭 확인하세요.
