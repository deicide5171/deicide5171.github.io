벡터 데이터베이스가 뭔가요 — 의미로 검색하는 저장소

2026. 9. 11. · AI

한 줄 요약 — 벡터 DB는 임베딩(벡터)을 저장하고 가장 가까운 벡터를 빠르게 찾는 데 특화된 저장소로, RAG의 검색 단계를 담당합니다.

 

벡터 검색엔 특별한 저장소가 필요

RAG에서는 문장을 임베딩(벡터)으로 바꿔 "비슷한 벡터"를 찾습니다. 일반 관계형 DB는 "값이 같은 것"은 잘 찾지만 "벡터가 가까운 것"은 어렵죠. 벡터 DB는 벡터를 저장하고 가까운 것을 빠르게 찾는 데 특화됐습니다.

 

무엇을 하나
기능 설명
저장 벡터 + 원본/메타데이터
유사도 검색 가까운 top-K 반환
근사 최근접(ANN) 정확도 약간 양보, 매우 빠름

 

RAG에서의 흐름
사전: 문서 -> 임베딩 -> 벡터 DB 저장
질문: 질문 -> 임베딩 -> 유사 문서 top-K 검색
     -> 찾은 문서를 LLM 프롬프트에 넣어 답변

 

실무 포인트

근사 최근접(HNSW 등)으로 정확도를 약간 내주고 속도를 얻으며, 파라미터로 균형을 조절합니다. "이 사용자 문서 중에서만" 같은 메타데이터 필터를 함께 씁니다. 전용 DB(Pinecone 등)와 pgvector 중 규모에 맞게 고르세요.

주의 — 전용 벡터 DB만 답은 아닙니다. 기존 PostgreSQL에 pgvector를 더하는 편이 운영이 간단할 수 있습니다.
