AI

한 줄 요약 — AI 에이전트는 목표를 받아 스스로 도구를 쓰고 결과를 보며 반복 판단해 일을 처리하며, 답만 하는 챗봇과 다릅니다.

 

챗봇과 에이전트는 뭐가 다른가

일반 챗봇은 질문에 텍스트로 답만 합니다. AI 에이전트는 목표를 받으면 계획을 세우고, 도구를 써서 실제 행동을 하고, 결과를 보고 다시 판단하는 과정을 반복합니다. "항공권 알아봐줘"에 챗봇은 방법을 설명하지만, 에이전트는 검색 도구를 호출해 실제로 찾아옵니다.

 

에이전트의 핵심 요소
요소 설명
LLM(두뇌) 무엇을 할지 판단·계획
도구(tools) 검색·API·코드 실행 등 행동 수단
반복 루프 행동 → 관찰 → 다음 행동
메모리 진행 상황·맥락 기억

 

동작 흐름
목표: "이번 주 서울 날씨 정리해줘"
1. LLM: "날씨 API를 호출해야겠다" (판단)
2. 도구 실행: 날씨 API 호출 -> 데이터 받음 (행동)
3. LLM: "충분한가?" 판단 (관찰)
4. 부족하면 다시 호출, 충분하면 정리해 답변 (반복/종료)

 

실무 포인트

에이전트는 강력하지만 예측이 어렵습니다. 결제·삭제 등 실제 영향을 주는 도구는 사람 확인 단계(human-in-the-loop)를 두세요. 단순 질의응답엔 일반 LLM으로 충분하고, 루프마다 LLM을 여러 번 호출하므로 비용·지연도 큽니다.

주의 — 에이전트는 루프를 무한정 돌 수 있으므로 루프 횟수 제한 같은 안전장치가 반드시 필요합니다.
