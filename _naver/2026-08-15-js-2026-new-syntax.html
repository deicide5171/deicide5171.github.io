2026년 최신 JS 문법 정리, 실무에 바로 쓰는 기능들

2026. 8. 15. · 웹 개발

한 줄 요약 — Object.groupBy처럼 이미 쓸 수 있는 문법과, Temporal·데코레이터처럼 아직 상태 확인이 필요한 문법을 구분해서 접근해야 합니다.

 

왜 매번 헷갈릴까요

JavaScript는 매년 TC39를 통해 새 문법을 표준화하지만, 실무에서는 "이게 지금 실제로 쓸 수 있는 단계인지"를 확인하는 일이 은근히 번거롭습니다. 제안 단계는 Stage 0부터 Stage 4까지 있고, 이 진행 상황은 회의마다 계속 바뀌기 때문에 과거 정보를 그대로 믿기보다는 실제 배포 환경에서 다시 확인하는 습관이 필요합니다.

 

현재 상태 정리 (변동 가능)
기능 대략적 상태 설명
Object.groupBy Baseline, 사용 가능한 것으로 보임 배열 요소를 조건별로 그룹핑
Temporal Stage 4 보도, 런타임별 확인 필요 Date를 대체하는 불변 날짜/시간 API
데코레이터 Stage 3, 트랜스파일러에서 널리 사용 클래스/메서드에 메타 동작 부여

 

바로 써볼 수 있는 예제

Object.groupBy는 배열을 조건별로 그룹핑할 때 유용합니다.

const orders = [
  { id: 1, status: "paid" },
  { id: 2, status: "pending" },
  { id: 3, status: "paid" },
];

const grouped = Object.groupBy(orders, (order) => order.status);
console.log(grouped);
// { paid: [...], pending: [...] }

 

실무 도입 시 이것만은 챙기세요
1. 지원 버전 재확인 — caniuse나 공식 릴리스 노트로 타겟 환경의 실제 지원 여부를 꼭 확인하세요.
2. Stage 3 이하는 신중하게 — 사양이 바뀔 수 있으므로 폴리필 여부와 함께 검토하세요.
3. Temporal은 점진 도입 — 기존 Date API 대체 범위가 크므로 신규 코드부터 적용하는 편이 안전합니다.
4. 표준 사양과 트랜스파일러 차이 인지 — 데코레이터처럼 먼저 쓰이던 문법은 버전별 동작 차이가 있을 수 있습니다.

 

마무리 — 3줄 요약

① Object.groupBy/Map.groupBy는 Baseline로 표기되어 바로 활용 가능한 것으로 보입니다.
② Temporal, 데코레이터 등은 스테이지가 계속 바뀌므로 도입 전 재확인이 필요합니다.
③ 새 문법 도입은 타겟 런타임의 실제 지원 현황을 기준으로 판단해야 합니다.
