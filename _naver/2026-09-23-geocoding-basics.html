지오코딩이 뭔가요 — 주소를 좌표로 바꾸는 기술

GIS

한 줄 요약 — 지오코딩은 주소를 위도·경도 좌표로 바꿔 지도에 표시하는 기술이며, 반대 방향인 역지오코딩은 좌표를 주소로 바꿉니다.

 

주소를 지도에 찍으려면 좌표가 필요합니다

"서울 중구 세종대로 110" 같은 주소는 사람은 이해하지만 지도 화면은 이해하지 못합니다. 지도에 점을 찍으려면 위도·경도 좌표(예: 37.5665, 126.9780)가 필요합니다. 주소를 이 좌표로 바꿔주는 것이 지오코딩입니다.

 

지오코딩과 역지오코딩
구분 입력 → 출력 예시
지오코딩 주소 → 좌표 주소 검색 후 마커 표시
역지오코딩 좌표 → 주소 현재 위치를 주소로 표시

 

어떻게 쓰나
1. 지오코딩 API에 주소를 보낸다: "서울 중구 세종대로 110"
2. API가 좌표를 돌려준다: { lat: 37.5665, lng: 126.9780 }
3. 이 좌표로 지도에 마커를 찍는다.

직접 구현하기보다 지오코딩 서비스(구글·네이버·카카오·국가 주소 API 등)를 쓰는 것이 일반적입니다.

 

실무 포인트

입력 주소가 지저분하면(오타, 지번/도로명 혼용) 매칭이 실패합니다. 자동완성·검색 UI로 정제된 주소를 받고, 모호하면 후보를 사용자에게 고르게 하세요. 반복 조회는 캐싱해 API 호출 비용을 줄입니다.

주의 — 대부분의 지오코딩 API는 호출량에 따라 과금되거나 한도가 있습니다. 같은 주소를 반복 조회한다면 결과를 캐싱하세요.
