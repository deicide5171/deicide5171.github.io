UNION과 UNION ALL 차이가 뭔가요 — 결과 합칠 때 주의점

2026. 9. 19. · 데이터베이스

한 줄 요약 — UNION은 중복을 제거하고, UNION ALL은 중복 제거 없이 그대로 합쳐 더 빠릅니다.

 

두 결과를 하나로 합치기

올해 주문과 작년 주문처럼 구조가 같은 두 결과를 세로로 이어 붙일 때 UNION을 씁니다. UNION과 UNION ALL의 차이는 중복 제거 여부입니다.

 

두 방식의 차이
-- UNION: 합친 뒤 중복 제거
SELECT name FROM customer_2025
UNION
SELECT name FROM customer_2026;

-- UNION ALL: 그대로 합침
SELECT name FROM customer_2025
UNION ALL
SELECT name FROM customer_2026;
구분 중복 속도
UNION 제거 느림(정렬·비교)
UNION ALL 그대로 빠름

UNION은 중복 제거를 위해 내부적으로 정렬·해시 비교를 하므로 데이터가 많으면 비용이 큽니다.

 

실무 포인트

두 결과가 겹칠 일이 없거나 중복이 있어도 괜찮다면 UNION ALL이 훨씬 빠릅니다. "그냥 합치기"인데 습관적으로 UNION을 쓰면 매번 불필요한 비용을 냅니다.

주의 — 두 SELECT의 컬럼 수·순서·타입이 호환돼야 합니다. 안 맞으면 에러가 납니다.
