JSON.parse와 JSON.stringify가 뭔가요 — 객체와 문자열 변환

2026. 9. 20. · 프론트엔드

한 줄 요약 — JSON.parse는 문자열 → 객체, JSON.stringify는 객체 → 문자열로 바꿉니다.

 

문자열인데 객체처럼 못 쓴다

서버 응답이나 localStorage 값은 문자열이라 data.name으로 바로 못 씁니다. 문자열→객체는 JSON.parse, 객체→문자열은 JSON.stringify입니다.

 

두 함수의 방향
// 문자열 → 객체
const obj = JSON.parse('{"name":"김","age":20}');
obj.name;              // "김"

// 객체 → 문자열
const json = JSON.stringify({ name: "김", age: 20 });
함수 방향 쓰임
JSON.parse 문자열→객체 응답·저장값 읽기
JSON.stringify 객체→문자열 전송·저장

JSON.stringify(user, null, 2)로 보기 좋게 들여쓸 수 있습니다.

 

실무 포인트

잘못된 JSON은 parse가 예외를 던지니 신뢰할 수 없는 입력은 try/catch로 감쌉니다.

주의 — stringify에서 undefined·함수·Symbol은 빠지고 Date는 문자열이 됩니다. JSON.parse(JSON.stringify(obj)) 깊은 복사도 이 때문에 완전하지 않습니다.
