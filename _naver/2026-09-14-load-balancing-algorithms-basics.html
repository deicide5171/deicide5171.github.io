부하 분산 알고리즘이 뭔가요 — 라운드 로빈부터 최소 연결까지

시스템 디자인

한 줄 요약 — 부하 분산 알고리즘은 로드 밸런서가 요청을 어느 서버로 보낼지 정하는 규칙으로, 라운드 로빈·최소 연결·IP 해시 등이 있습니다.

 

요청을 서버들에 어떻게 나누나

로드 밸런서는 요청을 여러 서버에 나눠줍니다. "어느 서버로 보낼지" 규칙이 여럿인데, 이것이 부하 분산 알고리즘입니다. 상황에 맞게 골라야 부하가 고르게 퍼집니다.

 

대표 알고리즘
알고리즘 방식
라운드 로빈 순서대로 배정
최소 연결 연결 적은 서버로
IP 해시 같은 IP는 같은 서버로

 

언제 무엇을
라운드 로빈: 서버 성능 비슷·요청 균일
최소 연결:   처리 시간이 제각각일 때
IP 해시:     같은 사용자를 같은 서버로(세션)

 

실무 포인트

서버 성능이 비슷하면 라운드 로빈이 무난합니다. 요청 처리 시간이 들쭉날쭉하면 최소 연결이 낫습니다. 로그인 세션이 특정 서버 메모리에 있으면 IP 해시/스티키 세션을 쓰세요.

주의 — 세션을 Redis 등 외부에 두면 스티키 세션 제약이 사라져 어떤 알고리즘이든 자유롭게 쓸 수 있습니다.
