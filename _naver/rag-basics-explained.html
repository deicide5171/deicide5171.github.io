RAG가 뭔가요 — 검색 증강 생성 개념을 처음부터 이해하기

2026. 9. 1. · AI

한 줄 요약 — RAG는 LLM을 재학습시키지 않고 질문에 맞는 문서를 찾아 함께 제공해 답변 정확도를 높이는 기법입니다.

 

왜 LLM에게 그냥 물어보면 안 되는가

LLM은 학습 시점까지의 데이터로만 답을 만듭니다. 최신 정보나 회사 내부 문서처럼 학습 데이터에 없는 내용을 물으면 그럴듯하지만 틀린 답(환각)을 만들어냅니다. RAG는 모델을 재학습시키는 대신 답할 때 필요한 문서를 찾아 같이 보여주는 방식으로 이를 해결합니다.

 

RAG의 기본 흐름
단계 하는 일
1. 색인 문서를 청킹해 임베딩 후 벡터 DB에 저장
2. 검색 질문과 가장 관련 있는 문서를 벡터 DB에서 검색
3. 증강 찾은 문서를 프롬프트에 함께 넣음
4. 생성 LLM이 문서를 참고해 답변 생성

 

예제 — 단순한 RAG 흐름
def answer_with_rag(question, vector_db, llm_client):
    relevant_docs = vector_db.search(question, top_k=3)
    context = "\n\n".join(doc.text for doc in relevant_docs)
    prompt = f"""다음 문서를 참고해서 답해줘. 없으면 모른다고 답해.

문서: {context}
질문: {question}"""
    return llm_client.generate(prompt)

"문서에 없으면 모른다고 답해"라는 지시가 실무에서 환각을 줄이는 가장 기본적인 방법입니다.

 

실무 포인트

RAG는 파인튜닝의 대체재가 아니라 다른 문제를 푸는 도구입니다. 최신 정보·사내 문서 검색에는 RAG가, 말투를 바꾸는 데는 파인튜닝이 더 적합합니다.

주의 — 검색 품질이 나쁘면 아무리 좋은 LLM을 붙여도 답이 부정확합니다. 문제가 생기면 먼저 "검색된 문서가 실제로 관련 있는가"부터 확인하세요.
