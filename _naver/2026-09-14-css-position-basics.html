CSS position이 뭔가요 — relative, absolute 헷갈림 정리

프론트엔드

한 줄 요약 — position은 요소의 배치 기준과 top/left 적용 여부를 정하며, relative 부모 + absolute 자식이 겹치기 정석입니다.

 

top, left가 안 먹는다

top·left로 옮기려는데 꿈쩍 안 하는 건 position 때문입니다. position은 요소가 어떤 기준으로 배치되고 위치 값이 먹히는지를 정합니다.

 

position 값
값 설명
static 기본, 위치값 무시
relative 원래 자리 기준 이동
absolute 위치 지정 조상 기준
fixed / sticky 화면 고정 / 스크롤 고정

 

핵심 관계
absolute 요소는 "가장 가까운 position이
static이 아닌 조상" 기준으로 배치
-> 부모: position: relative
   자식: position: absolute (흔한 패턴)

 

실무 포인트

위치값이 안 먹으면 position이 static일 가능성이 큽니다. 배지·툴팁·닫기 버튼 겹치기엔 relative 부모 + absolute 자식이 정석입니다. 상단바엔 fixed, 붙는 메뉴엔 sticky를 씁니다.

주의 — sticky는 부모 영역을 벗어나면 다시 흐릅니다. 고정하려는 범위와 부모 영역을 맞추세요.
