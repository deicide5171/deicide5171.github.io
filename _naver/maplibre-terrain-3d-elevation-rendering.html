MapLibre GL JS Terrain — 표고 데이터(DEM)로 3D 지형 렌더링하기

GIS

한 줄 요약 — Terrain-RGB 타일의 고도 값을 GPU 셰이더에서 메시 정점 Z좌표로 변형해 3D 지형을 만드는 MapLibre Terrain의 원리를 정리했습니다.

 

왜 지금 MapLibre Terrain을 알아야 하는가

등산로 지도, 재난 대응, 드론 경로 계획처럼 지형 자체가 핵심 정보인 서비스에서는 등고선만으로는 직관성이 떨어집니다. MapLibre GL JS는 terrain 소스로 표고 데이터를 실제 3D 메시로 변형해 렌더링합니다. 결과물 품질을 제어하려면 인코딩 방식과 변형 과정을 이해해야 합니다.

 

 

Terrain-RGB 타일: 표고 값을 이미지 픽셀로 인코딩하기

지형 서비스는 표고 값을 일반 PNG 이미지의 RGB 채널에 인코딩한 Terrain-RGB 타일을 씁니다. 정해진 공식으로 픽셀 값을 조합해 정밀한 고도를 복원합니다. 지형 데이터가 그냥 PNG이므로 기존 CDN·캐싱 인프라를 그대로 재사용할 수 있습니다.

 

GPU에서 평면 타일이 3D 메시로 변형되는 과정

MapLibre는 격자 메시를 미리 준비해두고, 디코딩한 고도 값을 버텍스 셰이더 단계에서 정점의 Z좌표로 대입합니다. 벡터·위성 레이어는 이 지형 메시 위에 드레이핑돼 자연스럽게 씌워집니다. 카메라를 기울이면(pitch) 입체감이 드러납니다.

항목 설명
Terrain-RGB 타일 표고를 PNG RGB로 인코딩
exaggeration 고도 시각적 과장 배율
hillshade 경사면에 음영을 넣는 레이어

 

예제 — Terrain 소스 설정과 exaggeration 적용
map.addSource('terrain-dem', {
  type: 'raster-dem',
  tiles: ['https://example.com/terrain-rgb/{z}/{x}/{y}.png'],
  tileSize: 256,
  maxzoom: 14,
});

map.setTerrain({
  source: 'terrain-dem',
  exaggeration: 1.5,
});

map.addLayer({
  id: 'hillshade',
  type: 'hillshade',
  source: 'terrain-dem',
  paint: { 'hillshade-exaggeration': 0.5 },
});

map.easeTo({ pitch: 60, bearing: -20 });

 

실무 포인트

exaggeration을 지역 특성에 맞게 조정하세요. 평지에서는 기본값으로 굴곡이 거의 안 보이지만, 산악 지형에서 과도하게 높이면 비현실적으로 보입니다.

지형 타일의 해상도와 maxzoom을 실제 필요 수준으로 제한하세요. 특정 줌 이상에서는 해상도 향상 없이 타일 요청만 늘어날 수 있습니다.

주의 — 모바일 기기에서는 지형 렌더링 성능을 별도로 테스트하세요. 3D 메시 변형과 hillshade 조합은 저사양 GPU에서 프레임 드롭을 유발할 수 있습니다.
