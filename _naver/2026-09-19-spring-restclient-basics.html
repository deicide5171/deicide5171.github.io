스프링 RestClient가 뭔가요 — 외부 API 호출 시작하기

2026. 9. 19. · 백엔드

한 줄 요약 — RestClient는 스프링 6.1+에서 권장되는 동기식 HTTP 클라이언트로, 체이닝으로 요청을 구성합니다.

 

다른 서버 API를 호출하고 싶다

결제 게이트웨이·외부 데이터 API처럼 내 앱이 다른 서버에 HTTP 요청을 보내야 할 때 씁니다. RestClient는 기존 RestTemplate을 대체하는 현대적 API입니다.

 

기본 사용법
RestClient client = RestClient.create();

User user = client.get()
    .uri("https://api.example.com/users/{id}", 1)
    .retrieve()
    .body(User.class);

get()·post()로 시작해 uri → body → retrieve → 결과 변환으로 이어집니다.

 

RestTemplate과의 관계
클라이언트 상태
RestTemplate 동작하나 유지보수 모드
RestClient 동기 호출 권장(6.1+)
WebClient 비동기·리액티브용

 

실무 포인트

retrieve()는 4xx·5xx에서 예외를 던지니 onStatus로 상태별 처리를 붙입니다. 빈으로 등록해 타임아웃·기본 헤더를 공통 설정하세요.

주의 — 타임아웃을 꼭 설정하세요. 외부 API가 느리면 내 스레드가 묶여 장애가 전파됩니다.
