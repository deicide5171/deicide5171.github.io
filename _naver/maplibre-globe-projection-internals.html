MapLibre GL JS Globe 투영 내부 동작 — 같은 타일로 평면과 구를 모두 그리는 법

GIS

한 줄 요약 — Globe 투영은 완전히 새로운 렌더 엔진이 아니라, 기존 벡터 타일 파이프라인 위에서 정점 셰이더의 투영 행렬만 바꿔치기하는 방식으로 구현됐습니다.

 

왜 지구본 모드가 다시 주목받는가

전 세계 데이터를 다루는 시각화에서는 평면 머케이터 투영의 근본적인 문제가 두드러집니다. 극지방으로 갈수록 면적이 극단적으로 부풀려지고 대권 항로가 부자연스럽게 휘어 보입니다. MapLibre GL JS는 projection: 'globe' 설정 하나로 이를 활성화할 수 있게 했습니다.

 

타일 데이터는 그대로, 투영 행렬만 바뀐다

평면 모드에서는 정점 셰이더의 투영이 단순한 2D 아핀 변환이었다면, Globe 모드에서는 정규화된 좌표를 구면 좌표로 다시 매핑하는 연산이 들어갑니다. 타일을 가져오고 파싱하는 앞단 파이프라인은 완전히 동일하며, 같은 스타일과 CustomLayer가 두 모드 모두에서 그대로 동작합니다.

 

줌 레벨에 따른 평면-구면 보간

줌 레벨이 깊어지면 지구본의 곡률이 시각적으로 감지하기 어려워집니다. MapLibre는 특정 임계값 근처에서 두 투영 방식을 부드럽게 보간해 전환하므로, 사용자는 전환을 눈치채지 못하고 고줌에서는 평면 투영과 동일한 성능을 유지합니다.

항목 평면 투영 Globe 투영
타일 데이터 동일 동일(재사용)
극지방 왜곡 심함 없음

 

Globe 투영 활성화와 대권 항로 예제
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://demotiles.maplibre.org/style.json',
  center: [0, 20],
  zoom: 1.5,
  projection: 'globe',
});

map.on('load', () => {
  map.addSource('flight-route', {
    type: 'geojson',
    data: turf.greatCircle([126.9, 37.5], [-122.4, 37.7]),
  });
  map.addLayer({
    id: 'flight-route-layer',
    type: 'line',
    source: 'flight-route',
    paint: { 'line-color': '#e0952b', 'line-width': 2 },
  });
});

 

실무 포인트

CustomLayerInterface와의 호환성을 확인하세요. 커스텀 WebGL 레이어가 좌표 변환을 하드코딩했다면 Globe 모드에서 좌표가 어긋날 수 있습니다.

극지방 근처 데이터 시각화에 특히 유용합니다. 항로, 해류, 극궤도 위성 경로처럼 고위도 지역을 다루는 시각화에서 우선순위가 가장 높습니다.

주의 — 구면 좌표 변환은 저사양 모바일 기기에서 프레임 드랍을 유발할 수 있으므로, 저줌 오버뷰에서만 Globe를 쓰고 콘텐츠 탐색은 평면 투영으로 유도하는 UX가 안전합니다.
