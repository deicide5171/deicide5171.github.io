querySelector가 뭔가요 — 자바스크립트로 HTML 요소 찾기

프론트엔드

한 줄 요약 — querySelector는 CSS 선택자로 HTML 요소를 찾는 메서드로, 하나는 querySelector·여러 개는 querySelectorAll입니다.

 

HTML 요소를 코드로 어떻게 집나

버튼 클릭에 반응하거나 텍스트를 바꾸려면 그 요소를 JS로 "찾아야" 합니다. querySelector는 CSS 선택자로 요소를 찾습니다. 스타일 줄 때 쓰던 선택자를 그대로 씁니다.

 

기본 사용
document.querySelector('.title');   // class
document.querySelector('#box');     // id
document.querySelectorAll('.item')  // 전부(NodeList)
  .forEach(el => el.classList.add('active'));

 

querySelector vs All
메서드 반환
querySelector 첫 매칭 1개(없으면 null)
querySelectorAll 전부(NodeList)

 

실무 포인트

없으면 null이라 바로 조작하면 오류가 나니 확인하거나 ?.를 쓰세요. 스크립트가 HTML보다 먼저 실행되면 못 찾으니 defer나 DOMContentLoaded 이후에 실행합니다.

주의 — 같은 요소를 반복해서 querySelector로 찾으면 비효율적입니다. 한 번 찾아 변수에 담아 재사용하세요.
