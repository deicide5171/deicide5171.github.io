NoSQL이 뭔가요 — SQL과 무엇이 다른지 기초부터

2026. 9. 2. · 데이터베이스

한 줄 요약 — NoSQL은 SQL을 안 쓴다는 뜻이 아니라, 고정된 테이블 구조에 얽매이지 않는 다양한 데이터베이스를 통칭하는 말입니다.

 

왜 "SQL을 안 쓴다"는 이름이 붙었나

NoSQL은 원래 "No SQL"이라는 뜻으로 시작했지만, 지금은 "Not Only SQL"로 이해됩니다. 관계형 DB처럼 고정된 테이블 구조와 SQL 질의어에 얽매이지 않고, 데이터 성격에 맞는 다양한 저장 구조를 쓰는 DB들을 통칭합니다.

 

근본적인 차이
항목 관계형 DB NoSQL
스키마 고정 유연하거나 없음
관계 표현 JOIN 문서에 함께 내장
대표 예시 MySQL, PostgreSQL MongoDB, Redis, Cassandra

 

같은 데이터, 다른 표현 방식
-- 관계형 DB
SELECT u.name, o.item FROM users u
JOIN orders o ON u.id = o.user_id;

// NoSQL 문서형
{ "name": "김철수", "orders": [{"item": "노트북"}] }

관계형 DB는 정규화를 지향하지만, NoSQL 문서형은 자주 함께 조회하는 데이터를 미리 합쳐 넣는(비정규화) 경향이 있습니다.

 

실무 포인트

NoSQL이 관계형 DB보다 무조건 빠르거나 뛰어난 것은 아닙니다. 강한 일관성과 복잡한 JOIN이 필요하면 여전히 관계형 DB가 적합합니다.

주의 — NoSQL은 문서형·키값형·와이드컬럼형·그래프형이 각각 성격이 완전히 다릅니다. "NoSQL 하나"로 뭉뚱그려 비교하는 것은 의미가 없습니다.
