자바 제네릭이 뭔가요 — 타입을 매개변수로 다루기

백엔드

한 줄 요약 — 제네릭은 다룰 타입을 밖에서 지정하게 해 캐스팅을 줄이고 잘못된 타입을 컴파일 시점에 차단합니다.

 

List<String>의 꺾쇠 안은?

List<String>처럼 꺾쇠 안에 타입을 적는 것이 제네릭입니다. 클래스·메서드가 다룰 타입을 매개변수처럼 밖에서 지정해 타입 안전성과 재사용성을 얻습니다.

 

제네릭이 없으면
// 없이: 캐스팅 필요, 실수 위험
List list = new ArrayList();
String s = (String) list.get(0);

// 제네릭: 안전
List<String> list = new ArrayList<>();
String s = list.get(0);   // 캐스팅 불필요
list.add(123);            // 컴파일 에러로 차단

 

직접 정의하기
class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}
Box<Integer> box = new Box<>();

T는 "나중에 정할 타입"의 자리표시자입니다.

 

실무 포인트

잘못된 타입은 실행 전 컴파일 에러로 걸러져 런타임 ClassCastException을 예방합니다. T·E·K·V 같은 관용 이름을 씁니다.

주의 — List<? extends Number> 같은 와일드카드는 유연한 API용입니다. 처음엔 기본 형태부터 익히세요.
