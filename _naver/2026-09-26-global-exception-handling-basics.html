전역 예외 처리 입문 — @RestControllerAdvice로 에러 응답 통일하기

백엔드

한 줄 요약 — @RestControllerAdvice는 전역 예외를 한곳에서 잡아 에러 응답을 통일하며, @ExceptionHandler로 예외별 상태코드를 정합니다.

 

컨트롤러마다 try-catch를 반복해야 하나

API마다 예외를 잡아 에러 응답을 만들면 비슷한 try-catch가 반복되고 형식도 제각각이 됩니다. @RestControllerAdvice는 전역 예외를 한곳에서 잡아 일관된 에러 응답으로 바꿔줍니다.

 

동작 개념
없을 때 있을 때
try-catch 반복 한곳에 모음
응답 형식 제각각 형식 통일

 

예제
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(UserNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(UserNotFoundException e) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
            .body(new ErrorResponse("USER_NOT_FOUND", e.getMessage()));
    }
}

 

실무 포인트

{ code, message } 같은 일관된 형식을 정하면 프론트가 다루기 쉽습니다. 예상 예외는 알맞은 4xx로, 예상 밖은 500으로 처리하고 로그로 추적하세요.

주의 — 스택 트레이스나 SQL 오류 원문을 응답에 그대로 담으면 보안에 취약합니다. 사용자에겐 일반 메시지, 상세는 서버 로그에만 남기세요.
