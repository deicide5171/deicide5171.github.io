ResponseEntity가 뭔가요 — 상태코드·헤더까지 직접 정하기

2026. 9. 18. · 백엔드

한 줄 요약 — ResponseEntity는 응답의 본문·상태코드·헤더를 모두 담아 반환해, 상황에 맞는 응답을 만듭니다.

 

응답 본문만 반환하면 부족할 때

객체를 반환하면 스프링이 JSON+200으로 응답합니다. 그런데 "생성됐으면 201, 없으면 404" 같은 상태코드나 헤더를 정하고 싶을 때가 있죠. ResponseEntity는 본문·상태코드·헤더를 모두 담아 반환합니다.

 

사용법
if (user == null)
    return ResponseEntity.notFound().build(); // 404
return ResponseEntity.ok(user);               // 200

return ResponseEntity.status(HttpStatus.CREATED).body(saved); // 201

 

무엇을 담나
요소 예
상태코드 200·201·404·400
헤더 Location 등

 

실무 포인트

조회 200·생성 201·없으면 404처럼 의미에 맞는 상태코드를 주세요. 생성 시 Location 헤더에 새 리소스 URL을 담는 게 REST 관례입니다. 단순 API는 객체를 그대로 반환해도 됩니다.

주의 — 무조건 200을 주면 클라이언트가 결과를 정확히 판단하기 어렵습니다. 상황에 맞는 상태코드를 반환하세요.
