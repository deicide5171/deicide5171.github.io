리눅스 서버 처음 접속했을 때 확인해야 할 것들 — SSH 기초 체크리스트

2026. 9. 1. · 인프라

한 줄 요약 — 배포보다 먼저 시스템 상태·열린 포트를 확인하고, 비밀번호 로그인 비활성화는 키 인증 확인 후에 적용해야 안전합니다.

 

왜 바로 작업을 시작하면 안 되는가

새 서버를 받으면 바로 배포부터 시작하고 싶지만, 기본 상태와 보안 설정을 먼저 확인하지 않으면 나중에 더 큰 문제로 돌아옵니다. 클라우드 서버는 기본 설정이 보안상 최소한만 되어 있는 경우가 많습니다.

 

접속 직후 확인 체크리스트
항목 확인 명령
디스크 여유 공간 df -h
열린 포트 ss -tulnp
방화벽 상태 ufw status

 

최우선 보안 설정
# /etc/ssh/sshd_config
# PermitRootLogin no
# PasswordAuthentication no

sudo systemctl restart sshd

sudo ufw allow 2222/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

PasswordAuthentication no로 바꾸기 전에 반드시 키 인증으로 접속되는지 먼저 확인해야 합니다. 확인 없이 바꾸면 서버에서 완전히 잠길 수 있습니다.

 

실무 포인트

sudo 없이 root로 상시 작업하는 습관은 피해야 합니다. 일반 계정을 만들고 sudo 그룹에 추가하세요.

주의 — 클라우드 서버는 서버 내부 방화벽과 클라우드 보안 그룹이 이중으로 걸려 있을 수 있습니다. 서버 안에서만 원인을 찾다가 시간을 낭비하지 마세요.
