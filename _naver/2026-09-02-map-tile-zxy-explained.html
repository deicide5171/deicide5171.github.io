지도 타일 z/x/y가 뭔가요 — 타일 좌표 체계 이해하기

2026. 9. 2. · GIS

한 줄 요약 — z는 줌 레벨, x·y는 그 레벨에서의 가로·세로 타일 인덱스이며, 줌이 1 올라갈 때마다 타일 개수는 4배로 늘어납니다.

 

타일 URL에 있는 그 숫자 세 개

웹 지도를 다뤄보면 /{z}/{x}/{y}.png 같은 URL 패턴을 항상 만납니다. 이 세 숫자를 모르면 왜 지도가 안 보이는지, 왜 엉뚱한 지역이 나오는지 디버깅할 수 없습니다.

 

 

z, x, y의 의미
값 의미 범위
z 줌 레벨(클수록 확대) 보통 0~22
x 가로 타일 인덱스 0 ~ 2^z - 1
y 세로 타일 인덱스 0 ~ 2^z - 1 
z=0: 1개 (지구 전체가 한 장)
z=1: 4개, z=2: 16개
z=10: 약 100만 개
z=18: 약 687억 개

 

예제 — 위경도를 타일 좌표로 변환
function lonLatToTile(lon, lat, zoom) {
  const n = Math.pow(2, zoom);
  const x = Math.floor((lon + 180) / 360 * n);
  const latRad = lat * Math.PI / 180;
  const y = Math.floor(
    (1 - Math.log(Math.tan(latRad) + 1 / Math.cos(latRad)) / Math.PI) / 2 * n
  );
  return { z: zoom, x, y };
}

이 변환식은 웹 메르카토르(EPSG:3857) 투영법을 전제로 하며, 대부분의 웹 지도가 이를 쓰기 때문에 사실상 표준입니다.

 

실무 포인트

같은 z/x/y는 항상 같은 이미지이므로 CDN에서 장기 캐싱하기 좋은 구조입니다. 데이터 갱신 시에는 URL에 버전을 붙여 무효화합니다.
