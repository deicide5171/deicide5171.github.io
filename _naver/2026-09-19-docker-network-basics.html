도커 네트워크가 뭔가요 — 컨테이너끼리 통신하기

인프라

한 줄 요약 — 같은 사용자 정의 네트워크에 넣으면 컨테이너 이름으로 서로를 찾아 통신합니다.

 

DB 컨테이너에 연결이 안 된다

앱과 DB를 각각 컨테이너로 띄웠는데 localhost:5432로는 안 붙습니다. 컨테이너마다 격리된 네트워크라, 한 컨테이너의 localhost는 다른 컨테이너가 아닙니다. 이때 도커 네트워크가 필요합니다.

 

같은 네트워크에 묶기
docker network create myapp-net
docker run --network myapp-net --name db postgres
docker run --network myapp-net --name app myapp

# app에서 DB 주소는 "db"
#   → postgres://db:5432

같은 사용자 정의 bridge 네트워크에 있으면 컨테이너 이름이 곧 호스트명이 됩니다.

 

네트워크 종류
종류 특징
bridge 기본. 같은 호스트 안 통신
host 호스트 네트워크 공유(격리 없음)
none 네트워크 없음(완전 격리)

 

실무 포인트

앱 설정에서 DB 주소를 localhost가 아니라 컨테이너 이름(db)으로 적습니다. compose로 여러 서비스를 정의하면 자동으로 한 네트워크에 묶여 서비스 이름으로 통신됩니다.

주의 — 기본 bridge에서는 이름으로 서로를 못 찾습니다. docker network create로 만든 네트워크에 함께 넣으세요.
