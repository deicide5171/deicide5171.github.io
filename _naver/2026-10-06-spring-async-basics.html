@Async 입문 — 스프링에서 오래 걸리는 작업 비동기로 돌리기

백엔드

한 줄 요약 — @Async는 메서드를 별도 스레드에서 비동기 실행해, 이메일·알림 같은 오래 걸리는 작업을 응답과 분리합니다.

 

이메일 보내느라 응답이 느려진다

가입 후 환영 이메일에 3초 걸리면 사용자는 그동안 멈춘 화면을 봅니다. 이메일 발송은 백그라운드에서 처리하면 되죠. @Async는 메서드를 별도 스레드에서 실행해, 호출한 쪽이 기다리지 않고 넘어가게 합니다.

 

동기 vs 비동기
[동기]  가입 -> 이메일(3초 대기) -> 응답 (총 3초+)
[비동기] 가입 -> 응답(즉시)
             \-> 이메일은 백그라운드에서 따로

 

사용법
@EnableAsync   // 설정 클래스에 한 번

@Service
public class MailService {
    @Async
    public void sendWelcome(String email) { ... }
}

 

실무 포인트

같은 클래스 내부 호출은 프록시를 안 거쳐 비동기가 적용되지 않습니다(다른 빈을 통해 호출). 기본 스레드 설정 대신 TaskExecutor로 전용 스레드 풀을 정해 폭주를 막으세요.

주의 — 비동기 메서드의 예외는 호출한 쪽으로 전달되지 않습니다. 내부에서 잡아 로그를 남기거나 CompletableFuture로 처리하세요.
