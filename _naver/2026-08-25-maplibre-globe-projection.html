평평한 지도가 둥글게 — MapLibre GL JS 지구본(Globe) 투영 모드 실전

2026. 8. 25. · GIS

한 줄 요약 — MapLibre GL JS의 globe 투영 모드는 기존 메르카토르 타일 데이터를 그대로 두고 GPU 셰이더에서 구면 좌표로 재투영해, 낮은 줌에서는 지구본처럼 보이고 줌인하면 익숙한 평면 지도로 자연스럽게 전환됩니다.

 

그린란드가 아프리카만큼 커 보이는 이유

메르카토르 도법으로 그린 세계 지도에서 그린란드가 아프리카만큼 커 보이는 착시는 웹 지도를 다뤄본 분이라면 한 번쯤 마주쳤을 문제입니다. 위도가 극에 가까워질수록 면적이 왜곡되는 것은 평면에 구를 펼치는 투영법의 근본적인 한계입니다. 줌인해서 도시 단위를 볼 때는 문제가 크지 않지만, 전 세계 항공편 경로나 글로벌 물류망처럼 지구 전체를 한눈에 보여줘야 하는 화면에서는 왜곡이 그대로 잘못된 인상을 남깁니다.

MapLibre GL JS는 이 문제를 해결하기 위해 globe 투영 모드를 도입했습니다. 낮은 줌 레벨에서는 실제로 구체 형태로 지구를 렌더링하고, 사용자가 줌인하면 매끄럽게 익숙한 평면 메르카토르 지도로 전환됩니다.

 

핵심 개념 1 — 평면 타일 위에 구를 렌더링한다는 것

MapLibre의 벡터 타일 시스템은 원래 메르카토르 좌표계를 전제로 설계됐습니다. globe 모드는 이 타일 데이터 자체를 바꾸는 것이 아니라, 동일한 메르카토르 타일 데이터를 GPU 셰이더 단계에서 구면 좌표로 재투영해서 그립니다. 정점 셰이더에서 평면 메르카토르 좌표를 위도·경도로 역산한 뒤 다시 3차원 구면 좌표로 변환해 카메라에 투영하는 방식이라, 서버 쪽 타일 파이프라인은 전혀 손댈 필요가 없습니다.

 

핵심 개념 2 — 줌 레벨에 따른 자동 전환

지구본을 멀리서 보다가 특정 지역을 줌인하면, 그 지역은 지구 표면의 극히 일부만 차지하게 되므로 구면 곡률의 시각적 영향이 사실상 사라집니다. MapLibre는 이 성질을 이용해 특정 줌 레벨 임계값(대략 줌 5 부근)을 기준으로 구체 투영과 평면 메르카토르 투영을 부드럽게 블렌딩합니다.

 

핵심 개념 3 — 메르카토르 대비 무엇이 달라질까요
구분 평면 메르카토르 Globe 모드
고위도 면적 왜곡 심함 없음
낮은 줌 전체 조망 좌우 반복되는 평면 하나의 구체로 표현
타일 데이터/스타일 표준 동일(변경 불필요)
GPU 렌더링 부하 낮음 다소 증가

 

예제 — MapLibre GL JS에서 globe 투영 활성화
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://demotiles.maplibre.org/style.json',
  center: [127.5, 36.5],
  zoom: 2,
  projection: 'globe', // 'mercator'(기본값) 대신 globe 지정
});

// 런타임에 투영 모드 전환
map.on('load', () => {
  document.getElementById('toggle-projection').addEventListener('click', () => {
    const current = map.getProjection().type;
    map.setProjection({ type: current === 'globe' ? 'mercator' : 'globe' });
  });
});

 

실무 도입 시 이것만은 챙기세요
1. 저사양 기기에서의 성능을 반드시 확인하세요 — 구면 재투영 셰이더는 모바일 GPU에서 프레임 드랍을 유발할 수 있습니다.
2. 커스텀 레이어와의 좌표 정합을 검증하세요 — deck.gl, threebox 같은 커스텀 WebGL 레이어가 평면 좌표를 가정하고 있으면 위치가 어긋날 수 있습니다.
3. 애니메이션 전환 중 사용자 조작을 막지 마세요 — 줌 임계값 부근에서 투영이 자동 전환될 때도 팬/줌 제스처가 정상 동작해야 합니다.

 

마무리 — 3줄 요약

① MapLibre의 globe 모드는 타일 데이터를 바꾸지 않고 GPU 셰이더에서 구면 좌표로 재투영해 지구본 렌더링을 구현합니다.
② 낮은 줌에서는 구체로, 높은 줌에서는 평면 메르카토르로 자연스럽게 전환됩니다.
③ 전 지구적 시각화에는 효과가 크지만 도시 단위 서비스에는 이점이 적으니 서비스 성격에 맞춰 선택적으로 적용하세요.
