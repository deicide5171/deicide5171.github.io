setTimeout과 setInterval이 뭔가요 — 자바스크립트 타이머

2026. 9. 17. · 프론트엔드

한 줄 요약 — setTimeout은 일정 시간 뒤 한 번, setInterval은 간격마다 반복 실행하며, 반환 id로 반드시 취소해야 합니다.

 

"3초 뒤에", "1초마다" 실행하려면

알림을 3초 뒤 닫거나 1초마다 시계를 갱신하는 동작이 필요하죠. JS는 setTimeout(정해진 시간 뒤 한 번)과 setInterval(간격마다 반복)로 이를 합니다.

 

사용법
const t = setTimeout(() => {...}, 3000); // 3초 뒤 한 번
clearTimeout(t);                          // 취소
const i = setInterval(() => {...}, 1000); // 1초마다
clearInterval(i);                         // 멈춤
// 시간 단위는 ms (1000ms = 1초)

 

실무 포인트

setInterval을 걸고 안 멈추면 메모리 누수가 납니다. React라면 useEffect cleanup에서 clearInterval을 호출하세요. setTimeout(fn, 1000)은 "정확히 1초"가 아니라 "최소 1초 후"입니다.

주의 — 작업이 오래 걸리면 setInterval은 겹칠 수 있습니다. 이전 작업이 끝난 뒤 다음을 예약하는 재귀 setTimeout이 더 안전할 때가 있습니다.
