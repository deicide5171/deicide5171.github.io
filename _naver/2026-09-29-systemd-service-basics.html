systemd 서비스가 뭔가요 — 프로그램을 서버 부팅 시 자동 실행하기

인프라

한 줄 요약 — systemd 서비스는 프로그램을 부팅 시 자동 실행하고 죽으면 재시작하며 로그를 관리합니다.

 

터미널을 닫으면 프로그램도 꺼진다

python app.py로 실행하면 SSH를 끊거나 서버가 재부팅되면 프로그램도 꺼집니다. 항상 떠 있고, 죽으면 살아나고, 부팅 시 자동 시작되게 하려면 서비스로 등록해야 합니다. 리눅스에선 systemd가 이 역할을 합니다.

 

할 수 있는 것
기능 설명
자동 시작 부팅 시 실행
자동 재시작 죽으면 다시 실행
로그 journalctl로 조회

 

서비스 파일과 명령
# /etc/systemd/system/myapp.service
[Service]
ExecStart=/usr/bin/python3 /home/user/app.py
Restart=always

sudo systemctl enable myapp   # 부팅 자동
sudo systemctl start myapp    # 지금 시작
journalctl -u myapp -f        # 로그 실시간

 

실무 포인트

start는 지금 실행, enable은 부팅 자동입니다(둘 다 해야 함). Restart=always/on-failure로 재시작 정책을 정하고 RestartSec으로 폭주를 막으세요. 로그는 journalctl로 봅니다.

주의 — 컨테이너 환경에선 systemd 대신 오케스트레이터(쿠버네티스 등)가 자동 시작·재시작 역할을 합니다.
