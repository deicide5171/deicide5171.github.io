Claude API 처음 써보기 — 메시지·스트리밍·도구 호출 5분 만에 끝내기

2026. 8. 31. · AI

한 줄 요약 — Claude API는 system 파라미터 분리와 max_tokens 필수 지정이 OpenAI와 다르며, 스트리밍은 전용 컨텍스트 매니저로 처리합니다.

 

왜 지금 Claude API인가

사내 챗봇이든 사이드 프로젝트든 "일단 LLM API 하나 붙여보자"는 순간이 옵니다. 공식 문서는 개념 설명 위주라 처음 붙이는 사람은 어디서 시작해야 할지 막막합니다. 이 글은 API 키 발급 이후 단계, 즉 첫 메시지 호출부터 스트리밍, 도구 호출까지 실제로 코드를 돌려보는 순서로만 정리했습니다.

Claude API는 OpenAI Chat Completions와 구조는 비슷하지만 이름과 파라미터가 몇 군데 다릅니다. 이 차이를 먼저 알면 삽질을 크게 줄일 수 있습니다.

 

핵심 개념 3가지
개념 설명
Messages API role(user/assistant)과 content 배열을 주고받는 단일 엔드포인트
system 파라미터 메시지 배열이 아니라 최상위 파라미터로 분리
max_tokens 필수 지정하지 않으면 요청 자체가 실패한다

 

예제 1 — 첫 메시지 호출
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    system="너는 친절한 한국어 코딩 도우미야.",
    messages=[
        {"role": "user", "content": "파이썬으로 피보나치 수열 함수를 짜줘"}
    ],
)

print(response.content[0].text)

 

예제 2 — 스트리밍과 도구 호출

응답이 길어질수록 스트리밍이 체감 지연을 크게 줄여줍니다. stop_reason이 tool_use면 모델이 도구 호출을 원한다는 뜻이므로, 실제 함수를 실행한 뒤 결과를 다시 대화에 넣어야 합니다.

with client.messages.stream(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "서울 날씨 알려줘"}],
    tools=[{
        "name": "get_weather",
        "description": "도시 이름으로 현재 날씨를 조회한다",
        "input_schema": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"],
        },
    }],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
    final = stream.get_final_message()
    if final.stop_reason == "tool_use":
        print("\n도구 호출 발생")

 

실무 포인트

요금은 입력·출력 토큰이 따로 과금됩니다. 긴 시스템 프롬프트를 반복 호출한다면 프롬프트 캐싱을 검토하세요.

max_tokens를 너무 낮게 잡으면 답변이 중간에 잘립니다. 프로덕션에서는 429·529 응답에 대한 지수 백오프 재시도를 반드시 넣어야 합니다.

주의 — API 키를 프론트엔드 코드에 그대로 넣으면 유출됩니다. 반드시 백엔드를 경유해 호출하세요.
