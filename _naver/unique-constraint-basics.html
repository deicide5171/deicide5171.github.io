UNIQUE 제약이 뭔가요 — 중복 값을 DB가 막게 하기

2026. 9. 12. · 데이터베이스

한 줄 요약 — UNIQUE 제약은 특정 컬럼(조합)에 중복 값이 들어가지 못하게 DB가 직접 막는 최종 방어선입니다.

 

앱에서만 중복을 막으면 위험하다

"이미 가입된 이메일인지"를 앱 조회로 확인한 뒤 저장하면, 조회와 저장 사이 동시 요청이 끼어 같은 이메일이 두 번 저장될 수 있습니다. UNIQUE 제약은 이런 중복을 DB가 직접 막습니다.

 

무엇을 하나
상황 UNIQUE 없을 때 있을 때
중복 저장 둘 다 들어감 두 번째 거부

 

설정하기
CREATE TABLE users (
    id BIGINT PRIMARY KEY,
    email VARCHAR(255) UNIQUE
);
-- 복합 UNIQUE: 한 학생이 같은 과목 두 번 신청 방지
ALTER TABLE enrollments
  ADD CONSTRAINT uq UNIQUE (student_id, course_id);

 

실무 포인트

앱 검사(친절한 메시지)와 DB 제약(최종 방어선)을 함께 쓰세요. 대부분 DB에서 UNIQUE 컬럼의 NULL 여러 개는 허용됩니다. 위반 오류를 잡아 "이미 사용 중인 이메일입니다"로 바꿔 안내하세요.

주의 — NULL 중복 허용 정책은 DB마다 다를 수 있으니 확인하세요. 위반 오류를 처리하지 않으면 사용자에게 원문 예외가 노출됩니다.
