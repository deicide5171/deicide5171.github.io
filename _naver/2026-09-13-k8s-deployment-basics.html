쿠버네티스 디플로이먼트가 뭔가요 — 파드를 원하는 개수로 유지

2026. 9. 13. · 인프라

한 줄 요약 — 디플로이먼트는 원하는 상태(파드 개수·버전)를 선언하면 쿠버네티스가 맞춰주며, 개수 유지·롤링 업데이트·롤백을 자동화합니다.

 

파드를 직접 만들면 관리가 안 된다

파드를 하나씩 직접 만들면 죽어도 아무도 다시 만들지 않고 업데이트도 수동입니다. 디플로이먼트는 "이 앱을 파드 3개로 항상 유지하라"처럼 원하는 상태를 선언하면 쿠버네티스가 맞춰주는 리소스입니다.

 

해주는 것
기능 설명
개수 유지 죽으면 자동 재생성
롤링 업데이트 무중단 새 버전 배포
롤백 이전 버전으로 되돌림

 

선언적 방식
replicas: 3      -> 파드 3개 유지
image: myapp:2.0 -> 이 버전으로
파드 하나 죽으면 -> 자동 재생성해 3개 유지
image를 2.1로 -> 롤링 업데이트로 하나씩 교체

 

실무 포인트

버전을 바꾸면 옛 파드를 하나씩 교체(롤링)해 서비스가 안 끊깁니다. 문제 시 kubectl rollout undo로 되돌리세요. HPA로 부하에 따라 파드 수를 자동 조절할 수 있습니다.

주의 — 디플로이먼트는 stateless 앱용입니다. DB처럼 각 파드가 고유 정체성·저장소를 가져야 하면 StatefulSet을 쓰세요.
