ConfigMap과 Secret이 뭔가요 — 설정을 코드 밖으로 빼기

인프라

한 줄 요약 — ConfigMap은 일반 설정값, Secret은 비밀값을 이미지 밖으로 빼 파드에 주입하며, 이미지 재빌드 없이 값을 바꿉니다.

 

설정을 이미지에 박으면 유연성이 없다

DB 주소·기능 플래그·API 키를 이미지에 넣으면 값 하나 바꾸려고 다시 빌드해야 합니다. ConfigMap과 Secret은 이런 설정값을 이미지 밖으로 빼서 파드에 주입합니다.

 

ConfigMap vs Secret
구분 ConfigMap Secret
용도 일반 설정값 비밀값
예 DB 주소·로그 레벨 API 키·비밀번호

 

어떻게 주입하나
1. 환경 변수로 주입: DB_URL, API_KEY ...
2. 파일로 마운트: /etc/config/... 경로에 파일
앱은 이미지 변경 없이 주입된 값을 읽는다

 

실무 포인트

같은 이미지를 쓰되 ConfigMap/Secret만 환경마다 다르게 두면 재빌드 없이 전환됩니다. Secret의 base64는 암호화가 아니라 인코딩이니, 저장 암호화나 외부 시크릿(Vault 등)을 쓰세요.

주의 — Secret YAML을 그대로 깃에 커밋하면 base64는 쉽게 풀려 유출됩니다. 원문을 저장소에 두지 마세요.
