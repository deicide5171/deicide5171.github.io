AI 에이전트 시대의 연결 표준, MCP(Model Context Protocol) 정리

2026. 8. 14. · AI

한 줄 요약 — AI가 외부 도구·데이터와 연결되는 방식을 표준화한 프로토콜 MCP. 왜 "AI 업계의 USB-C"라고 불리는지, 구조와 실무 주의점까지 한 번에 정리했습니다.

 

왜 지금 MCP인가

요즘 AI 활용의 중심은 "채팅"에서 "에이전트"로 옮겨가고 있습니다. 이제 AI는 답변만 생성하는 게 아니라 직접 파일을 읽고, DB를 조회하고, 외부 API를 호출하면서 일을 처리합니다.

그런데 문제가 하나 있었습니다. AI 모델마다, 도구마다 연결 코드를 전부 따로 만들어야 했다는 점입니다. 모델 N개 × 도구 M개 = N×M 통합 문제가 생긴 거죠. 새 도구 하나 붙이려면 모든 AI 앱에 맞춰 코드를 다시 짜야 했습니다.

MCP(Model Context Protocol)는 이 연결 방식을 표준화한 오픈 프로토콜입니다. 2024년 11월 Anthropic이 공개했고, 이후 OpenAI, Google 등 주요 업체들이 채택하면서 사실상의 표준이 됐습니다. 흔히 "AI 업계의 USB-C"라고 비유합니다. 어떤 기기든 USB-C 하나로 연결되듯, MCP만 지원하면 어떤 AI 앱이든 같은 도구 생태계를 쓸 수 있습니다.

 

구조는 딱 3가지: Host / Client / Server

 

구성 요소 역할 예시
Host 사용자와 만나는 AI 앱 Claude Desktop, IDE, 챗봇
Client Host 안에서 서버와 1:1 연결 유지 Host에 내장
Server 도구·데이터를 표준 방식으로 노출 GitHub 서버, DB 서버, 사내 API 래퍼

서버가 제공하는 기능은 세 종류입니다.

① Tools — AI가 호출하는 함수 (검색, 파일 쓰기, API 호출)
② Resources — AI가 읽는 읽기 전용 데이터 (파일 내용, DB 스키마)
③ Prompts — 재사용 가능한 프롬프트 템플릿

"AI가 실행하는 것(Tools)"과 "AI가 읽는 것(Resources)"을 구분한다는 게 설계의 핵심 포인트입니다. 권한 관리의 경계가 여기서 갈립니다.

 

코드로 감 잡기 — 서버가 이렇게 간단합니다

Python SDK를 쓰면 MCP 서버를 몇 줄로 만들 수 있습니다.

# weather_server.py
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("weather")

@mcp.tool()
def get_weather(city: str) -> str:
    """도시의 현재 날씨를 반환한다."""
    return f"{city}: 맑음, 27도"

if __name__ == "__main__":
    mcp.run()

이 서버를 AI 앱에 등록하면, AI는 "서울 날씨 어때?"라는 질문을 받았을 때 get_weather 함수를 스스로 찾아서 호출합니다. 함수 이름과 설명(docstring)이 곧 AI에게 전달되는 사용 설명서가 되는 셈입니다.

 

왜 중요한가 — 통합 비용이 N×M에서 N+M으로

MCP의 본질은 어댑터 패턴의 표준화입니다.

· 도구는 MCP 서버를 한 번만 구현하면 모든 AI 앱에서 쓸 수 있습니다.
· AI 앱을 바꿔도 이미 구축한 도구 생태계는 그대로 재사용됩니다. 벤더 종속이 줄어듭니다.
· 회사라면 사내 DB, 내부 API, 레거시 시스템을 MCP 서버로 한 번 감싸두면 어떤 AI 도구에서든 재사용할 수 있습니다. AI 도입의 인프라 계층이 되는 거죠.

 

도입 전 꼭 알아야 할 주의점

편리함만큼 공격 표면도 늘어납니다. 실무에서는 이것들을 챙겨야 합니다.

1. 프롬프트 인젝션 — 서버가 가져온 외부 데이터에 악성 지시문이 섞이면 AI가 명령으로 오인할 수 있음. 외부 데이터는 "데이터"로만 취급하는 설계 필요
2. 최소 권한 — 읽기로 충분한 서버에 쓰기 권한 금지
3. 승인 게이트 — 삭제·결제처럼 되돌리기 어려운 동작은 사람 확인 필수
4. 공급망 검증 — 서드파티 MCP 서버는 신뢰할 수 있는 출처만 설치
5. 감사 로그 — 어떤 도구가 언제 어떤 인자로 호출됐는지 기록

 

마무리 — 3줄 요약

① MCP는 AI 앱과 도구·데이터를 잇는 표준 프로토콜로, N×M 통합 문제를 N+M으로 바꿨다.
② 서버는 Tools(실행), Resources(읽기), Prompts(템플릿) 세 가지를 노출한다.
③ 최소 권한·승인 게이트·공급망 검증 같은 보안 설계를 반드시 함께 가져가야 한다.
