Ollama로 내 컴퓨터에서 LLM 돌리기 — 로컬 AI 첫걸음

AI

한 줄 요약 — Ollama는 명령 한 줄로 오픈 웨이트 LLM을 내려받아 요금 없이 오프라인으로 내 컴퓨터에서 실행하는 도구입니다.

 

왜 로컬에서 LLM을 돌리나

클라우드 API는 편하지만 요금이 들고 데이터가 외부로 나갑니다. 민감한 문서를 다루거나 요금 없이 실험하거나 오프라인에서 쓰고 싶을 때는 로컬 LLM이 답입니다. Ollama가 이를 쉽게 만들어줍니다.

 

Ollama의 장단점
항목 장점 한계
비용 API 요금 없음 하드웨어 자원 소모
프라이버시 데이터 외부 안 나감 -
성능 - 최상위 클라우드보다 대체로 낮음

 

설치와 첫 대화
ollama run llama3.2

>>> 파이썬으로 피보나치 함수 짜줘

모델이 없으면 자동으로 내려받고 곧바로 대화형 프롬프트가 뜹니다. 완전히 내 컴퓨터 안에서 동작합니다.

 

코드에서 API처럼 쓰기
requests.post("http://localhost:11434/api/generate", json={
    "model": "llama3.2",
    "prompt": "안녕하세요를 영어로",
    "stream": False,
})

Ollama는 로컬 API 서버(기본 11434 포트)를 함께 띄워 클라우드 API처럼 코드에서 호출할 수 있습니다.

 

실무 포인트

파라미터가 큰 모델(70B)은 많은 RAM·VRAM을 요구합니다. 처음에는 작은 모델(3B~8B급)이나 양자화 버전으로 시작하세요.

주의 — 로컬 모델은 최신 클라우드 모델만큼의 품질을 기대하면 안 됩니다. 복잡한 추론이 필요한 프로덕션 작업은 여전히 클라우드가 유리한 경우가 많습니다.
