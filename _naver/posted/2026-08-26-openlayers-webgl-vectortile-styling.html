OpenLayers도 이제 GPU로 그린다 — WebGL 벡터 타일 렌더러 스타일링 실전

2026. 8. 26. · GIS

한 줄 요약 — OpenLayers의 Canvas2D 벡터 렌더러 대신 WebGL 벡터 타일 레이어를 쓰면 대용량 피처도 부드럽게 그릴 수 있습니다. 스타일 표현식 기반 설정법과 기존 스타일 함수와의 차이를 정리했습니다.

 

피처 수만 개에서 프레임드랍이 나는 이유

OpenLayers로 벡터 타일을 그릴 때 전통적인 방식은 각 피처마다 JS 스타일 함수를 호출해 Canvas2D에 그리는 것입니다. 이 방식은 유연하지만, 피처 수가 수만 개를 넘어가면 매 프레임 스타일 함수 호출 비용이 병목이 됩니다. OpenLayers는 이 문제를 해결하기 위해 WebGLVectorTile 계열의 WebGL 기반 벡터 타일 레이어를 제공하며, 여기서는 JS 함수 대신 스타일 표현식(style expression)이라는 JSON 기반 선언적 문법으로 스타일을 정의합니다.

이 변화는 단순한 성능 최적화 이상의 의미가 있습니다. 표현식은 GPU 셰이더로 컴파일되므로, 피처 하나하나에 대해 JS 콜백을 호출하는 대신 GPU가 병렬로 스타일을 계산합니다.

 

핵심 개념 1 — 스타일 함수 대 스타일 표현식
구분 Canvas2D 스타일 함수 WebGL 스타일 표현식
문법 임의의 JS 함수 JSON 표현식 배열
실행 위치 CPU, 피처마다 콜백 GPU 셰이더 컴파일
대용량 렌더링 프레임드랍 위험 수십만 피처도 부드러움
줌 보간 수동 재계산 interpolate로 선언적 처리

 

핵심 개념 2 — 줌 레벨별 스타일 보간

WebGL 스타일의 강력한 점은 interpolate 표현식으로 줌 레벨에 따른 연속적인 스타일 변화를 선언적으로 표현할 수 있다는 것입니다. 구간별 값을 지정하면 중간 줌 레벨은 자동으로 보간됩니다.

 

예제 — WebGL 벡터 타일 레이어 스타일 표현식
import WebGLVectorTileLayer from 'ol/layer/WebGLVectorTile.js';
import VectorTileSource from 'ol/source/VectorTile.js';
import MVT from 'ol/format/MVT.js';

const roadsLayer = new WebGLVectorTileLayer({
  source: new VectorTileSource({
    format: new MVT(),
    url: 'https://example.com/tiles/{z}/{x}/{y}.pbf',
  }),
  style: {
    'stroke-color': [
      'match', ['get', 'class'],
      'motorway', '#e15759',
      'primary', '#f28e2b',
      'residential', '#bab0ac',
      '#dddddd',
    ],
    'stroke-width': [
      'interpolate', ['linear'], ['zoom'],
      8, 1,
      16, 6,
    ],
    filter: ['any',
      ['!=', ['get', 'class'], 'residential'],
      ['>=', ['zoom'], 13],
    ],
  },
});

match와 interpolate는 Mapbox/MapLibre Style Spec의 표현식 문법과 상당히 유사합니다. OpenLayers 팀이 의도적으로 문법 호환성을 맞춘 부분이라, 다른 라이브러리의 스타일 표현식 경험이 있다면 습득 곡선이 완만합니다.

 

실무 도입 시 이것만은 챙기세요
1. 속성 조인이 필요하면 표현식만으로 부족할 수 있습니다 — 실시간 외부 상태를 반영하려면 벡터 타일에 미리 속성을 넣거나 별도 갱신 파이프라인이 필요합니다.
2. 디버깅은 표현식을 잘게 쪼개서 확인하세요 — 표현식이 복잡해지면 원인 추적이 어려우니 filter를 단순화해 확인하세요.
3. 모든 브라우저가 WebGL2를 지원하지 않습니다 — 오래된 기기·임베디드 웹뷰에서는 Canvas2D 폴백을 함께 준비하세요.

 

마무리 — 3줄 요약

① OpenLayers WebGL 벡터 타일 레이어는 GPU 셰이더로 컴파일되는 선언적 표현식으로 대용량 피처를 부드럽게 렌더링합니다.
② match, interpolate 표현식은 Mapbox/MapLibre Style Spec과 문법이 유사해 학습 곡선이 완만합니다.
③ 표현식은 타일에 이미 존재하는 속성만 참조하므로, 실시간 외부 상태 반영은 별도 설계가 필요합니다.
