마커 수천 개로 지도가 버벅일 때 — 마커 클러스터링 기초

GIS

한 줄 요약 — 클러스터링은 가까운 마커를 묶음 마커로 합쳐 화면에 그리는 요소 수를 줌 레벨에 따라 크게 줄입니다.

 

마커 하나하나가 다 부담이다

전국 매장 5,000곳을 마커로 찍으면 지도가 버벅이고 겹친 핀으로 알아보기 어렵습니다. 마커 클러스터링은 가까이 모인 마커들을 하나의 묶음 마커로 합쳐 보여주는 기법입니다.

 

 

클러스터링의 동작
줌아웃: 가까운 마커를 "127" 숫자 원으로 묶음
확대: 묶음이 작은 묶음으로 나뉨
충분히 확대: 개별 마커가 하나씩 보임

 

Leaflet 예제
const markers = L.markerClusterGroup();
for (const store of stores) {
  markers.addLayer(L.marker([store.lat, store.lng]));
}
map.addLayer(markers);
// -> 화면에 보이는 묶음만 렌더링

실무 포인트

데이터가 수만 개를 넘으면 클라이언트 클러스터링도 한계가 있습니다. 서버에서 영역·줌에 맞게 미리 집계해 내려주는 방식을 검토하세요.

주의 — 클러스터를 클릭하면 그 영역으로 자동 확대되게 하세요. 이 상호작용이 없으면 사용자가 묶인 마커를 펼칠 방법이 없어 답답해합니다.
