Cesium 시작하기 — 3D 지구본 띄우고 카메라 다루기

GIS

한 줄 요약 — Cesium은 좌표를 Cartesian3.fromDegrees(경도, 위도, 고도)로 다루는 3D 전용 지도 라이브러리로, World Terrain을 쓰려면 무료 Ion 토큰이 필요합니다.

 

왜 지금 Cesium인가

2D 웹 지도 라이브러리로는 지형 고도, 3D 건물, 위성 궤도 같은 데이터를 표현하기 어렵습니다. Cesium은 처음부터 WGS84 타원체 위 3D 렌더링을 전제로 설계된 오픈소스 라이브러리라 디지털 트윈이나 항공·위성 데이터 시각화의 표준처럼 쓰입니다.

 

 

2D 지도 라이브러리와의 차이
항목 Leaflet/OpenLayers Cesium
좌표 표현 평면 좌표(투영법) 지구 타원체 3차원(Cartesian3)
지형 기본 미지원 World Terrain 내장 지원
대표 포맷 GeoJSON, WMTS 3D Tiles, CZML, KML

 

예제 — 첫 지구본 띄우기
Cesium.Ion.defaultAccessToken = 'YOUR_ION_ACCESS_TOKEN';
const viewer = new Cesium.Viewer('cesiumContainer', {
  terrain: Cesium.Terrain.fromWorldTerrain(),
});

viewer.camera.flyTo({
  destination: Cesium.Cartesian3.fromDegrees(126.978, 37.5665, 15000),
});

Cartesian3.fromDegrees(경도, 위도, 고도)로 좌표를 지정하는 점이 2D 라이브러리와 가장 다른 부분입니다.

 

엔티티 추가하기
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(126.978, 37.5665),
  point: { pixelSize: 12, color: Cesium.Color.RED },
  label: { text: '서울 시청' },
});

 

실무 포인트

Ion 액세스 토큰 없이도 라이브러리는 동작하지만, World Terrain이나 위성 베이스맵은 Ion 서비스를 거치므로 토큰이 필요합니다. 무료 티어로 개인 프로젝트는 충분합니다.

주의 — 대용량 3D 모델은 반드시 3D Tiles로 변환해서 로드해야 합니다. 원본 모델 포맷을 그대로 올리면 브라우저가 감당하지 못합니다.
