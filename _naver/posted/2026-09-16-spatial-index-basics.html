공간 인덱스가 뭔가요 — 반경 검색이 빨라지는 원리

GIS

한 줄 요약 — 공간 인덱스(R-tree)는 도형을 경계 상자로 계층적으로 묶어 겹치지 않는 영역을 통째로 건너뛰며 후보를 좁힙니다.

 

반경 검색은 왜 일반 인덱스로 안 되나

일반 B-Tree 인덱스는 "크다/작다"로 정렬된 1차원 데이터용인데, 위치는 위도·경도라는 2차원 값입니다. 공간 인덱스는 2차원 위치를 빠르게 검색하기 위한 전용 인덱스입니다.

 

 

왜 빠른가 — 경계 상자로 후보 좁히기
검색 영역과 안 겹치는 큰 사각형은
그 안의 수천 개 점을 하나하나 확인할 필요 없이 통째로 스킵
-> 전체 스캔 없이 겹칠 가능성 있는 영역만 파고든다

 

PostGIS에서 공간 인덱스
CREATE INDEX idx_places_geom ON places USING GIST (geom);

SELECT name FROM places
WHERE ST_DWithin(geom::geography,
    ST_MakePoint(126.978, 37.5665)::geography, 1000);

USING GIST로 공간 인덱스를 만듭니다. 없으면 반경 검색이 전체를 훑어 데이터가 많을수록 급격히 느려집니다.

 

실무 포인트

경계 상자는 1차 필터입니다. 사각형으로 후보를 좁힌 뒤 실제 원 안에 드는지 정밀 계산으로 다시 확인하는 2단계로 동작합니다.

주의 — 공간 인덱스는 데이터가 많을 때 진가를 발휘합니다. 수백 건 수준 작은 테이블에서는 전체 스캔이 오히려 빠를 수 있습니다.
