cron 스케줄링 기초 — 크론 표현식 읽고 쓰기

인프라

한 줄 요약 — 크론 표현식은 분·시·일·월·요일 5칸으로 구성되며, cron은 환경변수가 로그인 셸과 달라 절대 경로를 쓰는 것이 안전합니다.

 

매일 새벽 백업을 자동으로

"매일 새벽 3시 백업", "10분마다 점검" 같은 반복 작업을 사람이 매번 할 수 없습니다. cron은 정해진 시각·주기에 명령을 자동 실행하는 스케줄러입니다.

 

크론 표현식 5칸
* * * * *  실행할_명령
│ │ │ │ └─ 요일 (0-7)
│ │ │ └─── 월 (1-12)
│ │ └───── 일 (1-31)
│ └─────── 시 (0-23)
└───────── 분 (0-59)

 

예시로 익히기
표현식 의미
0 3 * * * 매일 새벽 3시
*/10 * * * * 10분마다
30 2 * * 1-5 평일 새벽 2시 30분

 

등록과 확인
crontab -e   # 편집
0 3 * * * /home/user/backup.sh
crontab -l   # 목록 확인

 

실무 포인트

터미널에선 되는데 cron에선 안 되는 흔한 이유가 PATH 등 환경변수 차이입니다. 절대 경로를 쓰거나 환경변수를 명시하세요. 실행 결과는 >> log 2>&1로 로그에 남기세요.

주의 — 여러 서버에서 같은 cron이 돌면 중복 실행됩니다. 서버를 확장했다면 분산 락(ShedLock 등)이나 전용 스케줄러를 고려하세요.
