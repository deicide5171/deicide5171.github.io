Mapbox GL JS 처음 시작하기 — 설치와 첫 지도 띄우기

GIS

한 줄 요약 — Mapbox GL JS는 MapLibre와 API가 거의 같지만 액세스 토큰이 필요하고 사용량 기반으로 과금됩니다.

 

Mapbox는 MapLibre와 뭐가 다른가

MapLibre는 Mapbox GL JS v1의 오픈소스 포크에서 시작돼 API가 거의 동일합니다. 차이는 라이선스와 서비스 구조입니다. Mapbox는 타일·지오코딩·내비게이션 서비스를 함께 제공하는 대신 액세스 토큰이 필요합니다.

 

 

예제 — 첫 지도 띄우기
mapboxgl.accessToken = 'YOUR_ACCESS_TOKEN';

const map = new mapboxgl.Map({
  container: 'map',
  style: 'mapbox://styles/mapbox/streets-v12',
  center: [126.978, 37.5665],
  zoom: 12,
});

map.addControl(new mapboxgl.NavigationControl());

style 값이 mapbox://styles/... 형태인 점이 MapLibre와 가장 눈에 띄는 차이입니다. 이 URL 스킴은 Mapbox 전용입니다.

 

실무 포인트

액세스 토큰을 프론트엔드 코드에 노출해도, Mapbox는 도메인 화이트리스트로 토큰을 보호하는 것을 권장합니다.

무료 티어를 초과하면 과금이 시작되므로 트래픽이 많다면 사용량 대시보드를 반드시 확인해야 합니다.

주의 — 라이선스 비용 없이 시작하고 싶다면 MapLibre GL JS + 자체 타일 서버 조합을 검토하세요. Mapbox의 지오코딩·내비게이션이 꼭 필요하지 않다면 오픈소스로 충분합니다.
