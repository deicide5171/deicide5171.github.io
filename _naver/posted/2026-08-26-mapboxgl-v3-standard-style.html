지도에 저녁노을과 그림자가 생겼다 — Mapbox GL JS v3 Standard 스타일 실전

2026. 8. 26. · GIS

한 줄 요약 — Mapbox GL JS v3의 Standard 스타일은 라이팅 프리셋과 config 기반 커스터마이징으로 3D 건물·그림자·시간대 표현을 코드 몇 줄로 가능하게 합니다. 실전 설정 방법을 정리했습니다.

 

레이어를 손으로 조립하던 시절

Mapbox GL JS의 스타일링은 오랫동안 레이어를 하나씩 쌓고, 각 레이어의 paint 속성을 표현식으로 채우는 방식이었습니다. 건물에 그림자를 넣거나 시간대에 따라 조명을 바꾸려면 fill-extrusion 레이어의 높이·색상 표현식을 손으로 조합하고, 하늘 레이어와 안개 레이어를 따로 추가해야 했습니다. v3부터 도입된 Standard 스타일은 이 작업의 상당 부분을 미리 만들어진 3D 라이팅 시스템과 config 옵션으로 대체합니다.

개발자는 레이어를 직접 조립하는 대신, 몇 개의 config 값만 바꿔서 사실적인 3D 지도를 얻을 수 있습니다.

 

핵심 개념 1 — 라이트 프리셋으로 조명을 통째로 바꿉니다
프리셋 특징 활용 예
dawn 낮은 태양각, 긴 그림자 아침 배송 현황 대시보드
day 밝은 조명, 짧은 그림자 기본값, 일반 내비게이션
dusk 저녁노을, 대비 강한 그림자 저녁 시간대 서비스 강조
night 어두운 톤, 창문 발광 효과 야간 운행 앱

과거에는 시간대별 분위기를 표현하려면 각 레이어의 색상·안개 표현식을 4세트 따로 관리해야 했지만, Standard 스타일에서는 프리셋 이름 하나만 바꾸면 관련된 모든 레이어의 색감과 그림자가 일관되게 갱신됩니다.

 

예제 — Standard 스타일 초기화와 config 커스터마이징
import mapboxgl from 'mapbox-gl';

const map = new mapboxgl.Map({
  container: 'map',
  style: 'mapbox://styles/mapbox/standard',
  center: [126.978, 37.5665],
  zoom: 15,
  pitch: 60,
});

map.on('style.load', () => {
  map.setConfigProperty('basemap', 'lightPreset', 'dusk');
  map.setConfigProperty('basemap', 'showPointOfInterestLabels', false);
  map.setConfigProperty('basemap', 'show3dObjects', true);

  map.setPaintProperty('building', 'fill-extrusion-color', '#d9d2c5');
});

setConfigProperty가 핵심 API입니다. 스타일 전체를 다시 만들지 않고도 런타임에 라이트 프리셋이나 레이블 표시 여부 같은 고수준 옵션을 바꿀 수 있어, 낮/밤 모드 토글 UI를 스타일 재로드 없이 부드럽게 전환할 수 있습니다.

 

실무 도입 시 이것만은 챙기세요
1. 레거시 스타일과 섞어 쓰지 마세요 — Standard 스타일은 v2와 다른 레이어 구조를 쓰므로 기존 커스터마이징 코드를 그대로 쓰면 오버라이드가 먹히지 않을 수 있습니다.
2. 3D 렌더링 비용을 저사양 기기에서 검증하세요 — show3dObjects와 라이팅 효과는 GPU 부하가 늘어나므로 저사양 폴백 설정을 준비하세요.
3. 라이트 프리셋 자동 연동은 별도 로직이 필요합니다 — Mapbox가 현재 시간에 맞춰 자동으로 프리셋을 바꿔주지 않으므로 애플리케이션 코드에서 직접 호출해야 합니다.

 

마무리 — 3줄 요약

① Mapbox GL JS v3 Standard 스타일은 레이어를 손으로 조립하던 3D 라이팅 작업을 라이트 프리셋과 config 옵션으로 대체합니다.
② dawn/day/dusk/night 프리셋은 태양 각도, 그림자, 색조를 한 번에 바꾸고, setConfigProperty로 런타임에 부드럽게 전환할 수 있습니다.
③ 레거시 v2 스타일과 레이어 구조가 다르므로 마이그레이션 시 커스터마이징 코드를 재검토해야 하고, 3D 렌더링 비용은 저사양 기기에서 별도로 검증해야 합니다.
