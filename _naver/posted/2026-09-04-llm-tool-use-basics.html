LLM 도구 호출(tool use)이 뭔가요 — AI가 함수를 부르는 원리

AI

한 줄 요약 — LLM은 함수를 직접 실행하지 않고 "실행해달라"고 요청만 하며, 실제 실행과 결과 전달은 개발자 코드의 몫입니다.

 

LLM은 왜 도구가 필요한가

LLM은 학습된 지식으로 텍스트를 생성할 뿐, "지금 날씨"나 "내 DB 데이터" 같은 실시간·외부 정보는 모릅니다. 도구 호출은 함수 목록을 LLM에게 알려주고, LLM이 필요할 때 호출을 요청하게 하는 방법입니다.

 

동작 흐름
1. 도구 목록·인자 형식을 LLM에 전달
2. 사용자: "서울 날씨 알려줘"
3. LLM: "get_weather를 city=서울로 호출해줘" (직접 실행 X)
4. 개발자 코드가 실제로 실행
5. 결과를 LLM에 다시 전달
6. LLM이 결과로 자연스러운 답변 생성

 

코드 예제
tools = [{
    "name": "get_weather",
    "description": "도시의 현재 날씨를 조회한다",
    "input_schema": {...},
}]

if response.stop_reason == "tool_use":
    tool_call = next(b for b in response.content if b.type == "tool_use")
    result = get_weather(tool_call.input["city"]) # 실행은 내 코드가

 

실무 포인트

도구의 description을 명확하게 쓰는 것이 성능에 직결됩니다. LLM은 이 설명만 보고 언제 어떤 도구를 쓸지 판단합니다.

여러 도구를 주고 LLM이 스스로 판단하게 하면 그것이 곧 AI 에이전트의 기본 뼈대가 됩니다.

주의 — "데이터 삭제" 같은 위험한 도구를 LLM이 자동 실행하게 두지 말고, 실행 전 사람 승인 단계를 두세요.
