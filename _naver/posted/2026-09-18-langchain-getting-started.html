LangChain 시작하기 — LLM 앱 개발 프레임워크 첫걸음

AI

한 줄 요약 — LangChain은 프롬프트·체인·RAG·메모리 같은 LLM 앱 공통 패턴을 부품으로 제공하며, 파이프(|)로 단계를 연결합니다.

 

LangChain은 무슨 문제를 풀어주나

실제 앱을 만들다 보면 프롬프트 관리, 여러 단계 연결, RAG, 대화 기록 유지 같은 반복 패턴이 생깁니다. LangChain은 이를 부품으로 제공해 LLM 앱을 조립하듯 만들게 해줍니다.

 

핵심 구성 요소
구성 요소 역할
프롬프트 템플릿 변수를 끼워 넣는 재사용 프롬프트
체인 여러 단계 연결
리트리버 벡터 DB 검색(RAG)
메모리 대화 기록 유지

 

예제 — 간단한 체인
prompt = ChatPromptTemplate.from_template(
    "{product}를 홍보하는 카피 한 줄 작성해줘")
model = ChatOpenAI(model="gpt-4o")
chain = prompt | model
result = chain.invoke({"product": "무선 이어폰"})

파이프(|) 기호로 단계를 연결하는 것이 특징입니다. 부품처럼 갈아 끼우거나 추가할 수 있습니다.

 

실무 포인트

LangChain은 추상화가 많아 학습 곡선이 있습니다. 단순한 작업에는 API 직접 호출이 더 이해하기 쉽고 디버깅도 편합니다.

주의 — LangChain은 빠르게 발전하며 API가 자주 바뀝니다. 튜토리얼을 따라 할 때 버전이 맞는지 확인하세요.
