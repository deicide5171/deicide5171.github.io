deck.gl 시작하기 — 대용량 데이터를 지도에 그리는 첫걸음

GIS

한 줄 요약 — deck.gl은 GPU(WebGL)로 수십만~수백만 개의 데이터를 부드럽게 그리는 대용량 시각화 라이브러리입니다.

 

마커 라이브러리로는 안 되는 규모

Leaflet 마커로 점 수십만 개를 그리면 각 마커가 DOM 요소라 버벅입니다. deck.gl은 GPU(WebGL)를 직접 활용해 대량의 점·선·면을 한 번에 렌더링합니다.

 

 

핵심: 레이어
레이어 용도
ScatterplotLayer 점 대량 표시
ArcLayer 두 지점 잇는 곡선(이동 흐름)
HexagonLayer 육각형 격자 밀집도 집계

 

예제 — 포인트 레이어
new ScatterplotLayer({
  data: points, // 수십만 개
  getPosition: d => d.position,
  getRadius: 30,
  getFillColor: [255, 80, 80],
})

data에 대량 배열을 넣고 getPosition으로 위치를 알려주면 GPU로 한꺼번에 그립니다.

 

실무 포인트

deck.gl은 배경 지도를 직접 그리지 않습니다. 데이터 시각화 레이어를 담당하고 배경 지도는 MapLibre·Mapbox와 함께 겹쳐 씁니다.

주의 — 모든 지도에 deck.gl이 필요한 건 아닙니다. 수천 개 수준이면 Leaflet·MapLibre로 충분하고, deck.gl은 대용량일 때 진가를 발휘합니다.
