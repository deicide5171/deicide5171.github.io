MapLibre GL JS 시작하기 — 설치부터 첫 지도 띄우기까지

GIS

한 줄 요약 — MapLibre GL JS는 Mapbox GL JS의 오픈소스 포크로 API가 거의 동일하며, center 좌표는 [경도, 위도] 순서임을 꼭 기억해야 합니다.

 

왜 지금 MapLibre인가

Mapbox GL JS가 v2부터 상용 라이선스로 전환되면서, 오픈소스 라이선스를 유지하는 포크인 MapLibre GL JS가 사실상 웹 지도 라이브러리의 무료 표준이 됐습니다. API가 Mapbox GL JS와 거의 동일해 기존 Mapbox 자료를 참고하며 학습해도 무방합니다.

 

 

핵심 개념 3가지
개념 설명
Style Spec 레이어·색상·라벨을 정의하는 JSON 명세
Vector Tile 좌표 데이터를 타일 단위로 나눈 바이너리(PBF)
Source / Layer Source는 데이터 출처, Layer는 그리는 방식 정의

 

예제 — 첫 지도 띄우기
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://demotiles.maplibre.org/style.json',
  center: [126.978, 37.5665], // [경도, 위도]
  zoom: 10,
});
map.addControl(new maplibregl.NavigationControl());

이 코드만으로 확대·축소·회전이 되는 벡터 지도가 뜹니다. center는 [위도, 경도]가 아니라 [경도, 위도] 순서라는 점이 가장 많이 헷갈리는 부분입니다.

 

실무 포인트

데모 스타일은 실서비스에 쓸 수 없습니다. 실제 서비스에서는 PostGIS + pg_tileserv, 또는 tippecanoe로 만든 PMTiles 같은 자체 벡터 타일 서버를 붙여야 합니다.

Mapbox 튜토리얼을 참고할 때는 mapboxgl을 maplibregl로 바꾸고 액세스 토큰 코드를 제거하면 대부분 그대로 동작합니다.

주의 — Mapbox 전용 스타일 URL(mapbox://styles/...)은 MapLibre에서 쓸 수 없습니다. 반드시 공개된 style.json URL을 사용하세요.
