Spring Boot 첫 프로젝트 만들기 — Initializr부터 첫 API 호출까지

백엔드

한 줄 요약 — Spring Initializr로 프로젝트를 만들고 @RestController + @GetMapping 조합만으로 첫 JSON API를 바로 확인할 수 있습니다.

 

왜 이 순서로 시작해야 하는가

Spring Boot를 처음 배우면 자동 설정, 빈, 애노테이션 개념이 한꺼번에 쏟아져서 "화면에 뭐라도 찍어보는" 첫 성공 경험까지 오래 걸립니다. 이 글은 개념 설명을 최소화하고 브라우저에 JSON 응답이 뜨는 것까지 가장 빠른 경로로 정리했습니다.

 

필요한 준비물
준비물 권장
JDK 21 이상(LTS)
IDE IntelliJ IDEA Community(무료)로 충분
Spring Boot 3.x 최신 안정 버전

 

프로젝트 생성

start.spring.io에서 Gradle 또는 Maven, Java, Spring Boot 3.x 최신, 의존성으로 Spring Web을 선택하고 Generate를 누르면 zip 파일이 다운로드됩니다. 압축을 풀고 IDE로 열면 바로 실행 가능한 구조가 갖춰져 있습니다.

 

예제 — 첫 REST 컨트롤러
@RestController
@RequestMapping("/api/hello")
public class HelloController {

    @GetMapping
    public Map<String, String> hello() {
        return Map.of("message", "안녕하세요, Spring Boot!");
    }
}

이 클래스 하나만 추가하고 메인 클래스를 실행하면 브라우저에서 http://localhost:8080/api/hello로 JSON 응답을 확인할 수 있습니다. @RestController가 반환값을 자동으로 JSON으로 직렬화합니다.

 

실무 포인트

@SpringBootApplication이 붙은 메인 클래스의 패키지 위치가 중요합니다. 이 패키지의 하위 패키지만 컴포넌트 스캔 대상이 되므로, 컨트롤러를 다른 패키지에 두면 빈을 찾을 수 없다는 에러가 납니다.

application.properties 대신 application.yml을 쓰면 계층 구조를 표현하기 쉬워집니다. 프로젝트가 커질수록 초반 습관이 중요합니다.

주의 — 포트 충돌(Port 8080 already in use)은 입문자가 가장 자주 겪는 에러입니다. application.yml에 server.port: 8081을 추가하거나 기존 프로세스를 종료하세요.
