토큰이 뭔가요 — LLM 요금과 길이 제한의 단위 이해하기

AI

한 줄 요약 — 토큰은 LLM이 텍스트를 처리하는 최소 단위로, 한국어는 영어보다 같은 의미에 더 많은 토큰을 소모하는 경향이 있습니다.

 

왜 요금이 '글자 수'가 아니라 '토큰'인가

LLM 요금표는 "100만 토큰당 얼마", 컨텍스트 제한도 "128K 토큰"처럼 표현됩니다. 토큰은 LLM이 텍스트를 처리하는 최소 단위로, 글자도 단어도 아닌 그 중간쯤의 조각입니다.

 

토큰은 어떻게 쪼개지는가
텍스트 대략 토큰 수
"hello" 1토큰
"tokenization" 2~3토큰
"안녕하세요" 3~5토큰

경험칙으로 영어는 1토큰이 약 4글자, 한국어는 글자당 토큰 수가 더 많습니다. 같은 의미라도 한국어로 쓰면 토큰이 더 소모돼 요금·길이에 불리할 수 있습니다.

 

예제 — 토큰 수 세어보기
import tiktoken

enc = tiktoken.get_encoding("cl100k_base")
text = "안녕하세요, 토큰을 세어봅시다."
tokens = enc.encode(text)
print(f"토큰 수: {len(tokens)}")
print(f"글자 수: {len(text)}")

요청 전에 토큰 수를 미리 계산하면 길이 초과 에러를 방지하고 예상 비용도 가늠할 수 있습니다.

 

실무 포인트

입력 토큰과 출력 토큰은 보통 요금이 다르며 출력이 더 비쌉니다. max_tokens로 응답 길이를 제한하는 것이 비용 절감에 직접적입니다.

주의 — 컨텍스트 길이 제한은 입력과 출력을 합친 값입니다. 입력을 꽉 채우면 답변 생성 여유가 없어 응답이 잘립니다.
