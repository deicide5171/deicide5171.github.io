MapLibre GL JS로 3D 건물 표현하기 — fill-extrusion 첫 설정과 흔한 실수

GIS

한 줄 요약 — 건물을 입체로 세우려면 fill이 아니라 fill-extrusion 레이어를 쓰고, 지도의 pitch를 함께 기울여야 눈으로 확인됩니다.

 

왜 fill 레이어로는 3D가 안 되나

fill 레이어는 폴리곤을 평면에 색으로 채우는 2D 렌더링 방식이라, 층수 데이터를 스타일에 연결해도 입체감이 생기지 않습니다. MapLibre GL JS에서 건물을 실제로 세워서 보여주려면 2D 폴리곤을 수직으로 압출하는 전용 레이어 타입인 fill-extrusion을 써야 합니다.

 

 

첫 설정과 흔한 실수
const map = new maplibregl.Map({
  container: 'map', pitch: 60, bearing: -20, ...
});
map.on('load', () => {
  map.addLayer({
    id: 'buildings-3d', type: 'fill-extrusion',
    source: 'openmaptiles', 'source-layer': 'building',
    paint: {
      'fill-extrusion-height': ['get', 'render_height'],
      'fill-extrusion-base': ['get', 'render_min_height']
    }
  });
});

pitch: 60처럼 지도를 충분히 기울이지 않으면 위에서 내려다보는 시점이라 건물이 세워져 있어도 평면 도형처럼 보입니다. "설정했는데 아무 효과가 없다"는 경우 대부분 이 pitch 설정을 빼먹었기 때문입니다.

주의 — fill-extrusion-height에 고정 숫자를 주면 모든 건물이 똑같은 높이로 뭉뚱그려집니다. render_height 같은 실제 속성값을 표현식으로 참조해야 하며, 사용하는 타일 소스마다 속성명이 다르니 스키마 문서를 꼭 확인하세요.

 

실무 포인트

도시 전체를 줌아웃한 상태에서 수만 개 건물을 모두 압출하면 렌더링 부하가 커지므로 minzoom으로 표시 범위를 제한하세요. light 속성으로 광원 방향을 조정하면 건물 면마다 음영이 달라져 훨씬 입체적으로 보입니다.
