외래키 CASCADE가 뭔가요 — 부모를 지우면 자식도 지울까

2026. 9. 16. · 데이터베이스

한 줄 요약 — 외래키 CASCADE는 부모를 지우면 자식도 함께 삭제하는 옵션으로, 편하지만 연쇄 삭제 위험이 있습니다.

 

회원을 지우면 그 회원의 주문은?

주문이 회원을 외래키로 참조할 때, 회원을 삭제하면 그 주문은? 그냥 두면 "없는 회원을 참조하는 주문"이 생겨 무결성이 깨집니다. 외래키의 ON DELETE 옵션이 이를 처리하며, CASCADE는 "부모 따라 자식도" 처리합니다.

 

주요 옵션
옵션 부모 삭제 시
CASCADE 자식도 함께 삭제
RESTRICT 자식 있으면 거부
SET NULL 자식 외래키를 NULL로

 

설정 예시
CREATE TABLE orders (
  id BIGINT PRIMARY KEY,
  user_id BIGINT REFERENCES users(id) ON DELETE CASCADE
);
-- 회원 삭제 시 그 회원의 orders도 자동 삭제

 

실무 포인트

부모 하나를 지웠는데 연쇄로 수많은 자식이 삭제될 수 있어 CASCADE는 신중히 쓰세요. 작성자 탈퇴해도 글은 남겨야 하면 SET NULL, 아예 deleted_at 플래그로 소프트 삭제도 고려합니다.

주의 — CASCADE는 실수로 큰 데이터가 연쇄 삭제될 수 있습니다. 중요한 데이터엔 RESTRICT로 막고 명시적으로 처리하는 편이 안전합니다.
