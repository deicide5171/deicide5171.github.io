포트가 뭔가요 — 포트 포워딩과 :8080의 의미

인프라

한 줄 요약 — 포트는 한 IP(서버)에서 여러 프로그램을 구분하는 "방 번호"이며, 포트 포워딩은 한 포트로 온 요청을 다른 포트로 넘기는 것입니다.

 

localhost:8080의 8080은 뭔가

IP 주소가 "건물 주소"라면 포트는 건물 안의 방 번호입니다. 한 서버에서 여러 프로그램이 동시에 돌 때, 어느 프로그램으로 연결할지를 포트 번호로 구분합니다. 웹 서버는 보통 80(HTTP)·443(HTTPS)을 씁니다.

 

자주 쓰는 포트
포트 용도
80 / 443 HTTP / HTTPS
22 SSH
3306 / 5432 MySQL / PostgreSQL

 

포트 포워딩
docker run -p 8080:80
  내 PC 8080 -> 컨테이너 안 80으로 연결
접속: localhost:8080 -> 컨테이너 웹서버(80)에 도달

 

실무 포인트

도커 -p 8080:80은 왼쪽이 밖(호스트), 오른쪽이 안(컨테이너)입니다. 80·443 같은 1024 미만 포트는 관리자 권한이 필요해, 개발엔 8080·3000을 씁니다. 외부 접속이 안 되면 방화벽/보안 그룹 규칙부터 확인하세요.

주의 — 서버 안에서 포트를 열어도 방화벽에서 허용하지 않으면 외부에서 접속되지 않습니다.
