도커 볼륨이 뭔가요 — 컨테이너 데이터 영구 저장하기

인프라

한 줄 요약 — 컨테이너 안 파일은 컨테이너와 함께 사라지므로, 남길 데이터는 볼륨(volume)에 저장합니다.

 

컨테이너 지웠더니 데이터가 사라졌다

컨테이너 안에 저장한 파일은 컨테이너를 삭제하면 같이 사라집니다. DB 컨테이너를 재생성했더니 데이터가 날아간 이유입니다. 컨테이너와 분리해 데이터를 남기는 방법이 볼륨입니다.

 

볼륨과 bind mount
# 볼륨: 도커가 관리하는 저장소
docker volume create mydata
docker run -v mydata:/var/lib/mysql mysql

# bind mount: 호스트 경로를 직접 연결
docker run -v /home/user/data:/var/lib/mysql mysql
방식 저장 위치 쓰임
volume 도커 관리 영역 운영 데이터(권장)
bind mount 호스트 지정 경로 개발 중 소스 연결

 

실무 포인트

DB·업로드 파일처럼 상태가 있는 데이터는 반드시 볼륨에 저장해 재배포 때 날아가지 않게 합니다. 개발 중엔 소스 폴더를 bind mount로 연결하면 수정이 즉시 반영됩니다.

주의 — 안 쓰는 볼륨이 쌓여 디스크를 잡아먹을 수 있습니다. docker volume prune으로 정리하되, 삭제 전 사용 여부를 확인하세요.
