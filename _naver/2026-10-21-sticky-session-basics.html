스티키 세션이 뭔가요 — 같은 사용자를 같은 서버로 보내기

시스템 디자인

한 줄 요약 — 스티키 세션은 같은 사용자의 요청을 항상 같은 서버로 보내 세션을 유지하지만, 근본 해법은 세션 외부화(Redis)입니다.

 

로그인했는데 갑자기 로그아웃된다

서버가 여러 대일 때 로그인 정보를 특정 서버 메모리에만 두면, 다음 요청이 다른 서버로 가서 "로그아웃"됩니다. 스티키 세션은 같은 사용자의 요청을 항상 같은 서버로 보내 이를 막습니다.

 

어떻게 붙이나
쿠키 기반: LB가 심은 쿠키로 서버 기억
IP 해시: 같은 IP는 같은 서버로
같은 사용자 -> 항상 서버 A -> 세션 유지

 

스티키 세션 vs 세션 외부화
방식 설명
스티키 세션 같은 서버로 고정
세션 외부화 Redis 등 공유 저장소

 

실무 포인트

근본 해법은 세션 외부화입니다. 세션을 Redis에 두면 어느 서버로 가도 조회할 수 있어 스티키 세션이 불필요하고 서버를 자유롭게 확장할 수 있습니다. JWT로 무상태화하는 방법도 있습니다.

주의 — 스티키 세션은 그 서버가 죽으면 사용자 세션이 날아가고 부하도 고르게 안 퍼집니다. 임시방편일 뿐 근본 해법은 아닙니다.
