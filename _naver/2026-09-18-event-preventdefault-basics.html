preventDefault가 뭔가요 — 브라우저 기본 동작 막기

2026. 9. 18. · 프론트엔드

한 줄 요약 — preventDefault()는 폼 제출 새로고침·링크 이동 같은 브라우저 기본 동작을 취소합니다.

 

폼을 제출했더니 페이지가 새로고침된다

폼 제출 버튼을 누르면 브라우저는 기본적으로 페이지를 새로고침합니다. 요즘은 JS로 직접(fetch 등) 처리하고 싶을 때가 많죠. preventDefault()는 이런 기본 동작을 취소합니다.

 

사용법
form.addEventListener('submit', (e) => {
  e.preventDefault();   // 새로고침 막기
  const data = new FormData(form);
  fetch('/api/submit', { method:'POST', body:data });
});

 

어디에 쓰나
기본 동작 막는 이유
폼 제출 새로고침 JS로 직접 처리
링크 이동 SPA 라우팅

 

실무 포인트

preventDefault(기본 동작 취소)와 stopPropagation(전파 막기)은 다릅니다. 링크 이동을 막고 JS로만 처리하면 JS 실패 시 이동이 안 되니, 실제 href를 두고 보강하는 게 안전합니다.

주의 — 취소 가능한 기본 동작이 있는 이벤트에서만 의미가 있습니다. event.cancelable로 확인할 수 있습니다.
