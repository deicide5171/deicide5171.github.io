방화벽과 보안 그룹 기초 — 어떤 포트를 열지 정하기

2026. 9. 7. · 인프라

한 줄 요약 — 방화벽·보안 그룹은 트래픽을 규칙으로 통제하며, "꼭 필요한 포트만 필요한 대상에게" 여는 최소 권한이 원칙입니다.

 

서버에 아무나 접속하면 안 된다

공개 IP 서버는 몇 분 안에 자동 스캔 봇의 접속 시도를 받습니다. 방화벽은 어떤 트래픽을 허용·차단할지 규칙으로 정하며, 클라우드에서는 보안 그룹 형태로 제공됩니다.

 

규칙의 기본 요소
요소 설명
방향 인바운드 / 아웃바운드
포트 80, 443, 22 등
소스 어느 IP에서 오는 것을 허용할지

 

보안 그룹 설정 예시
443(HTTPS): 모든 IP 허용 (웹 서비스)
22(SSH): 우리 사무실 IP만 허용
3306(DB): 애플리케이션 서버만 허용 (외부 차단)

 

실무 포인트

DB 포트를 절대 인터넷 전체에 열지 마세요. 3306·5432를 모든 IP에 열면 무차별 공격 표적이 됩니다. DB는 애플리케이션 서버에서만 접근하게 제한하세요.

주의 — 포트가 안 열리는 문제를 서버 안에서만 찾다가 클라우드 보안 그룹에서 막혀 있던 경우가 흔합니다. 둘 다 확인하세요.
