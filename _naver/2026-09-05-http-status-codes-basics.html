HTTP 상태 코드 정리 — 200, 404, 500 말고도 알아야 할 것들

2026. 9. 5. · 인프라

한 줄 요약 — 상태 코드는 첫 자리로 성공(2xx)·리다이렉션(3xx)·클라이언트 오류(4xx)·서버 오류(5xx)로 분류됩니다.

 

첫 자리 숫자가 곧 분류다
첫 자리 의미
2xx 성공
3xx 리다이렉션
4xx 클라이언트 오류
5xx 서버 오류

 

자주 만나지만 헷갈리는 코드
201 Created - 자원 생성 성공
204 No Content - 성공, 응답 본문 없음
401 Unauthorized - 인증 안 됨(로그인 필요)
403 Forbidden - 인증됐지만 권한 없음
429 Too Many Requests - 요청 과다
502 Bad Gateway / 503 Unavailable / 504 Timeout

 

헷갈리기 쉬운 구분

401 vs 403: 401은 "누군지 모르겠다", 403은 "누군지는 아는데 권한 없다"입니다. 400 vs 422: 400은 형식 자체가 잘못, 422는 형식은 맞는데 검증 실패입니다.

 

실무 포인트

모든 오류를 200으로 주고 본문에 에러를 담는 방식은 좋지 않습니다. 인증 실패는 401, 자원 없음은 404처럼 코드로 명확히 알려주는 것이 표준입니다.

주의 — 500번대는 서버 문제 신호입니다. 모니터링에서 5xx가 늘면 서버를, 4xx가 많으면 클라이언트나 API 사용법을 점검하세요. 429는 Retry-After만큼 기다렸다 재시도하세요.
