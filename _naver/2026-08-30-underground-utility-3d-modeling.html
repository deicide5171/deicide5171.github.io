땅 밑은 2D 도면으로 못 그린다 — 지하 시설물 3D 모델링과 BIM-GIS 연계

2026. 8. 30. · GIS

한 줄 요약 — 지하 시설물의 3D 모델링에서 가장 먼저 무너지는 것은 깊이(z값) 기준의 정합입니다. 데이터 표준 파편화, BIM-GIS 지오레퍼런싱까지 실무에서 부딪히는 지점을 정리했습니다.

 

2D 도면만으로는 깊이 충돌을 알 수 없습니다

도심 지하에는 상수도관, 하수관, 통신관, 전력구, 가스관이 서로 다른 기관에 의해 서로 다른 시기에 매설됩니다. 각 기관이 자기 관로만 2D 평면도로 관리하면, 그 도면들을 겹쳐 봤을 때 실제로 깊이까지 충돌하는지 알 수 없습니다. 굴착 공사 중 통신관을 절단하거나 가스관을 훼손하는 사고의 상당수가 이 평면도만으로는 안 보이는 깊이 충돌에서 비롯됩니다. 지하 시설물 3D 모델링은 각 시설물에 정확한 깊이·형상 정보를 부여해 3차원 공간에서 실제 간섭 여부를 검토할 수 있게 만드는 작업입니다.

 

핵심 개념 1 — 깊이(z값) 기준의 정합이 가장 먼저 무너집니다

지하 시설물 3D 모델링에서 가장 먼저 부딪히는 문제는 좌표계의 xy축이 아니라 z값(깊이/표고)의 기준입니다. 어떤 기관은 지표면 기준 상대 깊이로 기록하고, 어떤 기관은 특정 수준점을 기준으로 한 절대 표고로 기록합니다. 지표면 자체가 도로 재포장이나 지반 침하로 시간에 따라 변하기 때문에, 상대 깊이로만 기록된 오래된 데이터는 현재 지표 기준으로 재계산이 필요합니다. 여러 기관의 시설물을 통합하려면 이 z값들을 반드시 같은 수직 기준면으로 통일하는 좌표 변환이 선행돼야 합니다.

 

 

핵심 개념 2 — 데이터 표준의 파편화

지상 건물의 3D 표준화는 CityGML이 상당히 자리를 잡았지만, 지하 시설물은 표준화가 더 파편화돼 있습니다. CityGML은 Utility Network ADE라는 확장 모듈로 네트워크형 시설물을 노드와 링크의 그래프 구조로 표현하는 방법을 정의하지만, 실제 현장에서는 국가·지자체별 지하시설물 관리 표준이 별도로 존재해서 데이터를 주고받으려면 스키마 매핑이 필요합니다.

표준/체계 초점 표현 방식
CityGML Utility Network ADE 국제 표준, 지상 3D와 통합 지향 노드-링크 그래프 + LOD별 형상
국내 지하공간통합지도 국내 지하시설물 통합 관리 시설물 종류별 속성·형상 스키마
IFC(건축 BIM 표준) 건축·구조 부재 단위 부재 객체 + 속성 세트

노드-링크 그래프 구조가 중요한 이유는, 지하 시설물의 실제 관심사가 관이 어디 있는가를 넘어 이 관이 막히면 어느 구간이 단수되는가 같은 네트워크 위상 분석이기 때문입니다. 형상만 저장하고 연결 관계를 저장하지 않으면 이런 분석 자체가 불가능해집니다.

 

핵심 개념 3 — BIM-GIS 연계: 서로 다른 세계의 좌표를 맞춥니다

지상 건축물은 BIM(IFC)으로, 지하 시설물과 지형은 GIS(CityGML, 3D Tiles)로 따로 발전해 왔습니다. 지하 주차장, 지하철역, 공동구처럼 두 데이터가 실제로 맞닿는 프로젝트에서는, BIM의 로컬 좌표계를 GIS의 지리 좌표계로 정확히 변환하는 지오레퍼런싱이 필요합니다. 이때 수평 좌표뿐 아니라 수직 기준면까지 맞춰야 한다는 점을 흔히 놓칩니다.

 

예제 — 지하 시설물 충돌 검토 쿼리 (PostGIS 3D)
WITH normalized_pipes AS (
  SELECT
    id, facility_type,
    ST_Translate(geom, 0, 0, depth_offset) AS geom_3d
  FROM underground_facilities
)
SELECT
  a.id AS facility_a, a.facility_type AS type_a,
  b.id AS facility_b, b.facility_type AS type_b,
  ST_3DDistance(a.geom_3d, b.geom_3d) AS clearance_m
FROM normalized_pipes a
JOIN normalized_pipes b ON a.id < b.id
 AND ST_3DDWithin(a.geom_3d, b.geom_3d, 1.0)
WHERE ST_3DDistance(a.geom_3d, b.geom_3d) < 0.3
ORDER BY clearance_m ASC;

이 쿼리는 ST_3DDWithin으로 1차 후보를 좁힌 뒤 정확한 3D 거리를 계산하는 구조라, 데이터 규모가 커져도 계산량을 억제합니다.

 

실무 포인트

오래된 지하시설물 도면의 z값은 그 자체로 신뢰하지 마세요. 실제 굴착·공사 이력이 있는 구간은 최신 실측 데이터로 z값을 갱신해야 3D 모델의 신뢰도가 의미를 갖습니다.

네트워크 위상 없이 형상만 모델링하면 절반의 가치만 얻습니다. 실제 운영에 필요한 영향 범위 분석에는 노드-링크 위상 데이터가 반드시 필요합니다.

주의 — BIM-GIS 연계 프로젝트는 좌표 변환 검증을 초기에 별도 태스크로 분리하세요. 좌표계 불일치는 나중에 발견될수록 되돌리는 비용이 기하급수적으로 커집니다.
