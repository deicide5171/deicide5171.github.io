CSS 트랜지션이 뭔가요 — 부드러운 상태 변화 만들기

프론트엔드

한 줄 요약 — CSS 트랜지션은 상태가 바뀔 때 값이 지정 시간에 걸쳐 부드럽게 변하게 합니다.

 

색이 딱 바뀌어 어색하다

:hover로 색을 바꾸면 값이 순식간에 튀어 딱딱합니다. 트랜지션은 그 변화를 정해진 시간에 걸쳐 부드럽게 이어줍니다. JS 없이 간단한 인터랙션을 만드는 기본 도구입니다.

 

기본 사용법
.button {
  background: #03c75a;
  transition: background 0.3s ease;
}
.button:hover {
  background: #02a94c;   /* 부드럽게 변함 */
}

transition: 속성 시간 이징 형태입니다.

 

자주 쓰는 값
부분 의미 예
property 어떤 속성을 transform, opacity
duration 얼마 동안 0.3s, 200ms
timing 변화 곡선 ease, linear

 

실무 포인트

transform·opacity는 레이아웃을 다시 계산하지 않아 부드럽고 성능이 좋습니다. width·top 같은 값은 렌더링 부담이 큽니다.

주의 — transition: all은 의도치 않은 변화까지 애니메이션되고 성능도 나쁩니다. 대상 속성을 명시하세요.
