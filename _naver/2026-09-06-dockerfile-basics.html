Dockerfile 처음 써보기 — 내 앱을 컨테이너 이미지로 만들기

인프라

한 줄 요약 — Dockerfile은 앱 실행에 필요한 모든 것을 이미지로 굳혀 어디서든 같은 환경을 재현하는 설계도입니다.

 

"내 컴퓨터에선 되는데"를 없애는 법

"내 컴퓨터에선 되는데 서버에선 안 돼요"는 환경 차이 때문입니다. Dockerfile은 코드·런타임·의존성을 하나의 이미지로 굳혀 어디서든 같은 환경을 재현합니다.

 

자주 쓰는 명령
명령 역할
FROM 베이스 이미지(출발점)
COPY / RUN 파일 복사 / 빌드 중 명령 실행
CMD 컨테이너 시작 시 실행

 

예제 — Node.js 앱
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
docker build -t my-app .
docker run -p 8080:3000 my-app

 

실무 포인트

의존성 설치와 소스 복사를 분리하면 빌드 캐시가 잘 먹습니다. package.json을 먼저 복사·설치한 뒤 소스를 복사하면 소스만 바뀔 때 의존성 단계는 캐시를 재사용합니다.

주의 — .dockerignore로 node_modules·.git을 제외하고, alpine 경량 이미지와 멀티스테이지 빌드로 이미지 크기를 줄이세요.
