z-index가 뭔가요 — 요소가 겹칠 때 앞뒤 순서 정하기

프론트엔드

한 줄 요약 — z-index는 요소가 겹칠 때 앞뒤(z축) 순서를 정하며(클수록 위), position이 static이 아니어야 동작합니다.

 

모달이 다른 요소 뒤에 숨는다

팝업을 띄웠는데 다른 요소에 가려 안 보일 때가 있죠. 요소가 겹칠 때 "누가 앞에 보일지"는 z-index로 정합니다. 값이 클수록 앞에 옵니다.

 

기본 개념
.back  { z-index: 1; }   /* 뒤 */
.front { z-index: 10; }  /* 앞(위) */
* position이 static이 아닐 때만 동작

 

왜 큰 값을 줘도 안 먹을까
부모 A(z:1) 안의 자식(z:9999)
부모 B(z:2)
-> A의 자식이 9999여도 B보다 뒤!
   (자식은 부모 A의 쌓임 맥락 안에서만 겨룸)

 

실무 포인트

z-index가 안 먹으면 대부분 position이 static입니다(relative 등을 먼저). 값을 마구 키우지 말고 레이어 단계(모달 1000, 툴팁 1100)를 정해 관리하세요.

주의 — 부모에 transform·opacity·z-index가 있으면 새 쌓임 맥락이 생겨 자식 z-index가 바깥과 직접 안 겨룹니다. 모달이 안 뜨는 흔한 원인입니다.
