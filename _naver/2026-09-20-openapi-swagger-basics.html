API 문서 자동화 — OpenAPI와 Swagger 처음 써보기

백엔드

한 줄 요약 — 코드에서 문서가 자동 생성되므로 손으로 쓴 문서처럼 실제와 어긋날 일이 적습니다.

 

문서와 실제 API가 자꾸 어긋난다면

문서를 손으로 쓰면 API가 바뀔 때마다 따로 고쳐야 하고 곧 실제와 어긋납니다. OpenAPI는 API 명세를 표준 형식으로 기술하는 규격, Swagger는 그 명세로 문서·테스트 UI를 제공하는 도구입니다.

 

해주는 것
기능 설명
문서 자동 생성 코드에서 엔드포인트·응답 추출
인터랙티브 UI 브라우저에서 바로 호출(Try it out)
클라이언트 생성 명세로 호출 코드 자동 생성

 

Spring 적용 예시
// springdoc-openapi 의존성 추가하면 자동 생성
@Operation(summary = "사용자 조회")
@GetMapping("/{id}")
public UserResponse getUser(@PathVariable Long id) { ... }
// -> /swagger-ui.html 에서 대화형 문서 확인

코드가 바뀌면 문서도 자동으로 최신이 됩니다.

 

실무 포인트

손으로 쓰는 문서의 가장 큰 문제(실제와 불일치)를 근본적으로 줄여주는 것이 자동 생성의 핵심 이점입니다.

주의 — Swagger UI를 운영에 그대로 노출하면 API 구조가 공개됩니다. 외부 서비스라면 운영에서는 비활성화하거나 접근을 제한하세요.
