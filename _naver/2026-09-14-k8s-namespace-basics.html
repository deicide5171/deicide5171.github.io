쿠버네티스 네임스페이스가 뭔가요 — 하나의 클러스터를 나눠 쓰기

인프라

한 줄 요약 — 네임스페이스는 하나의 클러스터를 논리적으로 나눠 팀·환경별로 격리하며, 이름 격리·쿼터·접근 제어를 줍니다.

 

한 클러스터에 여러 팀·환경이 섞인다

한 클러스터에 여러 팀 앱이나 개발/운영 환경이 함께 돌면 리소스가 뒤섞이고 이름이 충돌합니다. 네임스페이스는 클러스터를 여러 공간으로 나눠 이를 해결합니다. 큰 사무실을 팀별 구역으로 나누는 셈이죠.

 

무엇을 주나
기능 설명
이름 격리 다른 NS면 같은 이름 가능
리소스 쿼터 NS별 CPU·메모리 상한
접근 제어 NS 단위 권한(RBAC)

 

사용 예
kubectl create namespace dev
kubectl apply -f app.yaml -n dev
kubectl get pods -n prod
# 기본 네임스페이스는 default

 

실무 포인트

dev·staging·prod나 팀별로 나누면 리소스·권한이 분리됩니다. ResourceQuota로 한 NS가 자원을 독점하지 못하게 막으세요. 단, 완전한 보안 격리는 아니라 강한 격리엔 클러스터를 분리합니다.

주의 — 네임스페이스 삭제는 그 안의 모든 리소스를 함께 지웁니다. 운영 네임스페이스 삭제는 매우 위험합니다.
