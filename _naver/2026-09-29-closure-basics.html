클로저가 뭔가요 — 함수가 바깥 변수를 기억하는 원리

프론트엔드

한 줄 요약 — 클로저는 함수가 자신이 선언된 곳의 변수를 기억하는 현상으로, 상태 유지·데이터 은닉에 쓰입니다.

 

함수가 끝났는데 변수가 살아있다?

보통 함수가 끝나면 그 안 변수는 사라집니다. 그런데 함수 안에서 만든 함수가 바깥 함수의 변수를 계속 기억하는 경우가 있죠. 이렇게 함수가 선언된 곳의 변수를 기억하는 것이 클로저입니다.

 

예시로 보기
function makeCounter() {
  let count = 0;
  return function() { count += 1; return count; };
}
const counter = makeCounter();
counter(); // 1
counter(); // 2  (count가 살아서 유지!)

makeCounter는 끝났지만 반환된 함수가 count를 계속 기억해 값이 누적됩니다.

 

무엇에 쓰나
활용 설명
상태 유지 값을 기억(카운터 등)
데이터 은닉 밖에서 직접 못 건드림

 

실무 포인트

클로저 안의 변수는 밖에서 접근 불가라 "비공개 변수" 효과를 냅니다. 예전 var 반복문 클로저 함정은 let으로 해결됩니다.

주의 — 클로저가 큰 데이터를 계속 참조하면 메모리에서 안 지워집니다. 필요 없으면 참조를 끊으세요.
