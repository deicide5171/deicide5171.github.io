Java Optional이 뭔가요 — null을 안전하게 다루기

백엔드

한 줄 요약 — Optional은 "값이 있을 수도 없을 수도 있음"을 타입으로 명시해 NullPointerException을 줄입니다.

 

null이 어디서 튀어나올지 모른다

메서드가 null을 반환할 수 있으면 받는 쪽이 null 체크를 잊고 호출해 NPE가 터집니다. Optional은 "값이 있을 수도, 없을 수도 있다"를 타입으로 명시해 없는 경우를 강제로 다루게 합니다.

 

사용법
Optional<User> findUser(Long id) { ... }
User u = findUser(1L).orElse(defaultUser);   // 없으면 기본값
findUser(1L).ifPresent(u -> print(u));       // 있을 때만
String name = findUser(1L).map(User::getName)
                          .orElse("이름 없음");

 

주요 메서드
메서드 하는 일
orElse(x) 없으면 x
orElseThrow() 없으면 예외
ifPresent / map 있을 때 실행 / 변환

 

실무 포인트

get()은 없으면 예외라 null 체크 안 하는 것과 다를 바 없으니 orElse·ifPresent로 다루세요. Optional은 반환 타입에만 쓰고, 파라미터·필드엔 권장되지 않습니다.

주의 — 리스트가 비어 있을 수 있으면 Optional<List>가 아니라 빈 리스트를 반환하세요. Optional은 단일 값이 없을 수 있을 때 씁니다.
