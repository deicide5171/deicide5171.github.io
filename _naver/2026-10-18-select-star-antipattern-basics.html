SELECT * 를 피하라 — 필요한 컬럼만 조회하기

데이터베이스

한 줄 요약 — SELECT *는 편하지만 불필요한 전송·인덱스 무력화·스키마 취약을 유발하니, 필요한 컬럼만 명시하세요.

 

SELECT * 는 편하지만 대가가 있다

SELECT *는 모든 컬럼을 가져와 타이핑이 편하지만, 실무에선 필요한 컬럼만 명시하는 것이 권장됩니다. 여러 문제를 일으키기 때문입니다.

 

SELECT * 의 문제
문제 설명
불필요한 전송 안 쓰는 컬럼까지 다
인덱스 무력화 커버링 인덱스 못 씀
스키마 취약 컬럼 변경 시 깨짐

 

대신 이렇게
-- 지양
SELECT * FROM users WHERE id = 1;
-- 권장
SELECT id, name, email FROM users WHERE id = 1;

 

실무 포인트

이름만 보여줄 건데 사진·긴 소개글까지 다 가져오면 낭비입니다. 조회 컬럼이 모두 인덱스에 있으면 테이블을 안 봐도 돼(커버링 인덱스) 빠릅니다.

주의 — SELECT * 결과의 컬럼 순서·개수에 코드가 의존하면, 나중에 컬럼이 추가되며 깨집니다. 컬럼을 명시하세요.
