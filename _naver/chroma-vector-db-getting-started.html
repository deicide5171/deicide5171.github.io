벡터 DB 처음 써보기 — Chroma로 시맨틱 검색 만들기

2026. 9. 4. · AI

한 줄 요약 — Chroma는 pip 한 줄로 설치되는 임베디드 벡터 DB로, 텍스트만 넣으면 임베딩이 자동 처리돼 의미로 문서를 검색할 수 있습니다.

 

왜 벡터 DB가 따로 필요한가

임베딩으로 텍스트를 벡터로 바꿨다면, 이제 "질문 벡터와 가장 가까운 문서 벡터를 빠르게 찾는" 저장소가 필요합니다. 수만~수백만 벡터 중 유사한 것을 찾는 연산은 전용 벡터 DB가 훨씬 효율적입니다. Chroma는 별도 서버 없이 파이썬 라이브러리로 바로 쓸 수 있습니다.

 

Chroma의 특징
항목 설명
설치 pip install chromadb 한 줄
임베딩 텍스트만 넣으면 자동 변환
적합한 용도 학습, 프로토타입, 중소 규모

 

예제 — 설치부터 검색까지
import chromadb
client = chromadb.Client()
collection = client.create_collection(name="docs")

collection.add(
    documents=["파이썬은 배우기 쉬운 언어다", "고양이는 잠을 많이 잔다"],
    ids=["doc1", "doc2"],
)

results = collection.query(query_texts=["코딩 언어 추천"], n_results=2)
# -> 파이썬 문서가 상위로 (의미가 가깝기 때문)

"코딩 언어 추천"에 "프로그래밍 언어" 문서가 걸리는 것이 시맨틱 검색의 핵심입니다. 키워드 매칭이라면 못 찾았을 것입니다.

 

실무 포인트

기본 임베딩 함수는 편하지만 한국어 성능이 아쉬울 수 있습니다. 한국어 문서가 많다면 다국어 지원 임베딩 모델을 명시적으로 지정하세요.

주의 — Chroma는 프로토타입에 최적이지만, 수백만 건 이상이거나 고가용성이 필요하면 Qdrant·Pinecone·pgvector를 검토하세요.
