멀티모달 AI가 뭔가요 — 텍스트 말고 이미지·음성도 이해하는 AI

AI

한 줄 요약 — 멀티모달 AI는 텍스트뿐 아니라 이미지·음성·영상을 함께 이해해, 텍스트만으로는 못 하던 작업을 합니다.

 

텍스트만 다루던 AI에서 한 걸음 더

초기 LLM은 텍스트만 다뤘습니다. 멀티모달 AI는 이미지를 보고 설명하거나, 표를 읽어 정리하거나, 음성을 듣고 답합니다. "모달"은 데이터 종류, "멀티"는 여러 개라는 뜻입니다.

 

멀티모달로 할 수 있는 일
사진 올리고 "이게 뭐야?" -> 이미지 이해
손글씨 메모 사진 -> 텍스트 변환·요약
차트 이미지 -> 데이터 표로 정리
화면 스크린샷 -> UI 문제점 지적

 

예제 — 이미지와 텍스트 함께 전달
"content": [
  {"type": "image", "source": {...}},
  {"type": "text", "text": "이 사진에 뭐가 있어?"},
]

content에 이미지와 텍스트를 함께 넣으면 모델이 이미지를 "보고" 질문에 답합니다.

 

실무 포인트

이미지는 토큰을 많이 소모합니다. 고해상도 이미지를 여러 장 넣으면 비용이 빠르게 늘므로 필요한 해상도로 줄이세요. 이미지 이해와 이미지 생성은 별개 기능입니다.

주의 — 멀티모달도 환각을 일으킵니다. 이미지 속 숫자를 잘못 읽을 수 있으니 금액·수치 같은 중요 정보는 사람이 검증하세요.
