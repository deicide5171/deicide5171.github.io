CSS Grid가 뭔가요 — 2차원 레이아웃 시작하기

2026. 9. 19. · 프론트엔드

한 줄 요약 — CSS Grid는 행과 열을 동시에 정의하는 2차원 레이아웃 도구로, 격자 배치에 잘 맞습니다.

 

카드를 격자로 배치하고 싶다

갤러리·대시보드처럼 행과 열이 모두 있는 배치는 Flexbox만으론 번거롭습니다. CSS Grid는 행·열을 동시에 정의해 이런 격자에 잘 맞습니다.

 

기본 사용법
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3등분 열 */
  gap: 16px;                            /* 칸 사이 간격 */
}

fr은 남은 공간을 비율로 나누는 단위입니다. repeat(3, 1fr)로 줄여 쓸 수도 있습니다.

 

자주 쓰는 속성
속성 하는 일
grid-template-columns 열의 개수·너비
gap 칸 사이 간격
grid-column / grid-row 아이템이 차지할 칸 범위

 

반응형 격자
grid-template-columns:
  repeat(auto-fill, minmax(200px, 1fr));

auto-fill + minmax를 쓰면 화면 폭에 맞춰 한 줄 카드 수가 자동으로 바뀝니다. 미디어 쿼리 없이 반응형이 됩니다.

주의 — 2차원 배치는 Grid, 한 줄 안 정렬은 Flexbox가 편합니다. 상황에 맞게 골라 쓰세요.
