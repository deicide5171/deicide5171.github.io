Sass 없이 중첩 셀렉터 쓰기 — CSS Nesting 네이티브 지원 실전 가이드

프론트엔드

한 줄 요약 — CSS Nesting이 표준화되면서 빌드 도구 없이도 순수 CSS 파일에 직접 중첩 선택자를 쓸 수 있게 됐습니다.

 

왜 지금까지 전처리기가 필요했나

관련된 스타일을 시각적으로 묶어서 관리하고 싶어서 Sass나 Less 같은 전처리기가 사실상 표준 도구로 자리 잡았습니다. 문제는 전처리기를 쓰려면 반드시 빌드 단계가 필요하다는 점이었습니다. 이제는 최신 브라우저가 별도 도구 없이 중첩 문법을 직접 지원합니다.

 

 

기본 문법과 주의할 차이
.card {
  padding: 16px;

  & .card-title { font-size: 18px; }
  &:hover { box-shadow: 0 4px 12px rgba(0,0,0,.1); }
}

가상 클래스나 결합자가 앞에 오는 경우는 &가 필수입니다. &를 생략한 자손 선택자 문법은 지원 브라우저 버전에 따라 동작이 갈릴 수 있으니, 팀 컨벤션으로 모든 중첩에 &를 명시하는 규칙을 정해두면 안전합니다.

주의 — 기존 .scss 파일을 그대로 .css로 바꾸면 대부분 실패합니다. @if, @for, 변수 연산 같은 Sass 전용 문법은 네이티브 CSS에 없으므로 파싱 에러가 납니다. 파일 단위로 점진적으로 마이그레이션하세요.

 

실무 포인트

중첩된 선택자는 브라우저가 완전한 선택자 체인으로 풀어서 계산하므로, 중첩이 깊어질수록 명시도가 함께 높아져 나중에 오버라이드하기 어려워집니다. 중첩 깊이는 2~3단계로 제한하고, 구형 브라우저 지원이 필요하다면 PostCSS 플러그인으로 하위 호환을 챙기세요.
