디바운스와 스로틀 — 이벤트가 너무 자주 발생할 때

프론트엔드

한 줄 요약 — 디바운스는 이벤트가 멈춘 뒤 한 번, 스로틀은 일정 시간마다 한 번 실행하며, 검색 자동완성은 디바운스가 적합합니다.

 

이벤트가 너무 자주 발생하는 문제

검색창에 타이핑할 때마다 요청을 보내면 "안녕하세요"를 치는 동안 5번의 요청이 나갑니다. 스크롤은 초당 수십 번 발생합니다. 디바운스와 스로틀은 실행 횟수를 줄이는 기법입니다.

 

디바운스 vs 스로틀
기법 동작
디바운스 멈추고 일정 시간 뒤 한 번
스로틀 일정 시간마다 최대 한 번

 

어디에 무엇을 쓰나
디바운스: 검색 자동완성, resize 완료 후 재계산
스로틀: 무한 스크롤, 실시간 진행률

 

간단한 디바운스 구현
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

clearTimeout으로 이전 예약을 취소하고 새로 예약하는 것이 핵심입니다. 입력이 멈추면 그때 한 번 실행됩니다.

 

실무 포인트

검색 자동완성에 스로틀을 쓰면 중간 결과가 계속 뜨고, 스크롤에 디바운스를 쓰면 멈춰야만 반응해 답답합니다. 목적에 맞게 고르세요.

주의 — React에서는 리렌더링마다 디바운스 함수가 새로 만들어지면 동작하지 않으므로 useCallback/useRef로 유지해야 합니다.
