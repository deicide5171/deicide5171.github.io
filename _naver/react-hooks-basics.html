React useState, useEffect 처음 배우기 — Hooks 기초

2026. 9. 1. · 프론트엔드

한 줄 요약 — useState는 상태 값을 관리하고, useEffect는 렌더링 이후의 부수 효과를 처리하며 의존성 배열로 실행 시점을 제어합니다.

 

왜 일반 변수로는 화면이 안 바뀌나

컴포넌트 함수 안에 일반 변수를 두고 값을 바꿔도 화면은 갱신되지 않습니다. React는 이 값이 바뀌면 다시 그려야 한다는 것을 알 방법이 없기 때문입니다. useState는 이를 React에게 알려주는 훅입니다.

 

useState 기본 사용법
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>현재 카운트: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}

setCount를 호출하면 React가 새 값으로 상태를 갱신하고 다시 렌더링합니다. count = count + 1처럼 직접 바꾸면 화면이 갱신되지 않습니다.

 

useEffect — 렌더링 이후에 할 일
useEffect(() => {
  fetch(`/api/users/${userId}`)
    .then(res => res.json())
    .then(data => setUser(data));
}, [userId]); // userId가 바뀔 때만 재실행

두 번째 인자인 의존성 배열이 핵심입니다. 빠뜨리면 렌더링마다 매번 실행되고, 빈 배열이면 최초 한 번만 실행됩니다.

 

실무 포인트

의존성 배열을 빠뜨리는 것이 초보자가 가장 흔히 하는 실수입니다. ESLint의 react-hooks/exhaustive-deps 규칙을 켜두면 자동으로 경고해줍니다.

useEffect(() => {
  const timer = setInterval(() => console.log('tick'), 1000);
  return () => clearInterval(timer); // 정리 함수
}, []);
주의 — 훅은 컴포넌트 최상위에서만 호출해야 합니다. if문이나 반복문 안에서 호출하면 React가 상태를 추적하지 못해 오류가 납니다.
