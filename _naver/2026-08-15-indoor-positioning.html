실내 지도, GPS 없이 위치를 잡는 방법들

2026. 8. 15. · GIS

한 줄 요약 — 건물 안에서는 GPS가 잘 안 잡히기 때문에, Wi-Fi나 블루투스 비콘, 초광대역(UWB) 신호 같은 다른 방법으로 위치를 찾습니다.

 

공항이나 큰 쇼핑몰에서 길을 잃는 이유

넓은 공항이나 쇼핑몰, 병원에서 스마트폰 지도를 켜봐도 내 위치가 이상하게 표시되는 경험, 한 번쯤 있으실 겁니다. 이는 GPS 신호가 건물 벽과 지붕에 가로막혀 실내에서는 제대로 작동하지 않기 때문입니다. 그래서 실내 공간에서는 GPS를 대신할 여러 실내 측위 기술이 발전해왔습니다.

 

어떤 기술들이 있을까요

아래 표에 정리한 것처럼 여러 기술이 있고, 정확도가 높을수록 설치 비용도 함께 늘어나는 경향이 있습니다. 그래서 필요한 정확도 수준을 먼저 정하는 것이 중요합니다.

기술 원리 특징
Wi-Fi RTT 신호가 오가는 시간 측정 기존 공유기 활용 가능
BLE 비콘 신호 세기로 거리 추정 설치 비용 저렴
지자기 측위 건물 철골이 만드는 자기장 패턴 별도 장비 불필요
UWB 초광대역 신호로 정밀 거리 측정 정확하지만 장비 설치 필요

 

실내 지도는 '층' 개념이 중요합니다

실외 지도와 달리 실내 지도는 같은 위치라도 몇 층인지에 따라 완전히 다른 공간을 가리킵니다. 그래서 애플이 공개한 IMDF(실내지도 표준 포맷) 같은 방식은 건물의 층, 공간, 출입구 등을 표준화된 형식으로 표현합니다.

// IMDF의 층(level) 정보 예시
{
  "type": "Feature",
  "feature_type": "level",
  "properties": {
    "ordinal": 1,
    "name": { "en": "1st Floor" },
    "outdoor": false
  }
}

 

실무 도입 시 이것만은 챙기세요
1. 필요한 정확도부터 정하세요 — 층 안내면 BLE로 충분, 정밀 안내면 UWB가 필요합니다.
2. 환경 요인을 고려하세요 — 신호 세기는 사람 움직임, 금속 구조물에 영향을 받습니다.
3. 유지보수 부담을 확인하세요 — 지자기 측위는 매장 레이아웃이 바뀌면 재작업이 필요합니다.
4. 표준 포맷을 검토하세요 — IMDF 같은 표준을 쓰면 다른 서비스와 연동이 쉬워집니다.

 

마무리 — 3줄 요약

① 실내에서는 GPS 대신 Wi-Fi, BLE, 지자기, UWB 등의 기술로 위치를 찾습니다.
② 정확도가 높아질수록 설치·유지보수 비용도 함께 커집니다.
③ IMDF 같은 표준 포맷을 쓰면 층 개념이 중요한 실내 지도를 체계적으로 관리할 수 있습니다.
