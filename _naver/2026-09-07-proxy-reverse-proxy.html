프록시와 리버스 프록시 차이 — 방향이 반대다

2026. 9. 7. · 인프라

한 줄 요약 — 정방향 프록시는 클라이언트를 대신하고, 리버스 프록시는 서버를 대신합니다 — 방향이 정반대입니다.

 

둘 다 "프록시"인데 왜 다른가

프록시는 "대리인"으로 중간에서 요청을 대신 전달합니다. 정방향 프록시와 리버스 프록시는 "누구를 대신하느냐"가 정반대입니다. 방향을 이해하면 차이가 명확해집니다.

 

방향의 차이
[정방향] 사용자 -> 프록시 -> 인터넷 (사용자를 가림)
[리버스] 사용자 -> 프록시 -> 내부 서버 (실제 서버를 가림)
항목 정방향 리버스
누구를 대신 클라이언트 서버
용도 접근 제어·우회 로드밸런싱·SSL·캐싱

 

리버스 프록시가 하는 일

로드밸런싱(요청 분산), SSL 종료(HTTPS 복호화 담당), 캐싱(응답 캐시), 보안(실제 서버 구조 숨김)입니다.

 

실무 포인트

웹 서비스에서 "프록시"라고 하면 보통 리버스 프록시를 뜻합니다. Nginx를 앱 서버 앞에 두는 구성이 대표적입니다.

주의 — 리버스 프록시 뒤에서는 클라이언트 IP가 가려집니다. 진짜 IP를 알려면 X-Forwarded-For 헤더를 프록시가 넘기고 서버가 읽어야 합니다.
