CSS Flexbox 기초 — justify-content와 align-items 헷갈리지 않기

2026. 9. 2. · 프론트엔드

한 줄 요약 — justify-content는 주축을, align-items는 교차축을 정렬한다는 규칙만 외우면 flex-direction이 바뀌어도 헷갈리지 않습니다.

 

왜 이 두 속성이 항상 헷갈리는가

"가로 정렬은 justify-content인가 align-items인가"를 매번 검색하게 됩니다. 근본 원인은 주축(main axis)과 교차축(cross axis) 개념을 모르고 가로/세로로만 외우려 하기 때문입니다.

 

핵심 개념 — 주축과 교차축
속성 정렬하는 축 기본값(row) 기준
justify-content 주축 가로
align-items 교차축 세로

flex-direction을 column으로 바꾸면 주축이 세로로 바뀌면서 두 속성의 실제 정렬 방향도 서로 뒤바뀝니다.

 

예제 — 정중앙 정렬
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
}

이 두 줄만 있으면 요소를 가로·세로 정중앙에 배치할 수 있습니다.

 

flex-direction을 바꾸면 생기는 변화
/* row: justify-content가 가로 */
.row { flex-direction: row; justify-content: space-between; }

/* column: justify-content가 세로로 바뀜! */
.column { flex-direction: column; justify-content: space-between; }

 

실무 포인트

특정 자식만 다르게 정렬하고 싶으면 그 자식에 align-self를 지정하세요. align-items는 모든 자식에 적용됩니다.

주의 — gap 속성을 쓰면 마진 계산 없이 간단히 간격을 줄 수 있습니다. 예전 마지막 요소 마진 제거 트릭은 이제 필요 없습니다.
