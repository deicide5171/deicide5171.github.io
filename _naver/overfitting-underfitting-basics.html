과적합과 과소적합이 뭔가요 — 모델이 배우는 두 실패

2026. 9. 20. · AI

한 줄 요약 — 과소적합은 덜 배워 다 약하고, 과적합은 외워서 학습만 잘하고 새 데이터엔 약합니다.

 

연습은 다 맞는데 시험은 틀린다

학습 데이터만 외워 새 데이터엔 약한 과적합(overfitting), 패턴을 아예 못 배워 학습 데이터조차 못 맞히는 과소적합(underfitting)이 대표적 두 실패입니다.

 

두 실패 비교
구분 학습 새 데이터
과소적합 낮음 낮음
적절 좋음 좋음
과적합 매우 높음 낮음 
과소적합: 연습·시험 다 못 봄 (덜 배움)
과적합:   연습만 만점, 시험 폭망 (외움)
목표:     둘 다 무난 (일반화)

 

실무 포인트

검증셋 성능이 학습셋보다 크게 낮으면 과적합 신호입니다. 과적합은 데이터 증강·규제·드롭아웃·조기 종료로, 과소적합은 모델 강화·특징 추가로 대처합니다.

주의 — 학습 성능만 보면 과적합을 놓칩니다. 반드시 검증셋 성능으로 판단하세요.
