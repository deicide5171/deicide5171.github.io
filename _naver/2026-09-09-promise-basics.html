프로미스(Promise)가 뭔가요 — 자바스크립트 비동기의 기본

2026. 9. 9. · 프론트엔드

한 줄 요약 — 프로미스는 나중에 완료될 비동기 작업의 결과를 담는 약속 상자이며, then(성공)·catch(실패)로 결과를 받습니다.

 

결과가 나중에 오는 작업을 어떻게 다루나

서버에서 데이터를 받는 작업은 시간이 걸립니다. JS는 기다리며 멈추지 않고 다음 코드를 실행하죠(비동기). 그럼 결과는 어떻게 받을까요? 프로미스는 "나중에 완료될 작업의 결과를 담는 약속 상자"입니다. 끝나면 성공값이나 실패 이유가 담깁니다.

 

프로미스의 3가지 상태
상태 의미
대기(pending) 아직 결과 없음
이행(fulfilled) 성공, 결과값 있음
거부(rejected) 실패, 에러 이유 있음

 

then/catch와 async/await
fetch('/api/user')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.log('실패:', err));

// async/await 버전
async function loadUser() {
  try {
    const res = await fetch('/api/user');
    console.log(await res.json());
  } catch (err) { console.log('실패:', err); }
}

 

실무 포인트

catch/try-catch가 없으면 실패가 조용히 묻힙니다. 독립적인 요청 여러 개는 await를 하나씩 하지 말고 Promise.all([...])로 병렬 처리하면 훨씬 빠릅니다. await는 async 함수 안에서만 씁니다.

주의 — 네트워크 요청은 언제든 실패할 수 있습니다. 에러 처리(catch)를 빼먹지 마세요.
