Helm이 뭔가요 — 쿠버네티스의 패키지 매니저

2026. 9. 13. · 인프라

한 줄 요약 — Helm은 여러 쿠버네티스 리소스를 차트로 묶어 설치·업그레이드·롤백을 한 줄로 하는 패키지 매니저입니다.

 

YAML이 수십 개가 되면 관리가 안 된다

앱 하나 배포에 Deployment·Service·ConfigMap·Ingress 등 YAML이 여럿 필요하고 환경마다 값도 다릅니다. Helm은 이를 하나의 패키지(차트)로 묶어 명령 한 줄로 관리합니다. apt·npm 같은 역할이죠.

 

핵심 개념
용어 설명
Chart 리소스 묶음 패키지
Values 환경별 설정값
Release 설치한 인스턴스

 

사용 흐름
helm install myapp ./mychart   # 설치
helm upgrade myapp ./mychart   # 업그레이드
helm rollback myapp 1          # 롤백
helm uninstall myapp           # 삭제

 

실무 포인트

PostgreSQL·Redis 등은 공개 차트로 helm install 한 줄로 설치됩니다. values-dev/prod.yaml로 환경을 분리하고, 업그레이드가 잘못되면 helm rollback으로 되돌리세요.

주의 — 공개 차트도 기본값이 운영에 안 맞을 수 있습니다. values로 리소스·복제 수 등을 환경에 맞게 조정하세요.
