SQL COALESCE와 NULLIF가 뭔가요 — NULL 다루는 두 함수

데이터베이스

한 줄 요약 — COALESCE는 NULL을 기본값으로, NULLIF는 특정 값을 NULL로 바꿉니다.

 

NULL 때문에 결과가 이상하다

NULL을 원하는 값으로 대체하거나, 반대로 특정 값을 NULL로 바꾸고 싶을 때 COALESCE와 NULLIF를 씁니다.

 

COALESCE — 첫 non-NULL
COALESCE(nickname, name, '이름없음')
-- 앞에서부터 처음 만나는 non-NULL 반환

SELECT SUM(COALESCE(amount, 0)) FROM orders;
-- NULL을 0으로 채워 합계
NULLIF — 같으면 NULL
NULLIF(value, 0)   -- value가 0이면 NULL

SELECT total / NULLIF(count, 0) FROM stats;
-- count=0이면 NULL → 0으로 나누기 에러 방지

 

언제 무엇인가
함수 동작
COALESCE 첫 non-NULL 반환(NULL→대체값)
NULLIF 같으면 NULL(특정 값→NULL)

 

실무 포인트

분모를 NULLIF(x, 0)으로 감싸면 0일 때 에러 대신 NULL이 나옵니다. 집계·표시 전엔 COALESCE로 NULL을 채웁니다.

주의 — COALESCE는 SQL 표준이라 이식성이 좋습니다. ISNULL·IFNULL은 특정 DB 전용입니다.
