DNS는 어떻게 동작하나 — 도메인이 IP로 바뀌는 과정

인프라

한 줄 요약 — DNS는 도메인 이름을 IP 주소로 바꿔주는 인터넷의 전화번호부이며, TTL 때문에 변경이 즉시 반영되지 않습니다.

 

왜 도메인을 IP로 바꿔야 하나

컴퓨터는 IP 주소로 서로를 찾지만 사람은 숫자를 외우기 어렵습니다. DNS는 example.com 같은 도메인을 실제 IP로 변환해주는 전화번호부입니다.

 

도메인이 IP로 바뀌는 과정
1. 브라우저·OS 캐시 확인
2. 없으면 DNS 리졸버에 질의
3. 루트 -> TLD(.com) -> 권한 서버 순으로 물어봄
4. 최종 IP를 받아 연결 (수십 ms 안에)

 

자주 나오는 DNS 레코드
레코드 의미
A / AAAA 도메인 → IPv4 / IPv6
CNAME 도메인 → 다른 도메인(별칭)
MX / TXT 메일 서버 / 텍스트 정보

 

TTL과 캐싱
TTL = 3600 (1시간) -> 1시간 동안 캐시된 IP를 그대로 씀
-> 도메인 IP를 바꿔도 즉시 반영 안 됨

 

실무 포인트

서버 IP를 바꾸기 전에 TTL을 미리 낮추세요. 며칠 전 TTL을 300초로 줄여두면 변경 시 캐시가 빨리 갱신됩니다.

주의 — "DNS 전파"는 즉시 되지 않습니다. "왜 아직 옛 사이트가 보이지"는 대부분 캐시가 아직 TTL을 안 지난 것입니다.
