@Value와 @ConfigurationProperties — 스프링에서 설정값 읽기

2026. 9. 10. · 백엔드

한 줄 요약 — 설정값은 코드에 박지 말고 application.yml에 두고 읽어오며, 단순 값은 @Value·묶음은 @ConfigurationProperties를 씁니다.

 

설정값을 코드에 박아 넣지 마라

API 키·서버 주소·페이지 크기를 코드에 직접 쓰면 바꿀 때마다 다시 빌드해야 합니다. 스프링은 이런 값을 application.yml에 두고 @Value 또는 @ConfigurationProperties로 읽어옵니다.

 

@Value vs @ConfigurationProperties
구분 @Value @ConfigurationProperties
방식 값 하나씩 객체로 묶음
적합 단순 값 몇 개 그룹화된 설정

 

예시
# application.yml
app:
  name: myservice
  page-size: 20

@Value("${app.page-size}")
private int pageSize;

@ConfigurationProperties(prefix = "app")
public class AppProps { private String name; private int pageSize; }

 

실무 포인트

비밀값은 yml 평문 대신 환경 변수·시크릿 매니저로 주입하세요. @Value("${app.timeout:5000}")처럼 기본값을 지정할 수 있고, 환경별 파일(application-dev/prod.yml)로 분리해 프로파일로 전환합니다.

주의 — API 키·비밀번호를 application.yml에 평문으로 넣고 깃에 올리면 유출됩니다. 참조만 두고 값은 외부에서 주입하세요.
