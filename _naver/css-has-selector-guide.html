CSS :has() 선택자로 부모 요소 스타일링하기

프론트엔드

한 줄 요약 — CSS :has() 선택자를 쓰면 자식 요소의 상태를 보고 부모 스타일을 바꾸는 작업을, 자바스크립트 없이 순수 CSS만으로 처리할 수 있습니다.

 

왜 지금 알아야 하는가

"체크박스가 체크되면 부모 카드에 테두리를 넣고 싶다"는 요구사항은 흔하지만, CSS는 오랫동안 자식 조건을 보고 부모를 선택하는 방법이 없었습니다. 그래서 대부분 자바스크립트로 클래스를 토글해서 우회했습니다. 이제 주요 브라우저가 모두 :has()를 지원하면서 이 제약이 풀렸습니다.

 

기본 문법
/* 이미지를 포함한 카드에만 특별한 패딩 적용 */
.card:has(img) {
  padding: 0;
}

/* 체크된 체크박스를 포함한 라벨의 배경색 변경 */
label:has(input:checked) {
  background-color: #e8f5e9;
}

기존 자손 결합자, 형제 결합자, 속성 선택자를 :has() 괄호 안에 그대로 쓸 수 있어 표현력이 매우 넓습니다.

 

자바스크립트 방식 vs :has() 방식

기존에는 폼 유효성 표시도 input.addEventListener로 클래스를 토글하는 식이었습니다. 스타일링 로직이 CSS와 JS 두 곳에 흩어지고, 서버 사이드 렌더링 환경에서는 하이드레이션 전까지 스타일이 적용되지 않아 화면이 잠깐 깨져 보이는 문제도 생겼습니다.

.form-group:has(input:invalid:not(:placeholder-shown)) {
  border-color: #d32f2f;
}
.form-group:has(input:valid) {
  border-color: #2e7d32;
}

이렇게 하면 이벤트 리스너 없이 브라우저의 네이티브 유효성 검사 상태만으로 스타일이 즉시 반영됩니다. 렌더링 전에 이미 결정되므로 하이드레이션 지연으로 인한 깜빡임도 없습니다.

주의 — :has()는 매칭 비용이 다른 선택자보다 높습니다. html:has(...)처럼 매우 넓은 범위로 걸면 리플로우 비용이 늘 수 있으니 범위를 좁혀서 사용하세요.

 

실무 포인트

body:has(.modal-open)처럼 최상위 요소에 걸어서 모달이 열렸을 때 배경 스크롤을 막는 패턴도 자바스크립트 없이 구현 가능합니다. 쉼표로 여러 조건을 나열하거나 :nth-child와 조합해 "항목이 5개 이상이면 스크롤 컨테이너로 전환" 같은 조건부 레이아웃도 처리할 수 있습니다. 다만 구형 브라우저 지원이 필요하다면 @supports selector(:has(a))로 감지 후 자바스크립트 폴백을 병행하세요.
