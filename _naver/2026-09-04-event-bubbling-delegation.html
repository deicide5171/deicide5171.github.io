이벤트 버블링과 이벤트 위임 — 자바스크립트 이벤트 기초

2026. 9. 4. · 프론트엔드

한 줄 요약 — 이벤트는 발생 요소에서 부모로 위로 전파(버블링)되며, 이를 이용해 부모 하나에만 핸들러를 다는 것이 이벤트 위임입니다.

 

자식을 클릭했는데 부모 핸들러가 실행되는 이유

버튼을 클릭했는데 감싼 div의 핸들러까지 실행되는 것은 버그가 아니라 이벤트 버블링 때문입니다. 이벤트가 부모 → 조부모 순으로 위로 전파됩니다.

 

버블링의 흐름
button 클릭 -> button 핸들러 실행 -> parent 핸들러도 실행

// 전파를 막으려면
event.stopPropagation();

 

버블링을 활용한 이벤트 위임
// 나쁜 방법: 항목마다 핸들러 100개
items.forEach(i => i.addEventListener('click', fn));

// 좋은 방법: 부모에 하나만
list.addEventListener('click', (e) => {
  const item = e.target.closest('.item');
  if (item) console.log(item.dataset.id);
});

 

이벤트 위임의 장점
장점 설명
성능 핸들러 하나로 수많은 자식 처리
동적 요소 나중에 추가된 항목도 자동 처리

e.target은 실제 클릭된 요소를, e.currentTarget은 핸들러가 달린 부모를 가리킵니다.

 

실무 포인트

AJAX로 나중에 그려지는 목록에는 이벤트 위임이 거의 필수입니다. 직접 핸들러를 달면 나중에 추가된 항목엔 핸들러가 없습니다.

주의 — stopPropagation()을 습관적으로 쓰지 마세요. 버블링을 막으면 위에서 이벤트 위임으로 처리하려던 로직이 동작하지 않을 수 있습니다.
