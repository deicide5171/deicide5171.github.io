CSS 박스 모델이 뭔가요 — margin, padding, border의 관계

2026. 9. 17. · 프론트엔드

한 줄 요약 — 박스 모델은 모든 요소가 content→padding→border→margin 층으로 된 사각형 박스라는 개념입니다.

 

요소는 모두 사각형 박스다

CSS에서 모든 요소는 사각형 박스입니다. 안쪽부터 내용→padding(안쪽 여백)→border(테두리)→margin(바깥 여백) 층으로 이뤄지죠. 레이아웃이 뜻대로 안 되면 대부분 이 관계로 풀립니다.

 

네 층
영역 설명
content 실제 내용
padding 안쪽 여백
border / margin 테두리 / 바깥 여백

 

크기 계산 (box-sizing)
content-box: width:100 + padding:20 + border:2 = 124px
border-box:  width:100이면 실제로도 100px
-> 대부분 box-sizing: border-box 권장

 

실무 포인트

보통 전역으로 * { box-sizing: border-box }를 걸어 "width가 곧 실제 너비"가 되게 합니다. 배경색은 padding까지 칠해지고 margin엔 안 칠해집니다(안쪽=padding, 사이=margin).

주의 — 위아래로 인접한 두 요소의 세로 margin은 합쳐지지 않고 큰 값 하나로 겹쳐집니다(margin collapse). 간격이 이상하면 의심하세요.
