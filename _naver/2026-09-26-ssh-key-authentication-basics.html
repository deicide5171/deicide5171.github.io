SSH 키 인증이 뭔가요 — 비밀번호 없이 서버 접속하기

인프라

한 줄 요약 — SSH 키 인증은 비밀번호 대신 공개키·개인키 쌍으로 신원을 증명하며, 개인키는 내 PC에만·공개키는 서버에 등록합니다.

 

매번 비밀번호를 치기 싫다면

SSH 접속마다 비밀번호를 입력하는 건 번거롭고 무차별 대입 공격에도 취약합니다. SSH 키 인증은 비밀번호 대신 한 쌍의 키로 신원을 증명합니다. 한 번 설정하면 비밀번호 없이 안전하게 접속할 수 있습니다.

 

공개키와 개인키
키 위치 역할
개인키 내 PC에만 열쇠(공유 금지)
공개키 서버에 등록 자물쇠(공유 OK)

 

설정 3단계
1. ssh-keygen -t ed25519 -C "my@email.com"
   -> id_ed25519(개인키), id_ed25519.pub(공개키)
2. ssh-copy-id user@server   # 공개키 등록
3. ssh user@server           # 비밀번호 없이 접속

 

실무 포인트

개인키가 새면 누구나 내 신원으로 접속합니다. 깃에 커밋되지 않게 .gitignore로 막고 키에 암호(passphrase)를 거세요. 키 인증 후엔 서버의 PasswordAuthentication no로 비밀번호 로그인을 막으면 더 안전합니다.

주의 — 개인키는 절대 공유·커밋하지 마세요. 실수로 깃 저장소에 올리면 즉시 폐기하고 새 키를 발급해야 합니다.
