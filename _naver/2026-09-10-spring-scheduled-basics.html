@Scheduled 입문 — 스프링에서 정해진 시간에 작업 실행하기

2026. 9. 10. · 백엔드

한 줄 요약 — @Scheduled는 메서드에 애너테이션을 붙여 정해진 주기·시각에 자동 실행하며, fixedRate·fixedDelay·cron으로 방식을 정합니다.

 

매일 자정에 자동으로 실행하고 싶다면

"매일 자정 정산", "10분마다 정리" 같은 반복 작업은 사람이 직접 돌릴 수 없죠. @Scheduled는 메서드에 애너테이션만 붙이면 정해진 시간·주기로 자동 실행해줍니다. 별도 스케줄러 서버 없이 앱 안에서 동작합니다.

 

세 가지 실행 방식
속성 의미
fixedRate 시작 시각 기준 N ms마다
fixedDelay 이전 작업 끝난 뒤 N ms 후
cron 크론 표현식으로 특정 시각

 

사용 예시
@Scheduled(fixedRate = 600000)   // 10분마다
public void cleanTemp() { ... }

@Scheduled(cron = "0 0 0 * * *")  // 매일 0시
public void dailySettle() { ... }
// 설정 클래스에 @EnableScheduling 필요

 

실무 포인트

fixedRate는 이전 작업이 안 끝나도 시작해 겹칠 수 있으니, 겹침이 곤란하면 fixedDelay를 쓰세요. 예외는 조용히 묻힐 수 있으니 내부에서 try-catch로 로그를 남기세요.

주의 — 앱을 여러 인스턴스로 띄우면 같은 스케줄이 중복 실행됩니다. 분산 환경에선 ShedLock 같은 도구로 한 번만 실행되게 잠그세요.
