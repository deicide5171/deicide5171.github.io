자바스크립트 전개/나머지(...) 연산자가 뭔가요

2026. 9. 19. · 프론트엔드

한 줄 요약 — ...는 만드는 쪽에선 전개(펼치기), 받는 쪽에선 나머지(모으기)로 동작합니다.

 

어떨 땐 펼치고 어떨 땐 모은다?

...는 같은 기호지만 위치에 따라 반대로 동작합니다. 값을 펼칠 땐 전개(spread), 여러 값을 모을 땐 나머지(rest)입니다.

 

전개(spread) — 펼치기
const b = [...a, 3, 4];              // 배열 합치기
const updated = { ...user, age: 20 };// 객체 병합
Math.max(...[3, 1, 5]);              // 인자로 펼치기 → 5
나머지(rest) — 모으기
function sum(...nums) {              // 인자를 배열로 모음
  return nums.reduce((a, b) => a + b, 0);
}
const [first, ...others] = [1, 2, 3];// others=[2,3]

 

언제 무엇인가
위치 의미
만드는 쪽(우변·인자) 전개(펼치기)
받는 쪽(파라미터·좌변) 나머지(모으기)

 

실무 포인트

{...state, key: value}로 기존 상태를 건드리지 않고 새 객체를 만드는 불변 업데이트에 핵심 도구입니다.

주의 — 객체 전개는 얕은 복사라 중첩 객체는 참조를 공유합니다. rest의 ...는 항상 마지막에 와야 합니다.
