SPA와 MPA 차이 — 페이지 전환 방식이 다르다

프론트엔드

한 줄 요약 — MPA는 페이지마다 새 HTML을, SPA는 JS로 화면만 바꾸며, 상호작용 많은 앱은 SPA·콘텐츠 사이트는 MPA가 적합합니다.

 

페이지를 넘길 때 새로고침되나 안 되나

링크를 눌러 화면이 하얗게 깜빡이며 새로고침되면 MPA, 깜빡임 없이 부드럽게 바뀌면 SPA입니다. MPA는 서버에서 새 HTML을, SPA는 하나의 페이지에서 JS로 화면만 바꿉니다.

 

SPA vs MPA
항목 SPA MPA
전환 JS로 화면 교체 서버에서 새 HTML
이후 전환 빠름 매번 서버 왕복
SEO 별도 대응 필요 유리

 

각 방식의 동작
MPA: 클릭 -> 서버 요청 -> 새 HTML -> 전체 새로고침
SPA: 클릭 -> 데이터만 받아옴 -> 화면 일부만 교체

 

실무 포인트

SPA는 SEO에 불리할 수 있어 SSR/SSG로 보완합니다. Next.js 같은 프레임워크가 이 조합을 제공합니다. 첫 로딩 성능을 위해 코드 분할도 중요합니다.

주의 — 모든 사이트가 SPA일 필요는 없습니다. 블로그·문서처럼 콘텐츠 중심이면 MPA·정적 사이트가 SEO·초기 로딩에 유리합니다.
