Lombok이 뭔가요 — 게터·세터 반복을 없애주는 라이브러리

백엔드

한 줄 요약 — Lombok은 게터·세터·생성자·toString 같은 반복 코드를 애너테이션으로 자동 생성해주는 자바 라이브러리입니다.

 

게터·세터를 매번 손으로 써야 하나

필드가 10개면 게터·세터가 20개, 생성자·toString·equals까지 더하면 코드가 수십 줄이 됩니다. 정작 중요한 로직이 파묻히죠. Lombok은 이런 반복 코드를 애너테이션 하나로 자동 생성해줍니다.

 

자주 쓰는 애너테이션
애너테이션 자동 생성
@Getter / @Setter 게터 / 세터
@ToString toString()
@Data 여러 개를 한 번에

 

사용 예시
@Getter @Setter
public class User {
    private Long id;
    private String name;
    private String email;
}
// getId(), setName() 등이 컴파일 시 자동 생성

 

실무 포인트

@Data는 세터까지 다 만들어 객체를 아무 데서나 바꾸게 하니 신중히 쓰세요. IDE가 자동 생성 코드를 인식하려면 Lombok 플러그인 설치가 필요합니다.

주의 — JPA 엔티티에 @ToString 전체를 걸면 연관 엔티티를 줄줄이 조회하거나 무한 순환에 빠질 수 있습니다. 연관 필드는 제외하세요.
