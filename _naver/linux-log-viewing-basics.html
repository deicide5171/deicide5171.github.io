리눅스에서 로그 보기 — tail, grep으로 원인 찾기

2026. 9. 18. · 인프라

한 줄 요약 — 서버 문제의 첫 단서는 로그이며, tail -f(실시간)·grep(키워드 필터)으로 원인을 빠르게 찾습니다.

 

서버가 이상할 때 어디를 보나

문제가 생기면 가장 먼저 볼 곳은 로그입니다. 하지만 수만 줄이라 그냥 열면 못 봐요. 리눅스의 로그 명령 몇 가지만 익히면 원인을 빠르게 찾습니다.

 

자주 쓰는 명령
명령 하는 일
tail -f 실시간으로 보기
grep ERROR ERROR 든 줄만
less 페이지 단위로

 

조합 활용
tail -f app.log | grep ERROR   # 실시간 에러만
grep -C 3 "NullPointer" app.log # 앞뒤 3줄 맥락
grep "2026-09-18 14:" app.log   # 특정 시간대

 

실무 포인트

문제를 재현하며 tail -f로 실시간 로그를 보면 어느 동작에서 무슨 로그가 나오는지 바로 압니다(종료 Ctrl+C). grep -i(대소문자)·-C(맥락)가 유용합니다.

주의 — 컨테이너는 파일 로그가 아니라 표준출력입니다. docker logs -f·kubectl logs -f로 보세요.
