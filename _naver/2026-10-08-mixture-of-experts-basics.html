MoE(전문가 혼합)가 뭔가요 — 큰 모델을 효율적으로 돌리는 구조

AI

한 줄 요약 — MoE는 여러 전문가 중 라우터가 고른 일부만 계산해, 모델은 크게 유지하며 추론 비용을 줄이는 구조입니다.

 

모델이 커지면 느리고 비싸다

일반 LLM은 답 하나에 모든 파라미터를 다 씁니다. 커질수록 정확하지만 느리고 비싸지죠. MoE는 여러 '전문가' 중 일부만 골라 써, 모델은 크게 유지하면서 실제 계산량을 줄입니다.

 

일반 모델 vs MoE
구분 일반(dense) MoE
사용 파라미터 매번 전부 일부 전문가만
실제 계산량 큼 상대적 적음

 

동작 개념
여러 전문가 신경망 + 라우터(선택기)
1. 라우터가 "이 입력엔 3, 7번 전문가" 판단
2. 선택된 전문가만 계산 (나머지 쉼)
3. 결과를 합쳐 출력

 

실무 포인트

"전체 파라미터"는 크지만 한 번에 쓰는 "활성 파라미터"는 적어, 성능은 큰 모델급·속도는 작은 모델급을 노립니다. API 사용자는 "왜 큰 모델인데 빠르고 저렴한가"의 배경으로 알아두면 됩니다.

주의 — 계산량은 줄어도 모든 전문가를 메모리에 올려야 해, 메모리(VRAM)는 전체 크기만큼 듭니다.
