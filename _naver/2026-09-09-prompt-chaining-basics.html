AI

한 줄 요약 — 프롬프트 체이닝은 복잡한 작업을 여러 단계로 쪼개, 한 단계 출력을 다음 입력으로 넘겨 품질과 안정성을 높입니다.

 

한 프롬프트에 다 시키면 품질이 떨어진다

"요약하고 번역하고 트윗용으로 줄여줘"를 한 번에 시키면 AI가 중간 단계를 대충 넘기기 쉽습니다. 프롬프트 체이닝은 복잡한 작업을 여러 단계로 쪼개, 한 단계의 출력을 다음 단계의 입력으로 넘기는 방식입니다.

 

한 방에 vs 체이닝
방식 특징
한 프롬프트에 전부 간단하나 품질 저하·통제 어려움
체이닝 단계별 확인·수정, 품질 향상

 

흐름 예시
1단계: 기사 -> "핵심 3가지 요약" -> 요약
2단계: 요약 -> "영어로 번역" -> 번역
3단계: 번역 -> "280자 트윗으로" -> 최종
각 단계 출력이 다음 단계 입력이 된다.

 

실무 포인트

단계마다 출력을 검증·보정하거나 재시도할 수 있어 신뢰도가 높습니다. 단계별로 다른 설정(요약은 낮은 temperature 등)도 가능합니다. 다만 각 단계가 LLM 호출이라 비용·지연이 늘어납니다.

주의 — 단계가 많을수록 비용·시간이 늘어납니다. 꼭 필요한 만큼만 쪼개고, 병렬 가능한 단계는 병렬화하세요.
