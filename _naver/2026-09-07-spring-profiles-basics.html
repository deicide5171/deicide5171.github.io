개발·운영 설정 분리하기 — Spring 프로파일 기초

백엔드

한 줄 요약 — Spring 프로파일은 환경별 설정을 파일로 분리하고 실행 시 활성 프로파일만 지정해 코드 변경 없이 환경을 전환합니다.

 

로컬 DB와 운영 DB 주소가 다른데

환경마다 DB 주소·로그 레벨이 다릅니다. 코드에 하드코딩하거나 배포할 때마다 바꾸면 실수가 생깁니다. Spring 프로파일은 환경별 설정을 파일로 분리해 실행 시 어느 환경인지만 지정하면 됩니다.

 

프로파일별 설정 파일
application.yml          # 공통
application-local.yml    # 로컬
application-prod.yml     # 운영

활성 프로파일 = 공통 + 해당 프로파일 설정
# application-prod.yml
spring:
  datasource:
    url: jdbc:mysql://prod-db.internal:3306/mydb
logging:
  level:
    root: INFO

 

프로파일 활성화
java -jar app.jar --spring.profiles.active=prod
# 또는
export SPRING_PROFILES_ACTIVE=prod

코드는 그대로 두고 실행 옵션만 바꾸면 환경이 전환됩니다.

 

실무 포인트

운영 비밀번호·키는 설정 파일에 넣지 마세요. 저장소에 올리면 유출됩니다. 환경변수나 시크릿 매니저로 주입받으세요.

주의 — 배포 시 프로파일 지정을 빠뜨리면 개발 설정으로 운영 서버가 뜨는 사고가 납니다. 배포 스크립트에서 반드시 확인하세요.
