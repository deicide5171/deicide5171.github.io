@Qualifier가 뭔가요 — 같은 타입 빈이 여러 개일 때 고르기

백엔드

한 줄 요약 — 같은 타입 빈이 여러 개면 주입이 애매해지는데, @Qualifier로 어느 빈을 쓸지 이름으로 지정합니다.

 

"어느 빈을 주입할지 모르겠다" 오류

인터페이스 하나에 구현체가 둘(KakaoPay·NaverPay 모두 PayService)이면, PayService 주입 시 "어느 것?" 오류가 납니다. @Qualifier는 여러 후보 중 어느 빈을 쓸지 이름으로 지정해 해결합니다.

 

해결 방법
방법 설명
@Qualifier("이름") 주입 지점에서 특정 빈 지정
@Primary 기본으로 쓸 것 하나 표시

 

예시
@Service("kakao") class KakaoPay implements PayService {}
@Service("naver") class NaverPay implements PayService {}

public OrderService(@Qualifier("kakao") PayService pay) {
    // KakaoPay가 주입됨
}

 

실무 포인트

대부분 하나를 기본으로 쓴다면 기본에 @Primary, 예외 상황만 @Qualifier로 지정하면 깔끔합니다. 구현체마다 의미 있는 이름을 붙이세요. 전략 패턴과 잘 어울립니다.

주의 — 같은 타입 빈이 여러 개인데 @Primary도 @Qualifier도 없으면 앱이 시작 단계에서 실패합니다.
