자바스크립트 this가 뭔가요 — 호출 방법이 값을 정한다

프론트엔드

한 줄 요약 — this는 선언 위치가 아니라 "어떻게 호출했느냐"로 값이 정해지며, 화살표 함수는 바깥 this를 그대로 씁니다.

 

this가 매번 다른 걸 가리킨다

자바스크립트 this는 "선언한 위치"가 아니라 "어떻게 호출했느냐"에 따라 값이 정해집니다. 그래서 같은 함수라도 호출 방법에 따라 this가 달라집니다.

 

호출 방식별 this
호출 this
obj.fn() 그 객체(obj)
일반 호출 전역/undefined
화살표 함수 바깥 this(고정)

 

예시
const user = { name:"철수", greet(){ console.log(this.name); } };
user.greet();       // "철수" (obj.method -> this=user)
const fn = user.greet;
fn();               // undefined (this 연결 끊김!)

 

실무 포인트

setTimeout·이벤트 핸들러 같은 콜백엔 화살표 함수를 쓰면 바깥 this를 유지해 문제가 줍니다. 메서드를 떼어 넘길 땐 bind(obj)로 묶거나 () => obj.method()로 감싸세요.

주의 — obj.method를 콜백으로 그냥 넘기면 this 연결이 끊깁니다. bind로 묶어 넘기세요.
