도커 이미지 레이어가 뭔가요 — 이미지가 층으로 쌓이는 구조

2026. 9. 15. · 인프라

한 줄 요약 — 도커 이미지는 Dockerfile 명령마다 만들어진 여러 레이어가 쌓인 구조이며, 안 바뀐 레이어는 빌드 캐시로 재사용됩니다.

 

도커 이미지는 한 덩어리가 아니다

도커 이미지는 통짜 파일이 아니라 여러 층(레이어)이 쌓인 구조입니다. Dockerfile의 각 명령(RUN·COPY)이 레이어를 만듭니다. 이 구조를 알면 빌드 속도·이미지 크기를 이해할 수 있습니다.

 

레이어 구조
FROM node:20         <- 베이스 레이어
COPY package.json .  <- 레이어 1
RUN npm install      <- 레이어 2
COPY . .             <- 레이어 3
각 명령이 이전 레이어 위에 새 층을 얹음

 

빌드 캐시
상황 동작
레이어 안 바뀜 캐시 재사용(빠름)
레이어 바뀜 그 레이어부터 다시

 

실무 포인트

자주 바뀌는 것을 뒤에 두세요. package.json을 먼저 복사·install 후 소스를 나중에 복사하면, 코드만 바꿔도 무거운 install은 캐시를 재사용합니다. .dockerignore로 크기도 줄이세요.

주의 — 앞쪽 레이어가 바뀌면 그 뒤 레이어의 캐시가 모두 무효화됩니다. 자주 바뀌는 COPY를 앞에 두면 매번 전체가 다시 빌드됩니다.
