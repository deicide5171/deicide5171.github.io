얕은 복사와 깊은 복사가 뭔가요 — 객체 복사의 함정

2026. 9. 12. · 프론트엔드

한 줄 요약 — 얕은 복사({...obj})는 1단계만, 깊은 복사(structuredClone)는 중첩까지 별도로 복사합니다.

 

복사했는데 원본이 같이 바뀐다

객체를 복사해 값을 바꿨더니 원본까지 바뀌는 경험이 있죠. 자바스크립트 객체는 값이 아니라 참조(주소)로 다뤄지기 때문입니다. 복사엔 얕은 복사와 깊은 복사가 있고, 차이를 모르면 버그가 납니다.

 

얕은 복사 vs 깊은 복사
구분 얕은 복사 깊은 복사
중첩 객체 참조 공유(같이 바뀜) 완전 별도
방법 {...obj} structuredClone

 

예시
const a = { name:"철수", info:{ age:20 } };
const b = { ...a };            // 얕은 복사
b.info.age = 99;
console.log(a.info.age);       // 99 (원본도 바뀜!)
const c = structuredClone(a);  // 깊은 복사
c.info.age = 50;
console.log(a.info.age);       // 99 (원본 안 바뀜)

 

실무 포인트

1단계 값만 있는 평평한 객체는 {...obj}로 충분합니다. 깊은 복사는 structuredClone을 쓰세요(JSON.parse(JSON.stringify())는 함수·Date를 못 다룸). React 상태는 원본 대신 복사본을 바꿔야 합니다.

주의 — 중첩 상태를 얕게만 복사하면 원본이 변해 버그가 납니다. 바꾸는 부분까지 새로 복사하세요.
