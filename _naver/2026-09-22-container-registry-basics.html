컨테이너 레지스트리가 뭔가요 — 이미지를 저장하고 배포하는 창고

인프라

한 줄 요약 — 컨테이너 레지스트리는 도커 이미지를 저장·공유하는 중앙 창고로, 개발자가 push한 이미지를 서버가 pull해 실행합니다.

 

만든 이미지는 어디에 두나

도커로 앱을 이미지로 만들면 다른 서버·팀원과 공유해야 합니다. 내 PC에만 있으면 배포 서버가 쓸 수 없죠. 컨테이너 레지스트리는 이미지를 저장·배포하는 중앙 창고입니다. 깃허브가 코드 저장소이듯, 레지스트리는 이미지 저장소이며 Docker Hub가 대표적입니다.

 

push와 pull
동작 방향 설명
push 내 PC → 레지스트리 이미지를 창고에 올림
pull 레지스트리 → 서버 창고에서 내려받음

 

사용 흐름
1. docker build -t myapp:1.0 .
2. docker tag myapp:1.0 레지스트리주소/myapp:1.0
3. docker push 레지스트리주소/myapp:1.0
--- 배포 서버에서 ---
4. docker pull 레지스트리주소/myapp:1.0
5. docker run 레지스트리주소/myapp:1.0

 

실무 포인트

회사 이미지엔 공개 저장소 대신 비공개 레지스트리(AWS ECR, GitHub Container Registry, Harbor 등)를 쓰세요. latest만 쓰지 말고 1.0.3처럼 버전 태그를 붙여야 롤백·추적이 쉽습니다. 취약점 스캔도 켜두세요.

주의 — Docker Hub 공개 저장소는 누구나 볼 수 있으므로, 회사 코드가 담긴 이미지를 올리면 안 됩니다.
