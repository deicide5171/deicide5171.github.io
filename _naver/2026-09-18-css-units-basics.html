px, em, rem, %가 뭔가요 — CSS 크기 단위 고르기

2026. 9. 18. · 프론트엔드

한 줄 요약 — CSS 단위는 절대(px)와 상대(em·rem·%·vw)로 나뉘며, 글꼴·여백엔 rem이 예측 가능하고 접근성에 좋습니다.

 

px만 쓰면 안 되나

px만 쓰면 편하지만 반응형·접근성에서 아쉽습니다. 화면 크기나 사용자 글꼴 설정에 유연한 단위를 알아두면 좋죠. CSS 단위는 절대(px)와 상대(em·rem·%·vw)로 나뉩니다.

 

주요 단위
단위 기준
px 고정 픽셀(절대)
em / rem 부모 / 루트 글꼴 크기
% / vw·vh 부모 비율 / 화면 1%

 

em vs rem
em: 부모 글꼴 기준 -> 중첩되면 누적돼 커질 수 있음
rem: 항상 루트(html) 기준 -> 예측 가능
-> 글꼴엔 보통 rem이 안전

 

실무 포인트

글꼴·여백엔 rem(사용자가 기본 글꼴을 키우면 함께 커져 접근성 좋음). 화면 비례엔 %·vw·vh를 씁니다. 테두리 1px·아이콘처럼 고정돼야 하는 값엔 px가 적합합니다.

주의 — em은 중첩되면 누적돼 예상보다 커질 수 있습니다. 헷갈리면 rem을 쓰세요. 무조건 상대 단위가 답은 아닙니다.
