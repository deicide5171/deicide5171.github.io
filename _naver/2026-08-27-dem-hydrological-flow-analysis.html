물은 어디로 흐르는가 — DEM 기반 수문분석, Flow Direction과 유역 추출

2026. 8. 27. · GIS

한 줄 요약 — DEM 한 장으로 물이 어디로 흐르고 어디에 모이는지, 유역 경계가 어디인지까지 계산할 수 있습니다. Flow Direction부터 유역 추출까지 표준 파이프라인을 정리했습니다.

 

DEM으로 무엇까지 계산할 수 있을까요

DEM(Digital Elevation Model)은 단순히 지형을 시각화하는 데만 쓰이지 않습니다. 표준 알고리즘을 순서대로 적용하면 이 지점에 떨어진 빗물이 어느 방향으로 흐르는가, 어느 지점에 물이 가장 많이 모이는가, 특정 관측 지점 상류의 배수 구역은 어디까지인가까지 계산해낼 수 있습니다. 이것이 DEM 기반 수문분석의 핵심 파이프라인입니다.

이 분석은 홍수 위험 지도 제작, 도로·교량 설계 시 배수 계획, 유역 단위 수자원 관리 등에 실무적으로 쓰입니다.

 

핵심 개념 1 — 표준 파이프라인, 전처리부터 유역 추출까지

첫째, 싱크 채우기입니다. 원본 DEM에는 측량·보간 오차로 인한 인공적인 움푹 파인 지점이 곳곳에 있어, 이런 지점을 주변과 같아지도록 채워 흐름이 끊기지 않게 합니다. 둘째, 흐름 방향 계산으로, 가장 널리 쓰이는 D8 알고리즘은 8방향 이웃 중 경사가 가장 급한 방향 하나로만 흐름을 보냅니다. 셋째, 흐름 누적 계산으로 각 셀로 흘러드는 상류 셀의 개수를 누적합니다. 넷째, 흐름 누적 값이 임계값을 넘는 셀만 골라 하천망을 추출하고, 특정 지점 기준으로 유역 경계를 그립니다.

 

 

핵심 개념 2 — 도구 선택, 무엇으로 계산할 것인가
도구 특징
GRASS GIS r.watershed 단일 명령으로 흐름방향·누적·유역 계산, 대용량에 강함
WhiteboxTools 오픈소스, Python 바인딩, 다양한 흐름 알고리즘 지원
PySheds Python 라이브러리, 파이프라인 전체를 코드로 스크립팅

D8은 구현이 단순하고 빠르지만 평탄한 지형에서 흐름을 한 방향으로만 몰아 부자연스러운 직선 패턴이 나올 수 있습니다. 정밀한 분석이 필요하다면 여러 방향으로 흐름을 분배하는 MFD 계열이 더 현실적인 결과를 냅니다.

 

예제 — PySheds로 유역 추출하기
from pysheds.grid import Grid

grid = Grid.from_raster("dem.tif")
dem = grid.read_raster("dem.tif")

# 1. 싱크 채우기
filled_dem = grid.fill_depressions(dem)
flooded_dem = grid.resolve_flats(filled_dem)

# 2. 흐름 방향 계산 (D8)
fdir = grid.flowdir(flooded_dem)

# 3. 흐름 누적 계산
acc = grid.accumulation(fdir)

# 4. pour point를 지정해 유역 delineate
x, y = 127.123, 37.456
x_snap, y_snap = grid.snap_to_mask(acc > 1000, (x, y))
catchment = grid.catchment(x=x_snap, y=y_snap, fdir=fdir, xytype="coordinate")

grid.to_raster(catchment, "watershed.tif")

snap_to_mask로 사용자가 지정한 좌표를 실제 하천 셀로 스냅하는 단계가 중요합니다. 좌표가 하천에서 한 셀만 벗어나도 완전히 다른 유역이 추출될 수 있습니다.

 

실무 도입 시 이것만은 챙기세요
1. DEM 해상도가 분석 스케일을 결정합니다 — 분석 목적에 맞는 해상도의 DEM을 선택해야 하며, 필요 이상으로 고해상도를 쓰면 노이즈가 흐름 방향을 왜곡할 수 있습니다.
2. 평탄한 지역의 흐름 방향 계산은 후처리가 필요합니다 — resolve_flats 같은 후처리로 미세한 경사를 인위적으로 부여해야 합니다.
3. 하천망 임계값은 검증 데이터로 보정하세요 — 실제 하천 지도와 비교해 임계값을 보정하는 과정이 필요합니다.

 

마무리 — 3줄 요약

① DEM 수문분석은 싱크 채우기 → 흐름 방향 → 흐름 누적 → 하천망/유역 추출 순서의 표준 파이프라인을 따릅니다.
② D8은 단순하고 빠르지만 평탄 지역에서 부자연스러운 패턴을 만들 수 있어, 정밀 분석에는 MFD 같은 다방향 알고리즘이 더 현실적입니다.
③ pour point 좌표를 실제 하천 셀로 스냅하는 과정과 DEM 해상도 선택이 유역 추출 결과의 신뢰도를 좌우합니다.
