자바 Stream이 뭔가요 — 컬렉션을 선언적으로 다루기

2026. 9. 19. · 백엔드

한 줄 요약 — Stream은 filter·map·collect로 컬렉션 처리를 선언적으로 짧게 표현합니다.

 

for 문이 길고 읽기 어렵다

리스트를 걸러 변환하고 모으는 작업을 for 문으로 짜면 임시 리스트와 조건문이 얽혀 길어집니다. Stream은 "무엇을 할지"를 선언해 짧고 읽기 쉽게 표현합니다.

 

for 문 vs Stream
// Stream: "20세 이상의 이름을 모아라"
List<String> result = users.stream()
    .filter(u -> u.getAge() >= 20)
    .map(User::getName)
    .collect(Collectors.toList());

 

자주 쓰는 연산
연산 하는 일
filter 조건에 맞는 것만 남김
map 각 요소를 변환
collect 리스트·맵으로 모음
count / sum 개수·합계 집계

filter·map은 지연되는 중간 연산이고, collect·count 같은 최종 연산이 호출될 때 한 번에 실행됩니다.

 

실무 포인트

"무엇을"에 집중해 로직이 한눈에 읽히는 게 장점입니다. 아주 단순한 반복은 for 문이 나을 때도 있습니다.

주의 — 최종 연산이 없으면 아무 일도 안 하고, Stream은 한 번 쓰면 재사용할 수 없습니다(다시 stream()).
