데이터 타입 고르기 — VARCHAR, TEXT, INT 뭘 써야 하나

데이터베이스

한 줄 요약 — 데이터 타입을 잘 고르면 공간을 아끼고 정렬·비교가 올바릅니다. 돈엔 DECIMAL, 전화번호는 문자가 원칙입니다.

 

타입을 대충 정하면 나중에 고생한다

"그냥 다 문자열로" 하면 정렬·계산·용량에서 문제가 생깁니다. 적절한 타입은 저장 공간을 아끼고, 값을 올바르게 정렬·비교하며, 잘못된 데이터를 막습니다.

 

자주 쓰는 타입
타입 용도
VARCHAR(n) 길이 제한 문자열(이름)
TEXT 긴 글(본문)
DECIMAL 정확한 소수(돈)
TIMESTAMP 날짜+시간

 

선택 기준
이름·이메일: VARCHAR
본문: TEXT
가격: DECIMAL (FLOAT는 오차!)
생성 시각: TIMESTAMP (타임존 고려)

 

실무 포인트

FLOAT는 소수를 근사값으로 저장해 오차가 나니 돈엔 DECIMAL을 쓰세요. 전화번호·우편번호는 앞의 0이 사라지지 않게 문자(VARCHAR)로 저장합니다.

주의 — 여러 지역 사용자가 있으면 날짜는 UTC로 저장하고 표시할 때 변환하세요. 타임존 없는 타입은 시간이 뒤섞입니다.
