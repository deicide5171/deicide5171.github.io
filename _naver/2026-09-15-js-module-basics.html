import/export가 뭔가요 — 자바스크립트 모듈 나눠 쓰기

2026. 9. 15. · 프론트엔드

한 줄 요약 — 모듈은 코드를 파일 단위로 나눠 export로 내보내고 import로 가져와 쓰는 방식입니다.

 

코드를 한 파일에 다 넣으면 관리가 안 된다

모든 코드를 한 파일에 몰면 길고 재사용도 어렵습니다. 모듈은 코드를 파일 단위로 나누고 필요한 것만 가져다 씁니다. JS는 export로 내보내고 import로 가져옵니다.

 

export와 import
// math.js
export function add(a, b) { return a + b; }
export const PI = 3.14;
// main.js
import { add, PI } from './math.js';
add(1, 2); // 3

 

named vs default
방식 가져오기
named import { a }
default import fn (이름 자유)

 

실무 포인트

named export를 기본으로 쓰면 자동완성·리팩터링이 쉽고 오타를 잡기 좋습니다. 경로·확장자는 환경(브라우저 vs 번들러)에 맞춥니다.

주의 — A↔B가 서로 import하는 순환 참조는 값이 undefined가 되는 문제를 냅니다. 공통 코드를 별도 파일로 빼 순환을 끊으세요.
