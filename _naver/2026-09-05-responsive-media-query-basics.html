반응형 웹 기초 — 미디어 쿼리와 모바일 퍼스트

2026. 9. 5. · 프론트엔드

한 줄 요약 — 반응형 웹의 핵심 도구는 미디어 쿼리이며, 작은 화면부터 확장하는 모바일 퍼스트(min-width)가 최근 권장됩니다.

 

하나의 페이지로 PC와 모바일 모두

같은 페이지가 PC에서는 넓게, 모바일에서는 좁게 잘 보이려면 화면 크기에 따라 레이아웃이 바뀌어야 합니다. 반응형 웹의 핵심 도구가 미디어 쿼리입니다.

 

미디어 쿼리 기본 문법
.container { display: flex; }

@media (max-width: 768px) {
  .container { flex-direction: column; } /* 모바일은 세로 */
}

 

모바일 퍼스트 vs 데스크톱 퍼스트
접근 미디어 쿼리
모바일 퍼스트 min-width (넓어지면 확장)
데스크톱 퍼스트 max-width (좁아지면 축소)

최근에는 모바일 사용자가 많고 스타일 관리가 깔끔해 모바일 퍼스트가 권장됩니다.

 

반응형의 필수 준비물
<meta name="viewport" content="width=device-width, initial-scale=1.0">

이 태그가 없으면 모바일 브라우저가 PC 화면을 축소해 보여줘 미디어 쿼리가 의도대로 동작하지 않습니다.

 

실무 포인트

고정 px 대신 상대 단위(rem, %, vw)를 활용하세요. Flexbox의 flex-wrap, Grid의 auto-fit, clamp() 함수를 쓰면 브레이크포인트 없이도 유연합니다.

주의 — 코드만 보지 말고 실제 기기나 개발자 도구의 반응형 모드로 여러 화면 폭에서 확인하는 것이 필수입니다.
