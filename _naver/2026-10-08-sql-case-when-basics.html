CASE WHEN이 뭔가요 — SQL 안에서 조건 분기하기

데이터베이스

한 줄 요약 — CASE WHEN은 조건에 따라 다른 값을 반환하는 SQL의 if-else로, 등급 분류·조건부 집계에 유용합니다.

 

값에 따라 다른 표시를 하고 싶다면

점수를 조회하며 "90 이상 A, 80 이상 B..." 등급을 함께 보여주고 싶을 때, SQL 안에서 바로 할 수 있습니다. CASE WHEN은 조건에 따라 다른 값을 반환하는 SQL 조건문입니다.

 

기본 문법
SELECT name, score,
  CASE
    WHEN score >= 90 THEN 'A'
    WHEN score >= 80 THEN 'B'
    ELSE 'F'
  END AS grade
FROM students;

위에서부터 조건을 검사해 처음 맞는 THEN 값을, 안 맞으면 ELSE 값을 씁니다.

 

활용 예
용도 예
등급 분류 점수 → A/B/C
조건부 집계 SUM(CASE WHEN ...)

 

실무 포인트

SUM(CASE WHEN status='완료' THEN 1 ELSE 0 END)로 조건별 개수를 한 쿼리에서 구할 수 있습니다(피벗 효과). WHEN은 위에서부터 멈추므로 좁은 조건을 위에 두세요.

주의 — ELSE가 없고 어떤 조건도 안 맞으면 결과가 NULL이 됩니다. 기본값이 필요하면 ELSE를 지정하세요.
