쿼럼(quorum)이 뭔가요 — 과반수로 일관성 맞추기

2026. 9. 20. · 시스템 설계

한 줄 요약 — 쿼럼은 쓰기·읽기 시 정해진 수 이상의 노드에 물어 일관성을 맞추며, W+R>N이면 최신값을 읽습니다.

 

어느 복제본을 믿나

같은 데이터를 여러 노드에 복제하면 가용성은 오르지만, 일부만 최신일 때 어느 값을 믿을지 문제입니다. 쿼럼은 정해진 수 이상의 노드에 물어보게 해 이를 다룹니다.

 

W + R > N 규칙
N = 복제본 총 개수
W = 쓰기 성공으로 인정할 노드 수
R = 읽기 시 응답받을 노드 수

W + R > N → 읽기·쓰기 집합이 겹쳐 최신값 확보
예: N=3, W=2, R=2 → 2+2 > 3

 

값에 따른 성향
설정 성향
W 크게 쓰기 느림, 일관성 유리
R 크게 읽기 느림, 최신값 유리
W=1, R=1 빠르나 오래된 값 위험

 

실무 포인트

노드 하나가 죽어도 과반이 살아 있으면 계속 동작합니다. W=R=(N/2)+1인 과반수가 기본값입니다.

주의 — 쿼럼은 "겹침"을 보장할 뿐, 동시 쓰기 충돌 해결(버전 벡터 등)은 별도로 필요합니다.
