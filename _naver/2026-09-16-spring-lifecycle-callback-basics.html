@PostConstruct가 뭔가요 — 빈 생성 후 초기화 코드 실행하기

2026. 9. 16. · 백엔드

한 줄 요약 — @PostConstruct는 빈이 만들어지고 의존성 주입이 끝난 직후 실행되는 초기화 메서드, @PreDestroy는 소멸 전 정리용입니다.

 

빈이 준비된 직후에 뭔가 하고 싶다

의존성 주입 후 캐시를 채우거나 설정을 검증하고 싶을 때가 있죠. 생성자에선 아직 주입이 안 끝났을 수 있습니다. @PostConstruct는 주입 완료 직후 자동 실행되는 초기화 메서드입니다.

 

생명주기 콜백
시점 애너테이션
초기화 @PostConstruct
소멸 전 @PreDestroy

 

예시
@PostConstruct
public void init() { /* 주입된 repo로 캐시 로드 */ }

@PreDestroy
public void cleanup() { /* 종료 전 자원 정리 */ }

 

실무 포인트

생성자엔 주입이 다 안 됐을 수 있으니 초기화는 @PostConstruct에 두세요. 스레드 풀·커넥션은 @PreDestroy에서 닫아 누수를 막습니다(그레이스풀 셧다운과 연계).

주의 — @PostConstruct는 앱 시작 시 실행됩니다. 여기서 오래 걸리는 작업을 하면 시작이 느려지니 꼭 필요한 것만 넣으세요.
