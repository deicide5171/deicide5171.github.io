CSS if() 함수 — 조건부 스타일링을 스크립트 없이 표현하는 법

프론트엔드

한 줄 요약 — 조건마다 규칙 블록을 중복 작성하던 문제를, 하나의 선언 안에서 조건과 값을 함께 표현하는 CSS if() 함수의 문법과 한계를 정리했습니다.

 

왜 지금 CSS 조건문을 다시 봐야 하는가

CSS에서 조건에 따라 다른 값을 쓰고 싶을 때는 미디어 쿼리, 컨테이너 쿼리를 조합해 우회적으로 해결해왔습니다. 문제는 조건 하나가 늘어날 때마다 규칙 블록 전체를 복제해야 한다는 것입니다. 다른 언어라면 삼항 연산자 하나로 끝날 일이 CSS에서는 선택자 중복으로 이어졌습니다.

 

선언 안에서 조건과 값을 함께 쓰기

if() 함수는 미디어·컨테이너·기능 조건을 값으로 직접 평가해, 조건이 참이면 첫 번째 값을 반환합니다. 문법은 if(조건1: 값1; 조건2: 값2; else: 기본값) 형태로, 위에서부터 순서대로 평가해 처음 참이 되는 조건의 값을 채택합니다. 스타일 쿼리와 결합하면 부모 요소의 커스텀 속성 값에 따라 자식 요소의 스타일을 완전히 다르게 분기할 수 있습니다.

미디어 쿼리 중첩 조건 수만큼 중복 전체 지원
CSS if() 함수 중복 없음 제한적

 

왜 아직 미디어 쿼리를 완전히 대체하지 못하는가

if()가 미디어·컨테이너·기능 쿼리를 조건으로 모두 받아들일 수 있다는 점은 강력하지만, 2026년 기준 브라우저 지원이 아직 제한적이라 Baseline에 오르지 못했습니다. 실무에서는 옛 방식을 폴백으로 유지하면서 @supports 검사로 점진적으로 도입하는 전략이 필요합니다.

컨테이너 크기별 패딩 분기 예제
.card { padding: 8px; }
@container (min-width: 400px) { .card { padding: 16px; } }
@container (min-width: 700px) { .card { padding: 24px; } }

/* if() 함수 방식 */
.card-modern {
  padding: if(
    container(min-width: 700px): 24px;
    container(min-width: 400px): 16px;
    else: 8px
  );
}

지원 브라우저가 아닌 환경을 위해 if() 선언 앞에 폴백 값을 먼저 적어두면, 미지원 브라우저는 폴백을 적용하고 지원 브라우저는 뒤의 선언으로 값을 덮어씁니다.

 

실무 포인트

@supports로 지원 여부를 먼저 확인해야 합니다. 폴리필이 없는 순수 CSS 기능이므로, 미지원 브라우저에서는 선언 자체가 무효화될 수 있습니다.

디자인 토큰과 결합할 때 진가를 발휘합니다. 다크모드·밀도 설정 같은 다차원 테마 분기를 자바스크립트 없이 CSS 레벨에서 해결할 수 있습니다.

주의 — 조건-값 쌍이 4개를 넘어가면 가독성을 위해 분리를 고려해야 합니다. 지나치게 긴 if() 체인은 오히려 기존 미디어 쿼리보다 읽기 어려워질 수 있습니다.
