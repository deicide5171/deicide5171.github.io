map, filter, reduce가 뭔가요 — 반복문 없이 배열 다루기

프론트엔드

한 줄 요약 — map은 변형, filter는 필터링, reduce는 하나의 값으로 합치는 배열 메서드로, 원본을 바꾸지 않고 새 결과를 반환합니다.

 

for 문을 매번 쓰기 번거롭다

각 값을 변형하거나, 조건에 맞는 것만 고르거나, 합계를 구하는 일은 흔합니다. for로도 되지만 길죠. map·filter·reduce는 이런 배열 처리를 한 줄로 간결하게 표현합니다.

 

세 메서드의 역할
메서드 하는 일
map 각 값을 변형
filter 조건 맞는 것만
reduce 하나의 값으로 합침

 

예시
const nums = [1, 2, 3, 4];
nums.map(n => n * 2);           // [2,4,6,8]
nums.filter(n => n % 2 === 0);  // [2,4]
nums.reduce((sum, n) => sum + n, 0); // 10

 

실무 포인트

map·filter는 원본을 안 바꾸고 새 배열을 반환해 React 상태에 안전합니다. filter(...).map(...)처럼 체이닝하면 읽기 쉽습니다. reduce는 강력하지만 복잡하면 읽기 어려우니 단순 합계·개수에 쓰세요.

주의 — 체이닝은 큰 배열을 여러 번 순회합니다. 성능이 중요하면 한 번에 처리하는 방법도 고려하세요.
