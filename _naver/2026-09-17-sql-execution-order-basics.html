SQL 실행 순서가 뭔가요 — WHERE에서 별칭이 안 되는 이유

데이터베이스

한 줄 요약 — SQL은 적힌 순서가 아니라 FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY 순으로 실행됩니다.

 

SQL은 적힌 순서대로 실행되지 않는다

SQL은 SELECT ... FROM ... WHERE 순으로 적지만 DB는 이 순서대로 실행하지 않습니다. 실제 순서를 알면 "WHERE에서 SELECT 별칭이 왜 안 되는지" 같은 규칙이 이해됩니다.

 

실제 실행 순서
1. FROM     테이블 정함
2. WHERE    행 거름
3. GROUP BY 그룹 묶음
4. HAVING   그룹 거름
5. SELECT   컬럼 고름(별칭 생김)
6. ORDER BY 정렬
7. LIMIT    자름

 

이걸 알면 풀리는 것
궁금증 이유
WHERE에서 별칭 X WHERE(2)가 SELECT(5)보다 먼저
WHERE에 집계 X 집계는 GROUP BY 이후

 

실무 포인트

WHERE엔 별칭 대신 원래 식(WHERE price*0.9 > 100)을 쓰거나 CTE로 감싸세요. 집계 조건은 HAVING에 씁니다. LIMIT은 ORDER BY 뒤에 적용돼 "상위 N개"가 제대로 나옵니다.

주의 — 정렬(ORDER BY) 없이 LIMIT만 쓰면 어떤 N개가 나올지 보장되지 않습니다.
