JPA 연관관계 매핑이 뭔가요 — @OneToMany 첫걸음

백엔드

한 줄 요약 — JPA 연관관계 매핑은 테이블 외래키 관계를 객체 간 참조로 연결하며, 외래키를 관리하는 쪽이 "주인"입니다.

 

외래키를 객체에서 어떻게 다루나

회원과 주문처럼 DB에서 외래키로 연결된 테이블을 JPA는 객체 간 참조로 표현합니다. 회원 객체가 주문 목록을 필드로 갖는 식이죠. 이것이 연관관계 매핑입니다.

 

관계 종류
애너테이션 관계
@OneToMany 하나가 여럿(회원-주문)
@ManyToOne 여럿이 하나에(주문-회원)

 

예시
class Member {
  @OneToMany(mappedBy = "member")
  List<Order> orders;
}
class Order {
  @ManyToOne
  Member member;   // 외래키 주인
}

 

실무 포인트

외래키를 실제 관리하는 쪽이 주인입니다(보통 @ManyToOne, 반대쪽은 mappedBy). 주인이 아닌 쪽만 바꾸면 DB에 반영이 안 됩니다. 연관 로딩은 LAZY를 기본으로 하세요.

주의 — 회원 목록 뒤 각 회원의 주문을 하나씩 조회하면 쿼리가 폭증합니다(N+1). fetch join·@EntityGraph로 한 번에 가져오세요.
