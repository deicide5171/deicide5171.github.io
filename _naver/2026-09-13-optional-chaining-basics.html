옵셔널 체이닝 ?.이 뭔가요 — undefined 에러 안 나게 접근하기

프론트엔드

한 줄 요약 — 옵셔널 체이닝(?.)은 중첩 속성 접근 시 중간이 없으면 에러 대신 undefined를 반환합니다.

 

Cannot read properties of undefined

user.address.city에서 address가 없으면 에러로 앱이 멈춥니다. 예전엔 user && user.address && ...로 일일이 확인했죠. 옵셔널 체이닝(?.)이 이를 간결하게 해줍니다.

 

사용법
// 예전: user && user.address && user.address.city
const city = user?.address?.city;
// address가 없으면 에러 대신 undefined

// 널 병합과 함께
const city = user?.address?.city ?? "미입력";

??(널 병합)는 왼쪽이 null/undefined일 때만 기본값을 씁니다.

 

?? vs ||
연산자 기본값을 쓰는 경우
?? null/undefined만
|| 0·""·false도 포함

 

실무 포인트

API 응답이 모든 필드를 주지 않을 때 data?.user?.profile?.name으로 안전하게 접근합니다. 함수 호출(obj.method?.())·인덱스(arr?.[0])에도 씁니다.

주의 — 0이 유효한 값이면 ||는 0도 "없음"으로 봐 기본값을 씁니다. 이럴 땐 ??를 쓰세요.
