쿠버네티스 볼륨이 뭔가요 — 파드가 죽어도 데이터 지키기

인프라

한 줄 요약 — 볼륨은 파드 바깥 저장 공간을 연결해 파드가 죽어도 데이터를 보존하며, 파드는 PVC로 스토리지를 요청합니다.

 

파드가 죽으면 파일이 사라진다

파드는 언제든 죽고 다시 만들어집니다. 컨테이너 안 파일은 파드가 사라지면 함께 없어지죠. DB 데이터·업로드 파일은 이러면 안 됩니다. 볼륨은 파드 바깥 저장 공간을 컨테이너에 연결해 데이터를 보존합니다.

 

PV와 PVC
개념 설명
PV 실제 저장 공간(디스크)
PVC "이만큼 달라"는 요청
StorageClass 저장소 자동 생성 템플릿

 

흐름
파드 -> PVC("10Gi 필요") -> PV(실제 디스크) 연결
데이터는 파드가 아니라 PV에 저장
파드가 죽어도 새 파드가 같은 PVC로 같은 데이터 사용

 

실무 포인트

DB·파일 저장소 같은 상태 있는 앱엔 영속 볼륨이 필수입니다. 하나의 파드만(ReadWriteOnce)인지 여러 파드 동시(ReadWriteMany)인지 접근 모드를 확인하세요. DB엔 Deployment 대신 StatefulSet을 씁니다.

주의 — 상태 없는(stateless) 앱은 볼륨 없이 여러 파드로 자유롭게 확장하는 것이 좋습니다. 볼륨을 무분별하게 붙이면 확장이 어려워집니다.
