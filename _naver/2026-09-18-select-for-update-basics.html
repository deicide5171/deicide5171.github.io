SELECT FOR UPDATE가 뭔가요 — 조회하면서 행을 잠그기

2026. 9. 18. · 데이터베이스

한 줄 요약 — SELECT FOR UPDATE는 조회한 행을 잠가 내 트랜잭션이 끝날 때까지 다른 트랜잭션이 못 바꾸게 하는 비관적 락입니다.

 

조회한 뒤 바꾸는 사이에 끼어들면

재고를 조회·계산해 다시 저장하는 동안 다른 트랜잭션이 같은 재고를 건드리면 값이 꼬입니다. SELECT ... FOR UPDATE는 조회하면서 그 행을 잠가 이를 막습니다(비관적 락).

 

사용법
BEGIN;
SELECT stock FROM products WHERE id=1 FOR UPDATE;
-- 다른 트랜잭션은 이 행을 못 건드리고 대기
UPDATE products SET stock = stock - 1 WHERE id=1;
COMMIT; -- 커밋하면 잠금 해제

 

실무 포인트

"조회 → 판단 → 갱신"을 원자적으로 해야 하는 재고 차감·좌석 예약에서 이중 차감을 막습니다. 잠금을 오래 쥐면 다른 트랜잭션이 대기하니, 필요한 행만 잠그고 트랜잭션을 짧게 유지하세요.

주의 — 여러 행을 트랜잭션마다 다른 순서로 잠그면 데드락에 빠집니다. 잠그는 순서를 통일하고, 충돌이 드물면 낙관적 락도 고려하세요.
