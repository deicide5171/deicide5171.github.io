커버링 인덱스가 뭔가요 — 테이블 안 읽고 조회 끝내기

2026. 9. 20. · 데이터베이스

한 줄 요약 — 커버링 인덱스는 쿼리에 필요한 컬럼을 인덱스에 다 담아 테이블 접근을 없앱니다.

 

인덱스를 탔는데도 느리다?

인덱스로 행을 찾아도 나머지 컬럼을 읽으려면 테이블 본체를 다시 뒤집니다. 이 추가 접근을 없애는 게 커버링 인덱스입니다. 필요한 컬럼이 인덱스에 다 있으면 테이블을 볼 필요가 없습니다.

 

어떻게 동작하나
SELECT name FROM users WHERE user_id = 100;

CREATE INDEX idx_cover ON users (user_id, name);
-- user_id로 찾고 name도 인덱스에 있어
-- 테이블 접근 불필요

 

일반 인덱스와 비교
구분 테이블 접근
일반 인덱스 위치 찾고 → 테이블에서 나머지 읽음
커버링 인덱스 인덱스만으로 완성(접근 없음)

 

실무 포인트

꼭 필요한 컬럼만 조회하는 빈번한 핵심 쿼리에 적용하면 효과가 큽니다. 조건 컬럼을 앞, 가져올 컬럼을 뒤에 두는 식으로 설계합니다.

주의 — 인덱스에 컬럼을 많이 넣으면 인덱스가 커지고 쓰기가 느려집니다. SELECT *는 커버가 어렵습니다.
