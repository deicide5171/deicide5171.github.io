React 'Cannot read properties of undefined' 에러 잡는 법

2026. 9. 1. · 프론트엔드

한 줄 요약 — API 응답이 오기 전 초기 렌더링에서 아직 없는 데이터에 접근해서 발생하며, 로딩 상태 분기 처리가 가장 확실한 해결책입니다.

 

왜 데이터가 분명히 오는데도 에러가 나는가

이 에러는 자바스크립트 자체 에러지만, React에서는 비동기로 데이터를 가져오는 컴포넌트에서 압도적으로 자주 발생합니다. API 응답 도착 전 state가 초기값(undefined)인 상태에서 속성에 접근하기 때문입니다.

 

에러가 나는 전형적인 패턴
const [user, setUser] = useState(); // 초기값이 undefined!

useEffect(() => {
  fetch(`/api/users/${userId}`).then(res => res.json()).then(setUser);
}, [userId]);

return <p>{user.name}님 환영합니다</p>; // 첫 렌더링에서 에러

 

해결 방법 3가지
// 방법 1: 로딩 상태 분기 (가장 명확)
if (!user) return <p>로딩 중...</p>;
return <p>{user.name}님 환영합니다</p>;

// 방법 2: 옵셔널 체이닝
return <p>{user?.name}님 환영합니다</p>;

// 방법 3: 안전한 초기값
const [user, setUser] = useState({ name: '' });

방법 1이 사용자 경험 측면에서 가장 바람직합니다. 옵셔널 체이닝은 에러는 막아주지만 로딩 중임을 보여주지 못합니다.

 

실무 포인트

배열의 경우 .map() 호출 전에 배열이 undefined인지 확인해야 합니다. 초기값을 빈 배열로 지정하면 이 문제를 원천적으로 피할 수 있습니다.

주의 — 중첩 객체 속성은 체인 전체에 옵셔널 체이닝을 적용해야 합니다. user.address.city가 아니라 user?.address?.city처럼요.
