한 줄 요약 — 벤치마크는 표준 문제 세트로 모델 성능을 점수화해 비교하는 시험지이며, 점수는 참고용이라 실제 용도로 테스트해야 합니다.

 

"이 모델이 87점" 같은 숫자는 뭔가

새 모델이 나오면 "벤치마크 87점" 같은 점수가 나옵니다. 벤치마크는 여러 문제 세트를 모델에 풀리고 정답률로 성능을 점수화한 것입니다. 모델끼리 같은 잣대로 비교하는 표준 시험지죠.

 

흔한 종류
분야 측정

코딩 문제 통과율
대화 품질 사람 선호도 비교

 

실무 포인트

벤치마크가 높아도 내 특정 업무(한국어 응대, 우리 문서 이해)를 잘한다는 보장은 없으니 내 데이터로 직접 테스트하세요. 모델마다 잘하는 분야가 다르니 여러 벤치마크와 용도를 함께 봅니다.

주의 — 벤치마크 문제가 학습 데이터에 들어갔으면(오염) 외워서 맞혀 점수가 부풀려집니다. 새 벤치마크·비공개 평가가 더 믿을 만합니다.
