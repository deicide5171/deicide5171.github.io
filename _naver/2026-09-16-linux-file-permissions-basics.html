리눅스 파일 권한이 뭔가요 — rwx와 chmod 755 읽기

2026. 9. 16. · 인프라

한 줄 요약 — 파일 권한은 소유자·그룹·기타에 읽기(r)·쓰기(w)·실행(x)을 정하며, rwxr-xr-x = 755입니다.

 

Permission denied는 왜 뜨나

스크립트 실행·파일 열기에서 "Permission denied"가 뜨는 건 파일 권한 때문입니다. 리눅스는 각 파일에 "누가 무엇을 할 수 있는지"를 정해둡니다. ls -l의 rwxr-xr-x가 이 권한입니다.

 

rwx와 대상
-rwxr-xr-x
 rwx : 소유자 = 읽기·쓰기·실행
 r-x : 그룹   = 읽기·실행
 r-x : 기타   = 읽기·실행
r=4, w=2, x=1

 

숫자 표기 (chmod 755)
숫자 권한
7 rwx (4+2+1)
5 r-x (4+1)
6 rw- (4+2)

 

실무 포인트

스크립트가 "Permission denied"면 chmod +x로 실행 권한을 주세요. SSH 개인키·설정은 소유자만 읽게 chmod 600으로 좁힙니다(너무 열리면 SSH가 거부).

주의 — chmod 777은 누구나 읽고 쓰고 실행할 수 있어 매우 위험합니다. "권한 문제니 777로"는 나쁜 습관입니다.
