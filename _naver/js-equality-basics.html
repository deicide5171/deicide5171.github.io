== 와 === 차이가 뭔가요 — 자바스크립트 비교의 함정

2026. 9. 11. · 프론트엔드

한 줄 요약 — ==는 타입을 자동 변환해 비교하고 ===는 타입까지 같아야 참이라, 기본적으로 ===를 씁니다.

 

0 == "0"은 참인데 0 === "0"은 거짓

자바스크립트엔 ==(느슨한 동등)과 ===(엄격한 동등)이 있습니다. 차이는 타입이 다를 때 자동 변환을 하느냐입니다. ==는 타입을 맞춰 비교하고, ===는 타입까지 같아야 참입니다.

 

== vs ===
비교 결과
0 == "0" true (변환 후)
0 === "0" false (타입 다름)
null == undefined true

 

== 의 함정
0 == ""        // true
0 == "0"       // true
"" == "0"      // false
false == "0"   // true

직관과 어긋나는 결과라 버그의 원인이 되기 쉽습니다.

 

실무 포인트

기본적으로 ===(그리고 !==)를 쓰세요. 단 value == null은 null 또는 undefined 체크에 편리해 예외적으로 씁니다. 사용자 입력은 Number(input) === 5처럼 명시적으로 변환 후 비교합니다.

주의 — ==의 타입 변환 규칙은 복잡해 예상 밖 결과가 많습니다. 이유가 없다면 항상 ===를 쓰세요.
