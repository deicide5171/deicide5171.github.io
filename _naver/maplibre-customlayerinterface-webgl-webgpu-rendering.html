MapLibre GL JS CustomLayerInterface 딥다이브 — 지도 위에 직접 WebGL 그리기

GIS

한 줄 요약 — 표준 스타일 스펙으로 표현 안 되는 커스텀 시각화는 CustomLayerInterface로 MapLibre 렌더링 파이프라인에 직접 WebGL 코드를 끼워 넣어 구현합니다.

 

왜 필요한가

MapLibre GL JS는 fill, line, symbol, heatmap 같은 내장 레이어로 대부분을 커버하지만, 커스텀 셰이더 효과나 대량 포인트 실시간 애니메이션 앞에서는 한계에 부딪힙니다. deck.gl의 MapboxOverlay도 내부적으로 바로 이 인터페이스를 구현해 통합됩니다.

 

렌더링 파이프라인 속 위치와 생명주기

CustomLayerInterface를 구현한 레이어는 일반 스타일 레이어와 동일하게 레이어 순서에 참여합니다. onAdd(map, gl)는 추가 시 1회 호출되어 셰이더·버퍼를 초기화하고, render(gl, matrix)는 매 프레임 호출되어 카메라 행렬을 받아 좌표를 지도와 일치시킵니다.

 

같은 GL 컨텍스트를 공유하는 함정

가장 중요한 사실은, 커스텀 레이어가 MapLibre 본체와 동일한 WebGL 컨텍스트를 공유한다는 점입니다. render() 안에서 블렌드 모드나 depth test 상태를 바꿔놓고 복원하지 않으면, 바로 다음에 그려지는 기본 레이어가 잘못된 상태에서 렌더링되어 지도가 깨질 수 있습니다.

메서드 호출 시점 주요 작업
onAdd 추가 시 1회 셰이더·버퍼 초기화
render 매 프레임 유니폼 설정, draw call
onRemove 제거 시 1회 리소스 해제

 

최소 구현 예제
const customLayer = {
  id: 'highlight-triangle',
  type: 'custom',
  renderingMode: '3d',

  onAdd(map, gl) {
    this.program = createProgram(gl, vertexSrc, fragmentSrc);
    this.buffer = gl.createBuffer();
    gl.bindBuffer(gl.ARRAY_BUFFER, this.buffer);
    gl.bufferData(gl.ARRAY_BUFFER, mercatorCoords, gl.STATIC_DRAW);
  },

  render(gl, matrix) {
    gl.useProgram(this.program);
    gl.uniformMatrix4fv(
      gl.getUniformLocation(this.program, 'u_matrix'), false, matrix);
    gl.enable(gl.BLEND);
    gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);
    gl.drawArrays(gl.TRIANGLES, 0, 3);
  },
};

map.on('load', () => map.addLayer(customLayer));

 

실무 포인트

좌표계 변환을 잊지 마세요. 경위도 좌표를 직접 셰이더에 넣으면 안 되고, MercatorCoordinate.fromLngLat 같은 유틸리티로 먼저 변환해야 합니다.

renderingMode: '3d'를 설정해야 depth buffer가 유지됩니다. 기본값에서는 매 프레임 depth buffer가 지워지므로 3D 오브젝트가 제대로 가려지지 않습니다.

주의 — 대량 데이터 시각화가 필요하다면 직접 WebGL을 다루기보다 deck.gl의 MapboxOverlay를 CustomLayer로 등록해 최적화된 레이어를 재사용하는 편이 효율적입니다.
