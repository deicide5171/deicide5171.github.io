도커 멀티스테이지 빌드가 뭔가요 — 이미지 가볍게 만들기

2026. 9. 20. · 인프라

한 줄 요약 — 멀티스테이지 빌드는 빌드·실행 단계를 나눠 필요한 산출물만 최종 이미지에 담습니다.

 

이미지가 1GB나 된다

빌드에 쓴 컴파일러·의존성이 최종 이미지에 남으면 무거워집니다. 멀티스테이지 빌드는 실행에 꼭 필요한 것만 최종 이미지에 담는 방법입니다.

 

빌드와 실행 분리
# 1단계: 빌드
FROM node:20 AS builder
WORKDIR /app
COPY . .
RUN npm ci && npm run build

# 2단계: 실행 (결과물만 복사)
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html

AS builder로 이름을 붙이고 --from=builder로 결과물만 가져옵니다. 컴파일러·node_modules는 남지 않습니다.

 

무엇이 좋아지나
항목 효과
이미지 크기 빌드 도구 제외로 대폭 감소
보안 불필요한 도구 없어 공격면 축소
배포 속도 작은 이미지가 빠르게 기동

 

실무 포인트

실행 단계 베이스로 alpine·distroless 같은 경량 이미지를 쓰면 더 가벼워집니다. 자주 안 바뀌는 의존성 설치를 앞 레이어에 두면 캐시가 재사용됩니다.

주의 — 마지막 단계엔 산출물(빌드 결과·바이너리)만 복사하고 소스·빌드 도구는 버리세요.
