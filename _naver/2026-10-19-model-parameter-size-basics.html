한 줄 요약 — 7B·70B는 파라미터(가중치) 수로 대략 모델 크기를 뜻하며, 클수록 성능은 좋지만 느리고 비쌉니다.

 

모델 이름의 7B는 뭘까

모델 이름의 7B·70B는 파라미터 수입니다. B는 10억이라 7B는 70억 개, 70B는 700억 개죠. 파라미터는 모델이 학습하며 조정하는 가중치로, 대략 모델의 크기·용량을 나타냅니다.

 

크기가 커지면
항목 작은(7B) 큰(70B)
성능 낮음 높음
속도·비용 빠름·적음 느림·많음

 

파라미터가 많으면 왜 똑똑한가
많을수록 더 많은 패턴·지식을 담음
-> 복잡한 추론·다양한 지식에 유리
단, 잘 학습된 작은 모델이
   못 배운 큰 모델보다 나을 수 있다

 

실무 포인트

간단한 분류·요약은 작은 모델로 충분하고 빠릅니다. 복잡한 추론엔 큰 모델이 유리하죠. 큰 모델은 메모리(VRAM)가 많이 드는데 양자화로 줄여 작은 장비에서 돌리기도 합니다.

주의 — 파라미터 수만으로 성능을 단정하지 마세요. 학습 데이터·구조(MoE)·파인튜닝에 따라 크게 달라집니다. 실제 벤치마크·실사용으로 확인하세요.
