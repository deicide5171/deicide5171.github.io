시스템 프롬프트가 뭔가요 — 유저 프롬프트와 무엇이 다른가

2026. 9. 5. · AI

한 줄 요약 — 시스템 프롬프트는 AI의 성격·규칙·제약을 지정하는 특별한 자리로, 규칙은 system에 실제 요청은 user에 넣어야 일관성이 유지됩니다.

 

같은 프롬프트인데 왜 역할을 나누나

메시지에는 system·user·assistant 세 role이 있습니다. 시스템 프롬프트(system)는 "AI가 어떻게 행동해야 하는지"를 정하는 특별한 자리로, 일반 대화(user)와 역할이 다릅니다.

 

세 가지 역할
role 용도
system AI의 성격·규칙·제약 지정
user 실제 질문·요청
assistant AI의 이전 답변(맥락 유지)

 

시스템 프롬프트 예제
{"role": "system",
 "content": "너는 친절한 고객센터 상담원이야. 항상 존댓말을 쓰고,
             환불은 7일 이내만 가능하다고 안내해."}
{"role": "user", "content": "환불하고 싶어요"}

시스템 프롬프트에 역할·말투·규칙을 적으면 그 뒤 모든 대화에 일관되게 적용됩니다.

 

user에 다 넣는 것과 뭐가 다른가
나쁨: 매 user에 규칙 반복 -> 길어지면 묻히고 조작 쉬움
좋음: 규칙은 system, 요청만 user -> 설정·대화 분리

 

실무 포인트

"친절하게"보다 "존댓말, 3문장 이내, 모르면 모른다고"처럼 구체적인 규칙이 원하는 동작을 안정적으로 만듭니다.

주의 — 시스템 프롬프트만으로 100% 통제되지 않습니다(프롬프트 인젝션). 민감한 작업엔 출력 검증 같은 추가 안전장치가 필요합니다.
