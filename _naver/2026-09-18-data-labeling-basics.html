데이터 라벨링이 뭔가요 — AI에게 정답을 알려주는 작업

AI

한 줄 요약 — 데이터 라벨링은 AI가 학습하도록 데이터에 정답(라벨)을 붙이는 작업으로, 라벨 품질이 AI 성능을 좌우합니다.

 

AI는 정답이 있어야 배운다

지도학습 AI는 "입력 → 정답" 쌍을 보며 배웁니다. 고양이 사진에 "고양이" 정답이 붙어야 학습하죠. 데이터 라벨링은 데이터에 이 정답(라벨)을 붙이는 작업입니다.

 

라벨의 예
작업 라벨
이미지 분류 "개/고양이" 태그
감정 분석 "긍정/부정"
객체 탐지 경계 상자 + 이름

 

왜 중요한가
라벨 정확 -> AI가 올바른 패턴 학습
라벨 부정확 -> AI도 잘못 배움
(쓰레기 in, 쓰레기 out)

 

실무 포인트

여러 사람이 라벨링하면 기준이 제각각이니 명확한 가이드를 만드세요. 일부를 여러 명이 라벨링해 합의도를 보는 등 품질 검증을 합니다. LLM으로 초벌 라벨을 달고 사람이 검수하기도 합니다.

주의 — 라벨 오류가 많으면 모델이 아무리 좋아도 성능이 안 오릅니다. AI 초벌 라벨도 틀릴 수 있으니 검증은 필수입니다.
