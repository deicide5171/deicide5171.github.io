구조 분해 할당이 뭔가요 — 객체·배열에서 값 꺼내기

2026. 9. 12. · 프론트엔드

한 줄 요약 — 구조 분해 할당은 객체·배열의 값을 한 번에 여러 변수로 꺼내는 문법으로, 함수 매개변수·React props에 유용합니다.

 

값을 하나씩 꺼내기 번거롭다

객체·배열에서 값을 const name = user.name;처럼 하나씩 쓰면 반복이 많습니다. 구조 분해 할당은 값을 한 번에 여러 변수로 꺼냅니다.

 

객체와 배열
const user = { name:"철수", age:20 };
const { name, age } = user;   // name="철수", age=20

const arr = [1, 2, 3];
const [first, second] = arr;  // first=1, second=2

 

자주 쓰는 형태
문법 의미
const {a = 1} = obj 없으면 기본값 1
const {a: x} = obj a를 x 이름으로
function f({a, b}) 매개변수에서 바로 분해

 

실무 포인트

function api({url, method, body})처럼 옵션 객체를 바로 분해하면 인자 순서를 외울 필요가 없습니다(React props도 동일). const {timeout = 5000} = options처럼 기본값으로 안전하게 쓰세요.

주의 — const {a:{b:{c}}} = obj처럼 너무 깊게 분해하면 읽기 어렵고, 중간이 undefined면 에러가 납니다. 깊으면 단계를 나누세요.
