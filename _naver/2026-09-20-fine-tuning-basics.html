파인튜닝이 뭔가요 — 언제 모델을 직접 학습시켜야 할까

AI

한 줄 요약 — 파인튜닝은 학습된 모델에 말투·형식을 덧입히는 추가 학습이며, 최신 지식 주입에는 RAG가 더 적합합니다.

 

이미 똑똑한 모델을 왜 또 학습시키나

파인튜닝은 이미 학습된 모델을 특정 목적·도메인·말투에 맞게 추가 학습시키는 것입니다. "처음부터 학습"이 아니라 "이미 아는 모델에 우리만의 스타일을 덧입히는" 작업입니다.

 

파인튜닝 vs 다른 방법
프롬프트 엔지니어링: 지시를 잘 쓰기 (가장 저렴)
RAG: 외부 지식 검색해 넣기 (최신·사내 정보)
파인튜닝: 모델 행동 자체를 바꾸기 (말투·형식)

순서: 프롬프트 -> RAG -> 그래도 안 되면 파인튜닝

 

흔한 오해
오해: "파인튜닝하면 새 지식을 외운다"
사실: 행동·스타일을 바꾸는 데 강하지,
      최신 사실 주입엔 비효율적. 그건 RAG가 적합.

 

실무 포인트

양질의 학습 데이터가 성패를 좌우합니다. 지저분한 데이터로 학습하면 오히려 나빠집니다. 전체 파인튜닝보다 LoRA 같은 경량 기법이 실용적입니다.

주의 — 파인튜닝은 데이터 준비·학습·버전 관리 부담이 큽니다. 프롬프트·RAG로 해결되면 그것이 훨씬 저렴하고 유연합니다.
