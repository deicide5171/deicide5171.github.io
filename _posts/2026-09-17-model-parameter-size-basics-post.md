## 모델 이름의 7B는 뭘까

`Llama 7B`, `70B`처럼 모델 이름에 붙는 숫자는 **파라미터 수**다. B는 billion(10억)이라 7B는 70억 개, 70B는 700억 개의 파라미터를 뜻한다. **파라미터**는 모델이 학습하며 조정하는 "가중치"로, 대략 모델의 크기·용량을 나타낸다.

## 크기가 커지면

| 항목 | 작은 모델(7B) | 큰 모델(70B) |
|---|---|---|
| 성능 | 대체로 낮음 | 대체로 높음 |
| 속도 | 빠름 | 느림 |
| 비용·메모리 | 적음 | 많음 |
| 실행 환경 | 노트북도 가능 | 고성능 GPU 필요 |

## 파라미터가 많으면 왜 똑똑한가

```text
파라미터가 많을수록 -> 더 많은 패턴·지식을 담을 수 있음
-> 복잡한 추론·다양한 지식에 유리
단, 무조건 크다고 좋은 건 아니다:
  잘 학습된 작은 모델이 못 배운 큰 모델보다 나을 수 있다.
```

## 실무 포인트

- **용도에 맞는 크기를 골라라.** 간단한 분류·요약은 작은 모델로 충분하고 빠르고 싸다. 복잡한 추론·다목적 작업엔 큰 모델이 유리하다. 무조건 큰 모델을 쓰면 비용만 낭비할 수 있다.
- **메모리가 실행 가능 여부를 정한다.** 큰 모델은 파라미터를 다 메모리에 올려야 해 GPU 메모리(VRAM)가 많이 든다. 양자화(quantization)로 메모리를 줄여 작은 장비에서 돌리기도 한다.
- **파라미터 수만으로 비교 말라.** 학습 데이터 품질, 구조(MoE 등), 파인튜닝에 따라 성능이 크게 달라진다. 크기는 하나의 지표일 뿐, 실제 성능은 벤치마크·실사용으로 확인한다.

## 마무리 요약

- 모델 이름의 7B·70B는 파라미터(가중치) 수로, 대략 모델의 크기·용량을 뜻한다.
- 클수록 대체로 성능이 좋지만 느리고 비싸며 메모리가 많이 든다.
- 용도에 맞는 크기를 고르고, 파라미터 수만으로 성능을 단정하지 말고 실제로 확인한다.
