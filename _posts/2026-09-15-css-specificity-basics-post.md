## 스타일을 줬는데 안 바뀐다

CSS로 색을 바꿨는데 화면이 그대로일 때가 있다. 다른 규칙이 더 "강해서" 이겼기 때문이다. 여러 규칙이 같은 요소에 충돌하면, CSS는 **명시도(specificity, 우선순위)**로 어느 규칙을 적용할지 정한다.

## 우선순위 (높을수록 이김)

| 선택자 | 강도 |
|---|---|
| 인라인 스타일(`style="..."`) | 가장 강함 |
| id(`#header`) | 강함 |
| class·속성·가상클래스(`.btn`) | 중간 |
| 태그(`div`, `p`) | 약함 |

같은 강도면 **나중에 선언된 규칙**이 이긴다.

## 예시

```css
p { color: black; }        /* 태그: 약함 */
.text { color: blue; }     /* class: 중간 */
#intro { color: red; }     /* id: 강함 */

/* <p id="intro" class="text">...</p> -> 빨강(id가 이김) */
```

## 실무 포인트

- **`!important`는 최후의 수단.** `!important`는 우선순위를 무시하고 강제 적용한다. 급할 땐 편하지만 남발하면 나중에 스타일을 못 덮어 유지보수가 지옥이 된다. 정말 필요할 때만 쓴다.
- **id 선택자 남용을 피하라.** id는 우선순위가 너무 높아 나중에 덮기 어렵다. 스타일링은 주로 class로 하고 id는 자바스크립트 선택·앵커 용도로 쓰는 것이 관리에 좋다.
- **안 먹으면 개발자 도구로 확인.** 브라우저 개발자 도구는 어떤 규칙이 적용되고 어떤 규칙이 덮였는지(줄 그어진 것) 보여준다. 우선순위 문제는 여기서 바로 진단할 수 있다.

## 마무리 요약

- CSS 명시도(우선순위)는 규칙이 충돌할 때 어느 것을 적용할지 정한다.
- 인라인 > id > class > 태그 순으로 강하고, 같은 강도면 나중 선언이 이긴다.
- `!important`와 id 남용을 피하고, 안 먹으면 개발자 도구로 우선순위를 확인한다.
