## 왜 로컬에서 LLM을 돌리나

ChatGPT나 Claude API를 쓰면 편하지만, 요금이 들고 데이터가 외부로 나간다. 민감한 문서를 다루거나, 요금 없이 마음껏 실험하거나, 인터넷 없이 쓰고 싶을 때는 **로컬 LLM**이 답이다. **Ollama**는 복잡한 설정 없이 명령 한 줄로 오픈 웨이트 모델을 내려받아 내 컴퓨터에서 실행하게 해주는 도구다.

## Ollama의 장단점

| 항목 | 장점 | 한계 |
|---|---|---|
| 비용 | API 요금 없음 | 내 하드웨어 자원 소모 |
| 프라이버시 | 데이터가 외부로 안 나감 | - |
| 성능 | - | 최상위 클라우드 모델보다 대체로 낮음 |
| 필요 사양 | - | 큰 모델일수록 많은 RAM·GPU 필요 |

## 설치와 첫 대화

```bash
# 1. 설치 (macOS/Linux/Windows 모두 공식 설치 프로그램 제공)
# 설치 후 아래 한 줄이면 모델을 내려받아 바로 대화

ollama run llama3.2

# 프롬프트가 뜨면 그냥 대화하면 된다
>>> 파이썬으로 피보나치 함수 짜줘
```

`ollama run <모델명>`을 실행하면 모델이 없으면 자동으로 내려받고, 곧바로 대화형 프롬프트가 뜬다. 클라우드 API 없이 완전히 내 컴퓨터 안에서 동작한다.

## 코드에서 API처럼 쓰기

```python
import requests

response = requests.post("http://localhost:11434/api/generate", json={
    "model": "llama3.2",
    "prompt": "안녕하세요를 영어로 번역해줘",
    "stream": False,
})
print(response.json()["response"])
```

Ollama는 로컬에 API 서버(기본 11434 포트)를 함께 띄워주기 때문에, 클라우드 LLM API와 비슷한 방식으로 코드에서 호출할 수 있다. 덕분에 로컬에서 개발하다 나중에 클라우드로 바꾸기도 수월하다.

## 실무 포인트

- **모델 크기와 내 하드웨어를 맞춰야 한다.** 파라미터가 큰 모델(70B 등)은 많은 RAM·VRAM을 요구해, 사양이 부족하면 매우 느리거나 아예 안 뜬다. 처음에는 작은 모델(3B~8B급)로 시작하는 것이 좋다.
- **양자화된 모델을 쓰면 더 적은 자원으로 돌릴 수 있다.** 정밀도를 낮춰 용량을 줄인 양자화 버전은 성능 손실을 감수하는 대신 일반 노트북에서도 돌아갈 수 있게 해준다.
- **로컬 모델은 최신 클라우드 모델만큼의 품질을 기대하면 안 된다.** 실험·프라이버시·오프라인 용도에는 훌륭하지만, 복잡한 추론이 필요한 프로덕션 작업은 여전히 클라우드 모델이 유리한 경우가 많다.

## 마무리 요약

- Ollama는 명령 한 줄로 오픈 웨이트 LLM을 내려받아 내 컴퓨터에서 실행하는 도구다.
- 요금 없이, 데이터를 외부로 보내지 않고, 오프라인에서도 LLM을 쓸 수 있다.
- 로컬 API 서버를 함께 띄워 코드에서 클라우드 API처럼 호출할 수 있으며, 모델 크기는 하드웨어에 맞춰 골라야 한다.
