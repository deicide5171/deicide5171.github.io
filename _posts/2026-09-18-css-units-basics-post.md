## px만 쓰면 안 되나

CSS로 글자·여백 크기를 정할 때 `px`만 쓰면 편하지만, 반응형·접근성에서 아쉽다. 화면 크기나 사용자 글꼴 설정에 따라 유연하게 조절되는 단위를 알아두면 좋다. CSS 단위는 **절대 단위**(px)와 **상대 단위**(em·rem·%·vw)로 나뉜다.

## 주요 단위

| 단위 | 기준 |
|---|---|
| px | 고정 픽셀(절대) |
| em | 부모 요소의 글꼴 크기 |
| rem | 루트(html)의 글꼴 크기 |
| % | 부모 요소 대비 비율 |
| vw / vh | 화면 너비/높이의 1% |

## em vs rem

```text
em: 부모 글꼴 크기 기준 -> 중첩되면 누적돼 커질 수 있음
rem: 항상 루트(html) 기준 -> 예측 가능, 일관적
-> 글꼴 크기엔 보통 rem이 안전
```

## 실무 포인트

- **글꼴·여백엔 rem을 권장.** rem은 루트 글꼴 크기 기준이라 예측 가능하고, 사용자가 브라우저 기본 글꼴을 키우면 함께 커져 접근성에도 좋다. em은 중첩 시 누적돼 헷갈릴 수 있다.
- **화면 비례엔 %·vw·vh.** 컨테이너 너비를 부모의 절반으로 하려면 `50%`, 화면 전체 높이를 채우려면 `100vh`처럼 상대 단위를 쓴다. 반응형 레이아웃의 기본이다.
- **px가 나쁜 건 아니다.** 테두리 1px, 아이콘 크기처럼 딱 고정돼야 하는 값엔 px가 적합하다. 무조건 상대 단위가 좋은 건 아니고 상황에 맞게 섞어 쓴다.

## 마무리 요약

- CSS 단위는 절대(px)와 상대(em·rem·%·vw)로 나뉜다.
- em은 부모 글꼴, rem은 루트 글꼴 기준이며 글꼴·여백엔 rem이 예측 가능하고 접근성에 좋다.
- 화면 비례엔 %·vw·vh를 쓰고, 고정돼야 하는 값엔 px를 쓰며 상황에 맞게 섞는다.
