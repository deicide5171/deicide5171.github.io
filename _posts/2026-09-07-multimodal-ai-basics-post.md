## 텍스트만 다루던 AI에서 한 걸음 더

초기 LLM은 텍스트만 입력받고 텍스트만 출력했다. **멀티모달(multimodal) AI**는 여러 종류(모달리티)의 데이터를 함께 다룬다. 이미지를 보고 설명하거나, 사진 속 표를 읽어 정리하거나, 음성을 듣고 답하는 것이 멀티모달이다. "모달"은 데이터의 종류를 뜻하고, "멀티"는 그것이 여러 개라는 뜻이다.

## 어떤 것을 함께 다루나

| 모달리티 | 예시 |
|---|---|
| 텍스트 | 질문, 문서 |
| 이미지 | 사진, 스크린샷, 도표 |
| 음성 | 녹음, 실시간 대화 |
| 영상 | 동영상 프레임 분석 |

## 멀티모달로 할 수 있는 일

```text
- 사진을 올리고 "이게 뭐야?" -> 이미지 이해
- 손글씨 메모 사진 -> 텍스트로 변환·요약
- 차트 이미지 -> 데이터 표로 정리
- 화면 스크린샷 -> UI 문제점 지적
- 음성 질문 -> 음성/텍스트 답변
```

핵심은 사람이 여러 감각으로 정보를 받아들이듯, AI도 텍스트에 갇히지 않고 이미지·음성을 함께 이해해 더 자연스럽게 돕는다는 것이다.

## 코드 예제: 이미지와 텍스트를 함께 전달

```python
response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[{
        "role": "user",
        "content": [
            {"type": "image", "source": {...}},  # 이미지
            {"type": "text", "text": "이 사진에 뭐가 있어?"},  # 텍스트
        ],
    }],
)
```

멀티모달 모델은 `content`에 이미지와 텍스트를 함께 넣을 수 있다. 모델이 이미지를 "보고" 텍스트 질문에 답한다.

## 실무 포인트

- **이미지는 토큰을 많이 소모한다.** 이미지도 내부적으로 토큰으로 변환되어 처리되므로, 고해상도 이미지를 여러 장 넣으면 비용이 빠르게 늘어난다. 필요한 해상도로 줄여서 넣는 것이 좋다.
- **이미지 이해와 이미지 생성은 다른 기능이다.** "사진을 이해하는 것"과 "그림을 그려내는 것"은 별개 능력이다. 모델·서비스마다 지원 범위가 다르므로 무엇을 지원하는지 확인해야 한다.
- **멀티모달도 환각을 일으킨다.** 이미지 속에 없는 것을 있다고 하거나 숫자를 잘못 읽을 수 있으므로, 중요한 정보(금액, 수치)는 반드시 사람이 검증해야 한다.

## 마무리 요약

- 멀티모달 AI는 텍스트뿐 아니라 이미지·음성·영상 등 여러 종류의 데이터를 함께 이해한다.
- 이미지 설명, 표·차트 읽기, 음성 대화 등 텍스트만으로는 못 하던 작업을 할 수 있다.
- 이미지는 토큰 비용이 크고 환각도 일어나므로, 해상도 조절과 중요한 정보의 사람 검증이 필요하다.
