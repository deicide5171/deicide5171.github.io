## 유해한 내용을 사람이 다 검토할 순 없다

사용자가 올리는 글, 또는 AI가 생성하는 답변에 욕설·혐오·폭력·성적 내용이 섞일 수 있다. 양이 많아 사람이 다 검토하긴 어렵다. **콘텐츠 모더레이션(moderation)**은 **텍스트·이미지에서 유해·부적절한 내용을 자동으로 탐지·분류**해 걸러내는 것이다.

## 어디에 적용하나

```text
입력 모더레이션: 사용자가 보낸 내용을 검사
  -> 유해하면 차단하고 AI에 안 넘김
출력 모더레이션: AI가 생성한 답을 검사
  -> 유해하면 사용자에게 안 보여줌
```

## 분류 카테고리 예

| 카테고리 | 예 |
|---|---|
| 증오·혐오 | 특정 집단 비하 |
| 폭력 | 폭력 위협·묘사 |
| 성적 내용 | 성인물 |
| 자해 | 자해·자살 조장 |

## 실무 포인트

- **점수와 임계값으로 판정.** 모더레이션은 보통 카테고리별 위험도 점수를 준다. "0.8 이상이면 차단"처럼 임계값을 정한다. 너무 낮으면 정상 내용도 막고(과차단), 너무 높으면 유해 내용이 새니 균형을 맞춘다.
- **완벽하지 않으니 사람 검토 병행.** 자동 모더레이션은 실수한다. 애매한 것은 사람이 다시 보게 하거나, 사용자 신고와 결합한다. 특히 위험도가 높은 서비스는 사람 검토를 함께 둔다.
- **맥락을 놓칠 수 있다.** 같은 단어도 맥락에 따라 유해할 수도, 아닐 수도 있다(의료·교육 등). 무조건 키워드로 막으면 정상 대화가 차단되니, 맥락을 고려하는 모델과 예외 처리를 둔다.

## 마무리 요약

- 콘텐츠 모더레이션은 유해·부적절한 내용을 자동으로 탐지·분류해 걸러내는 것이다.
- 사용자 입력(입력 모더레이션)과 AI 출력(출력 모더레이션) 양쪽에 적용한다.
- 점수·임계값으로 판정하되 과차단을 조심하고, 사람 검토와 맥락 고려를 병행한다.
